# 見開き 1 ページずらし確認用サンプル

`Ctrl+←/→` の「見開き 1 ページずらし」で、表紙あり / 表紙なし / 横長ページ境界の挙動を確認するための手動テストデータ。

各 `pages/` フォルダを mImageViewer で開き、見開き表示にしてから 3 ページ目または README 内の対象ページを表示し、`Ctrl+→` を押す。

## 01_plain_5p

全 5 ページ、すべて縦長。

- 表紙ありの初期状態: `1 -> 2,3 -> 4,5`
- 3 ページ目で 1 ページずらし後: `1,2 -> 3,4 -> 5`
- 表紙なしの初期状態: `1,2 -> 3,4 -> 5`
- 3 ページ目で 1 ページずらし後: `1 -> 2,3 -> 4,5`

## 02_leading_landscape_6p

全 6 ページ、1 ページ目だけ横長。

- 初期状態: `[1] -> 2,3 -> 4,5 -> 6`
- 3 ページ目で 1 ページずらし後: `[1] -> 2 -> 3,4 -> 5,6`
- 表紙あり / 表紙なしどちらでも同じになる

## 03_mid_landscape_page3_8p

全 8 ページ、3 ページ目だけ横長。表紙なしで、横長ページの後ろ側の区間を確認する。

- 初期状態: `1,2 -> [3] -> 4,5 -> 6,7 -> 8`
- 5 ページ目で 1 ページずらし後: `1,2 -> [3] -> 4 -> 5,6 -> 7,8`

## 04_mid_landscape_page4_8p

全 8 ページ、4 ページ目だけ横長。表紙ありで、通常の表紙区間と途中横長境界の両方を確認する。

- 初期状態: `1 -> 2,3 -> [4] -> 5,6 -> 7,8`
- 6 ページ目で 1 ページずらし後: `1 -> 2,3 -> [4] -> 5 -> 6,7 -> 8`
