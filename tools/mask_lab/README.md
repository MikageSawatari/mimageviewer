# mask_lab

消しゴム / 隠蔽加工のマスク作成 UI とアルゴリズムを、mIV 本体へ組み込む前に試すための軽量実験アプリ。

本体の動画、検索、PDF、ONNX などを使わず、JPEG / PNG 画像 1 枚だけを読み込んで以下を試せる。

- クリック式多角形囲み
- 多角形の境界吸着
- マスクの拡大 / 縮小 / 平滑化
- 境界で止まる筆
- 境界線だけを追加 / 除去する筆

## 起動

```powershell
cargo run -p mask_lab -- path\to\image.png
```

起動後に画像ファイルをウィンドウへドラッグ & ドロップしても読み込める。

## 出力

左パネルのボタンから、入力画像と同じフォルダへ以下を保存する。

- `{stem}_mask.png`: 白黒マスク
- `{stem}_mask_overlay.png`: 半透明マスクを重ねた確認用画像

このツールは検証用であり、mIV 本体の配布物には含めない。
