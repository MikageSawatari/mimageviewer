# comic_lab bundled fonts

This directory contains lab-only bundled fonts. The lab registers TTF/OTF/TTC
files here at startup before system fonts, so the onomatopoeia presets can use
OFL fonts without requiring a Windows install.

Currently bundled for onomatopoeia sampling (18 font files, about 61 MiB total):

- `HachiMaruPop-Regular.ttf` - `HachiMaruPop-OFL.txt`
- `KaiseiDecol-Bold.ttf` - `KaiseiDecol-OFL.txt`

The current files were downloaded from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl

When bundling OFL fonts, keep the original license text beside the font files
and preserve the font's upstream name unless the OFL terms for that family allow
renaming.
