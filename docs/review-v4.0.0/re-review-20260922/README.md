### U-1 (P1) コレクションから開いた本を Esc で抜けると、コレクションではなく実フォルダへ戻る

- 観測者: 利用者 (実機、2026-09-22)。スマートフォルダでは正しく戻れるとの報告。Codex が調査・修正中。
- コード上の原因 (Fable 確定、作業ツリーで未修正を確認): 「親の一覧へ戻る先」を決める関数が `src/app.rs` に
  3 つあり、同じ分岐列を重複して持つ。

  | 関数 | 使われる場面 | コレクション分岐 | スマートフォルダ分岐 |
  | --- | --- | --- | --- |
  | `grid_parent_nav_target` (`:19363`) | BS / ⬆ の可否表示 | あり | あり |
  | `resolve_grid_parent_nav` (`:19399`) | BS / ⬆ の実行 | あり | あり |
  | `resolve_return_to_parent_nav` (`:19470`) | 「ページを直接開く」で開いた本から Esc / Enter / 右クリックで抜ける | **無し** | あり |

  3 つ目だけ `collection_grid_parent_nav()` が抜けており、末尾の `effective_folder().parent()` へ落ちる。
  コミット済みの状態でも同じで、今回の修正による退行ではなくコレクション実装当初からの抜け。
  初回レビューの横断テーマ T1 (コレクションだけ既存の分岐列から漏れる) と同じ型で、初回レビューでも拾えていなかった。
- 修正方向: `resolve_return_to_parent_nav` の先頭へ他の 2 つと同じ 1 分岐を足す。受け側の
  `apply_fullscreen_close_nav_immediate` (`:19530-`) は既に `AddressBarNav::Collection(restore)` を
  `open_collection_grid` へ渡せる。コレクションでは実フォルダ用の `select_after_load` を設定しない。
  3 関数を 1 つにまとめる構造修正は v4.0.x でもよい。
- 回帰: コレクション root から ZIP / PDF を「ページを直接開く」ON で開き、`take_pending_return_to_parent_nav()` が
  `AddressBarNav::Collection` を返すこと。変換が要る書庫 (表示中のパスが変換後 ZIP を指す) でも同じこと。

## 6. 追補: U-1 / RA-3 / T2-1 の修正確認 (2026-09-22、2 回目)

対象は作業ツリーの未コミット差分。今回は監査エージェントを使わず、Fable が該当箇所だけを直接読んだ。
アプリは起動しておらず、cargo も実行していない。Codex の記録では全体テストと確認用ビルドは通過している。

| ID | 判定 | 根拠 |
| --- | --- | --- |
| U-1 Esc の戻り先 | **解消** | `resolve_return_to_parent_nav` の先頭に `collection_grid_parent_nav()` の分岐が入り、3 関数が揃った (`src/app.rs:19364, 19400, 19471`)。`open_collection_grid` は旧フルスクリーンを閉じないため、閉じる操作に由来する場合だけ先に閉じる `apply_collection_input_nav(restore, fullscreen_close_origin)` を新設 (`:19525-19533`)。即時経路 (`:19584`) と通常の合流点 (`:75376`) の両方が同じ関数を通り、合流点は `input_nav_from_fullscreen_close` (`:75299`) を入力の裁定まで保持する。BS など全画面に由来しない復帰では閉じない |
| RA-3 表示順と読み順 | **解消** | 列ヘッダの hover に「列ヘッダの順番は一覧の表示と選択だけに使います。ページ送りや連続再生は…」を追加 (`src/ui_main.rs:5616`、テスト `:5657`) |
| T2-1 誤タイムアウト | **解消 (設計変更)** | 利用者の承認により 10 分の期限そのものを廃止。`src/collection_store/read_lease.rs` に期限・予算・期限切れの処理は残っておらず、再試行間隔 50ms → 200ms → 1 秒と、PDF パスワード入力中の一時停止は維持。明示取消・置換・古い応答の不採用は Codex の回帰 16 件で固定 |

### 確認を勧める点 (P2、出荷は止めない)

- **別窓での Esc**: `apply_collection_input_nav` は素の `close_fullscreen()` を呼ぶ。通常フォルダの同じ経路は、閉じる前に
  別窓の動画を昇格し、静止画の別窓を保護する手順を踏む (`src/app.rs:25055-25062` と `take_pending_return_to_parent_nav` の
  フォールバック `:19511-19521`)。F12 別ウィンドウや複数ウィンドウでコレクションの本を Esc で閉じたとき、通常フォルダの
  同じ操作と結果が揃うかを実機で 1 回見ておくとよい。Codex の記録は別 context の回帰を含むとしているが、この手順の差は
  コード上に残っている。
- **期限廃止の代償**: 受理済みの要求に actor が永久に応答しない場合、50ms の完了観測が取消か終了まで続く
  (Codex の記録にも明記)。actor の停止や切断は終端として扱われるので、通常は起きない。コレクションを開いた状態の
  静止時ヘルスチェック (§4 の 2) を出荷前に 1 回測ることを引き続き勧める。
