  findings-11 C3 により、このフラグでログが **256MB × 4 世代** 自動保持される =
  **手動のログ退避は不要**。異常が出たら発生時刻をメモするだけでよい。
- 素材: `H:\home\mimageviewer_detached_smoke_20260630` (フォルダ名に「pinned」を含むものが
  あるが素材自体はそのまま使える)。必要物: 画像フォルダ×2 (アニメ WebP/GIF 含む)、
  複数ページ ZIP×2、複数ページ PDF×2、動画×2 (連続再生確認用に同フォルダへ)、音声×2。
- 異常の報告形式: 「ケース ID + 操作 + 見た目 + 発生時刻」。

## 1. 現行仕様の要点 (チェック時の期待値)

- **ビューワモード** (環境設定 radio):
  - **フル機能ウィンドウ** (以下 OFF): 編集あり。F12 で linked 1 枚だけ別窓化しメインに
    追従。サブ radio「本の表示モード」(ページ一覧 / ページを表示 = 直開き) あり。
  - **複数ウィンドウ** (以下 ON): 開くたび独立した新窓。編集機能なし (案内表示)。
    ZIP/PDF/対応アーカイブは**常に直開き** (保存値がページ一覧でも直開き動作)。
  - どちらのモードでも「画像のみフォルダを本として扱う」checkbox は表示される。
  - モード切替時は開いていた別窓が**全て自動クローズ + トースト** (確認ダイアログなし)。
- **メディア窓は動画/音声共用で常に 1 本** (両モード)。新しい動画/音声を開くと種を
  またいで差し替わる。
- **live-park** (両モード): メディア窓は別窓をアクティブ化しても閉じず再生継続
  (= parked)。parked 中は HUD が減光・操作は inert で、**復帰はクリックのみ**
  (どこをクリックしても復帰、ホイール/キー/Alt+Tab では復帰しない)。× は close。
- **parked の EOF**: 連続再生 ON なら parked のまま次のメディアへ自動進行 / OFF なら停止。
- **ON モードの独立窓**: F12・Ctrl 系フォルダ移動は無効 toast。右クリック短押しで close、
  右ドラッグでリング/ジェスチャ (設定に従う)。

## 4. ログの見方 (異常があったときだけ)

```powershell
$log = "$env:APPDATA\mimageviewer\logs\mimageviewer.log"
Select-String -Path $log -Pattern 'passive_activate|passive_close|active_context_state|session_|host_lost|clear host|allocate_window_id|font_resync|panic|hwnd_adopted|liveness_clear|rejected_default|deferred_registration_delayed|source swap' | Select-Object -Last 250
```

異常の代表シグネチャ (出たら NG として時刻ごと報告):

- `parked_hwnd_liveness_clear` (窓を閉じていないのに出る) = 窓の裏死
- `passive_placement_update_rejected_default` = 既定サイズ再生成
- `hwnd_adopted_watcher` (生きた窓がある状態で出る) = repair 誤採用
- `deferred_registration_delayed` (初回 open 以外で出る) = 直列化スキップ
- `down_window_from_point_mismatch` = stale hwnd 棄却
- `deferred source swap dropped` / `state_transition_unexpected` = parked EOF/セッションの異常
