## やること

### 1. 実体化基盤 (汎用の materializer として切る)

正本 §5 が名指ししている: **「P3 の実体化基盤は、将来ドラッグアウト / OS ファイル
クリップボードの仮想ページ対応にも使える」ので、最初から「外部ツール専用」ではなく
汎用の materializer として切る。**

- ワーカーで実体化する。**UI スレッドで展開 / デコード / エンコード / レンダリングをしない**
  ([ui-responsiveness.md](../ui-responsiveness.md) §4)
- キャンセルトークンを持つ。**古い要求の結果で起動しない** (世代番号。正本 §4.6)
- 出力は正本 §4.3 の表のとおり:

| 対象 | 出力 |
| --- | --- |
| 加工なしの実ファイル | **そのまま渡す (コピーしない)** |
| 加工なしの ZIP エントリ | 元バイト列をそのまま書き出す ([books.rs:916](../../src/books.rs:916) と同じ) |
| 加工ありのページ | 焼き込んで PNG (`CompositeSource` + `BakedEditSnapshot` を再利用) |
| PDF ページ | PNG へレンダリング。**解像度はツールごと (`pdf_render_long_edge`、既定 4096)** |

**`0 = 表示相当` は廃止する** (2026-09-01 決定、正本 §4.3)。設定 UI から選択肢を外し、
保存済みの `0` は **4096 として読む**。`render_page(.., 0, ..)` は実質 1px になるので、
このまま出荷すると「表示相当を選ぶと 1px」という不具合になる。
**viewport を見に行く実装はしない** (歯止めの外へ出る)。

**動画フレームと見開き合成は P4。** この段では作らない。

### 2. 一時ファイルの寿命 (正本 §4.6)

- 置き場所: 通常版 `%TEMP%\mimageviewer\ext-<pid>\`、
  ポータブル版 `<exe_dir>\data\temp\ext-<pid>\`
- ファイル名は**元のエントリ名を維持**。衝突時のみ連番
- 同じ対象の再要求は**再利用** (mtime / サイズで検証)
- **孤児回収は「ディレクトリ名の PID が生きていないものだけ」**。全消しにしない
  (mIV は実際に 2 つ同時に走り得る。理由は正本に記載)
- **所有権**: 渡す前は起動要求が持ち、要求を捨てるときに消す。
  **外部アプリへ渡した瞬間にプロセス単位ディレクトリへ移す。渡した後は消さない**
  (外部アプリが開いている)。終了時に `ext-<pid>` ごと消す。`keep_temp` なら残す
- 掃除はワーカー。**UI スレッドでディレクトリ走査 / 削除をしない**

### 3. `PayloadPolicy` を実際に効かせる

現在この設定は**保存されるだけで起動時に読まれていない**。効かせる。

- `AsDisplayed` (既定): 見た目が変わるかの判定に
  **[`books::page_requires_full_composite()`](../../src/books.rs:305) をそのまま使う。**
  新しい判定を書かない。何も掛かっていなければ元ファイルを渡す
- `Original`: 常に元データ
- `Container`: 書庫 / PDF / 動画本体
- `RealFileOnly`: 実ファイルのときだけ有効

**AI アップスケール結果は焼き込まない** (正本 §6 の決定 4)。

### 4. 編集用ツールのガード (正本 §4.8)

**判定は 2 段構え。**

- **メニューの有効 / 無効**は、項目種別と見開き状態という**同期で分かる情報だけ**で決める。
  **UI スレッドで補正 DB を読まない**
- **最終判定は実体化ワーカーが起動直前に行う。** 元ファイルそのものでなければ
  **spawn せずエラー**
- メニューでは**無効表示 (グレー) + 理由のツールチップ**。§4.9 の「無効なツールは積まない」の
  例外として扱う
- 文面は理由と代替手段まで書く (正本に例あり)

### 5. P2 の暫定制限を外す

正本 §4.5 に「**P2 での混在選択は飛ばすではなく実行しない。P3 でページを実体化できる
ようになったらこの制限は消える**」と書いてある。**実体化できるようになった対象は
拒否をやめて通す。** 併せて次も見直す:

- `LaunchTarget::Virtual` の扱い (実体化できるなら渡せる)
- 右クリックで仮想ページに閲覧ツールを積まない判定
- [item-kind-capability-matrix.md](../item-kind-capability-matrix.md) の
  「拒否 (P3 まで)」と書いたセル

**まだ渡せないもの (動画フレーム / 見開き合成 = P4) は拒否のまま**にし、
理由がそう読めるようにする。

## 品質

- **`cargo fmt` を通す**。UI 文言を足したら `python scripts/check_ui_glyphs.py`
- **実体化の判定 (どの対象がどの出力になるか) と寿命の状態遷移は純関数にして単体テスト**を書く。
  特に: 加工なし実ファイルはコピーしない / 加工なし ZIP は無劣化 / 生きている PID の
  ディレクトリを消さない / 渡した後は消さない / 古い世代の結果で起動しない
- `cargo test -p mimageviewer --lib`。見た目を変えたら `--test ui_snapshot`
- 触った設計ドキュメントを更新する (正本、`docs/spec.md`、必要なら
  `docs/async-architecture.md` と `docs/ui-responsiveness.md`)
