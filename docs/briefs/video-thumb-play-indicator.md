# 動画セルの中央 再生アイコンを、バッジまたは非表示へ切り替えられるようにする

正本は [next-release-backlog.md](../next-release-backlog.md) **§2.11**。着手前に同項を読むこと。

## 1. 要望

専用スレ >>271 (2026-08-20)。動画サムネイル上のアイコンを小さくするか、非表示にしたい。

**§2.11 は「対象が中央の再生アイコンで合っているか」の回答待ちのまま。**
そこで **既定は現在の中央アイコンのまま変えない。**回答が来てから既定を変えるかを
判断できる形にする。これなら回答を待たずに実装しても手戻りが出ない。

## 2. 仕様 (利用者判断、2026-08-22)

**3 択の設定**にする:

| 選択肢 | 表示 |
| --- | --- |
| 再生アイコン (**既定**) | 現在どおりセル中央に `▶` |
| 左下バッジ | 中央には出さず、左下レーンへ ZIP / PDF と同じ形のバッジ |
| なし | どちらも出さない |

## 3. 実装先

### 3.1 中央アイコン

[grid_paint.rs:411](../../src/app/grid_paint.rs:411)。`GridItem::Video` の match アームの**外**で
「常時表示」として描いている (サムネイルが Pending / Failed でも描かれる)。

### 3.2 左下バッジ

[grid_paint.rs:137](../../src/app/grid_paint.rs:137) `bottom_left_content` が
**item 種別 → 左下レーンの内容**を決める純関数で、既に unit test がある。現在:

```rust
GridItem::Video(_) | GridItem::Audio(_) => filename = Some(item_name),
GridItem::ZipFile(_) => { container_kind = Some(Format); container_label = Some("ZIP"); filename = ...; }
```

**動画はレーンが空いている** (ファイル名のみ)。ここへ `BottomContainerKind::Format` を足す。
ZIP / PDF / 対応アーカイブと同じ扱いになり、描画側 `draw_overlay_format_badge` も既存のものを使える。

## 4. ⚠️ 音声には適用しない

同じ「中央のアイコン」に見えるが、意味が違う:

- **動画**: 実サムネイルの**上に重なる overlay**。消しても代表画像が残る。
- **音声**: [grid_paint.rs:414](../../src/app/grid_paint.rs:414) が背景を塗って音楽アイコンを描く。
  波形サムネは生成しないので、**アイコンがセルの中身そのもの**。消すと空の箱になる。

`bottom_left_content` では `Video` と `Audio` が同じアームなので、**分けるときに巻き込まない**こと。
この設定は動画専用。音声用の設定を増やさない。

## 5. バッジの色は、テキスト一致で決めない

[ui_helpers.rs:1144](../../src/ui_helpers.rs:1144) の現状:

```rust
let bg = match placement.text.as_str() {
    "ZIP" => 青, "PDF" => 赤, _ => 橙,   // 橙 = RAR / 7Z / LZH
};
```

**ラベル文字列で色を決めている。**このまま動画を足すと、拡張子ラベル (MP4 / MKV / WEBM …) は
すべて `_` に落ちて**アーカイブと同じ橙**になり、見分けが付かない。

- **動画のバッジはアーカイブと視覚的に区別できること。**
- **色の決定を「拡張子文字列の一覧との一致」にしないこと。**新しい動画形式を足すたびに
  色が静かに変わる/漏れる構造にしない。種別を渡す形にするなど、増える側で壊れない形にする。
- ラベルを拡張子にするか固定文言にするかは選んでよい。**選んだ理由と、色をどう決めたかを報告に書く。**
  ラベル幅は `measure_thumbnail_badge_text` で実測されるので長さの制約は緩い。

## 6. 設定

- 3 値の typed enum。既存の設定と同じく `#[serde(other)]` 相当で未知値を既定へ正規化する
  (前例: `FsSidePanelMode` / `SortOrder`)。
- 設定 UI は一覧・サムネイル表示まわりの既存ページへ置く。**どこへ置いたかを報告に書く。**
- 文言に実装語を出さない (CLAUDE.md「マニュアル・製品ページの記述方針」)。
  「overlay」「バッジレーン」等を UI に出さない。

## 7. 制約

- **既定を変えない** (= 再生アイコン)。§1 のとおり対象確認待ちのため。
- 音声セルの見た目を変えない (§4)。
- ZIP / PDF / 対応アーカイブの既存バッジの見た目を変えない。
- 中央アイコンとバッジの**両方を同時に出さない** (3 択であって組み合わせではない)。
- 「なし」でもサムネイル生成中の中央「動画」プレースホルダ
  ([grid_paint.rs:400](../../src/app/grid_paint.rs:400)) は残す (読み込み中の手がかり)。
  変える必要があると判断したら、変える前に報告する。

## 8. テスト

`bottom_left_content` は純関数なので、そこで固定できる:

- 3 値それぞれで、中央アイコンとバッジの有無が期待どおりになること (排他)。
- **音声は 3 値のどれでも見た目が変わらないこと。**
- ZIP / PDF / 対応アーカイブのバッジが 3 値のどれでも変わらないこと (**回帰**)。
- 既定値が現在の表示と同一であること (**回帰**)。
- 未知値が既定へ正規化されること。
- UI スナップショット (§2.11 が列挙している組み合わせ): 通常動画、代表画像あり / なし、
  選択 / hover、狭いセル、形式 / 評価 / タグ バッジとの重なり。
  設定ページのスナップショットも 1 枚。
