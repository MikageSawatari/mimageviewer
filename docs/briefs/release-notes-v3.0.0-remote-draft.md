### v3.0.0 (YYYY-MM-DD)

- **外出先から、自宅 PC のライブラリを見られるようになりました。** 自宅の PC で mImageViewer を起動したままにしておくと、外出先のスマートフォン・タブレット・ノート PC のブラウザから同じライブラリを開けます。画像も、漫画（ZIP / PDF）も、動画も、手元の端末にコピーせずそのまま見られます。既定ではオフです。
  - 画面はスマートフォンでの操作を前提にしています。左右のタップでページ送り、中央のタップで上下バーの表示切り替え、上へスワイプでメニュー、下へスワイプで一覧、ピンチで拡大です。初回に操作の説明を表示します。
  - 見開き表示、ページ位置の指定、明るさなどの画像補正、カラー化、AI（拡大・ノイズ除去）、ポストフィルタ、表示トリムを、本体と同じように操作できます。レーティング・ブックマーク・読んだ位置・見開き設定・補正は**自宅 PC 側に記録される**ので、帰宅後は続きから読めます。
  - 動画と音声は、自宅 PC 側で変換しながら配信します。画質を選べます。ZIP / PDF に加えて RAR / 7z / LZH も開けます。
  - 接続には Tailscale と PIN の**両方**が必要です。mImageViewer 自身はインターネットに出ず、自宅 PC の中だけで待ち受けます。Tailscale に参加していない端末からは、URL を知っていても届きません。
  - ホーム画面に登録すると、次からアイコンを押すだけでアプリのように開けます。手順は[マニュアル](https://mikage.to/mimageviewer/manual/tut-remote.html)にあります。
  - ファイルの操作（コピー・移動・削除・名前の変更）、タグの付け外し、画像の編集はできません。同時に操作できるのは常に 1 台です。
  - 有効にすると、**すべてのドライブについて、mImageViewer で表示できるファイルが閲覧できるようになります。**自分が管理している端末からだけお使いください。詳しくは[マニュアル](https://mikage.to/mimageviewer/manual/tut-remote.html)をご覧ください。
