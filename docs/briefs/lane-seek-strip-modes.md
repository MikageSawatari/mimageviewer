### 何を作るか

現行の「再生位置を中央に固定して周辺を流す表示」は残したまま、**動画全体を横幅へ収めた
ストリップ**も選べるようにする。全体表示ではサムネイル / 波形を動かさず、現在位置を示す
赤線が左から右へ移動する。

表示モードは 4 組み合わせ + 非表示:

1. サムネイル × 周辺表示 (現行)
2. サムネイル × 全体表示
3. 音声波形 × 周辺表示 (現行)
4. 音声波形 × 全体表示
5. 非表示

高さは **大 (現行) / 中 / 小 (約 48 logical pt)** の 3 段階。egui は論理座標なので設定名に
px を出さず「大 / 中 / 小」とする。中の具体値は実機レイアウトを見て決める。

### 利用者の用途 (確認済み)

精密なフレーム選択ではなく、**高さ 32〜48px 程度の小さなサムネイルで場面や明るさの
大まかな違いを把握すること**。粗い時間間隔で問題ないとの回答を得ている。
S キーの動画タイル一覧は「別画面へ切り替えず動画を見ながら全体を把握したい」を満たさないため、
ストリップ側へ足す。

### 操作

- `Shift+S` は既定で「非表示 → サムネイル周辺 → サムネイル全体 → 波形周辺 → 波形全体」を循環。
- 右下のストリップボタンは見開き設定と同様のメニューを開き、非表示と 4 モードを直接選べる。
  高さも同じメニューかサブメニューから。
- 環境設定で **4 モードそれぞれを Shift+S の循環に含めるか**を選べる。これは機能自体の非表示
  設定にはしない。循環から外したモードも右下メニューからは直接選べ、**設定次第で到達不能に
  ならない**ようにする。全解除は許可しないか、読み込み時にサムネイル周辺だけを有効へ正規化する。

### 実装上の不変条件

- 現在は `SEEK_STRIP_HEIGHT` を前提に、ロック時の動画表示領域・strip rect・hover / hit-test・
  サイドパネル判定を複数箇所で算出している。**定数の局所置換で済ませない。** 選択済みの高さを
  **1 つの layout snapshot で解決**し、描画・入力・動画の予約領域が同じ値を見る。
  中心は `src/video/native_presenter/render_core.rs` の `VideoVisualLayout` と HUD ロック。
- 全体サムネイルはアスペクト比を維持し、指定高さからセル幅を決める。利用可能幅に収まる枚数を
  算出して先頭から末尾までを等間隔に採る。横スクロールさせず、セル間に不自然な空白を作らない。
  **正確な任意フレームを同期デコードしない** — 既存の近傍フレーム / キャッシュ / worker で
  段階的に埋める。
- 全体波形は動画全体を横幅へ写像する。長時間動画でも UI thread で全解析を待たず、既存の粗い
  波形データを使って段階表示する (§1.152 の永続キャッシュは未実装。**このレーンの前提にしない**)。
- 赤線は `current_time / duration` を左右端へ写像する。**長さ不明・0・ライブ相当では全体表示を
  成立させず周辺表示へフォールバック**する。

### テスト

- ロックあり / なし、HUD 表示 / 非表示、フルスクリーン / native presenter、
  DPI 100 / 125 / 150%、縦長 / 横長動画で、ストリップと映像・ボタン・hit-test がずれないこと。
- 4 モードと非表示の循環、無効化したモードの skip、右下メニューから全モードへ直接到達、
  全解除設定の正規化。
- 全体表示の先頭 / 中央 / 末尾で赤線が左右端 / 中央へ一致し、リサイズ後もアスペクト比と
  等間隔の時刻サンプリングを保つこと。デコード待ちで UI を止めないこと。

## 共有登録簿 — A が着地するまで触らない ⚠️ このレーンは直撃する

レーン A (`external-tool-launch` worktree、右クリックメニューと外部ツール起動) が、
以下を全面的に書き換えている。**先に触ると解決不能なコンフリクトになる。**

| 場所 | このレーンでの用途 |
| --- | --- |
| `src/settings.rs` / `src/settings_db.rs` | `video_seek_strip_state` の拡張、循環対象の設定 |
| `src/keymap.rs` / `docs/keymap.ini.default` | `Shift+S` の循環変更 |
| `src/ui_dialogs/preferences/pages.rs` | 環境設定 (動画タブ) の項目追加 |
| `src/ui_dialogs/context_menu.rs` (+`context_menu_model.rs`) | 通常は不要 |

**進め方**: 先に「モードと高さを 1 つの snapshot で解決する内部構造 + 描画 + hit-test +
テスト」を作り込み、**設定 / キー / 環境設定の配線を最後の 1 コミットにまとめる**。
A が着地したらそのコミットだけを載せ直す形にすれば、機械的な解決で済む。
それまでは既定値をコード内の定数として持ち、永続化しない状態で動かしてよい。

## 進め方

- 修正前に、観測された失敗・守るべき不変条件・違反を作った経路を特定する。症状を消す
  guard / delay / retry を根本原因の代わりに置かない。
- キー操作の追加・変更は原則 `KeyAction` + keymap helper 経由
  ([keymap-spec.md](../keymap-spec.md))。固定扱いにするなら理由を同ドキュメントへ残す。
- 実装を Codex へ出すなら**出す前にコミットする**。**1 worktree につき Codex は 1 本まで。**
- コミット前に `cargo fmt` (引数なし・ワークスペース全体)。
- テストは `cargo test -p mimageviewer --lib <filter>` で最小に。
