## 1. AI の「使いません」通知が消えない (利用者報告、実機)

大きい PDF を読んでいると、画面下に

> AI が無効か、元画像が設定された処理サイズ上限の対象外です

が **出たまま消えず、読書の邪魔になる。**

### 原因 (特定済み。ここは再確認しなくてよい)

`RemoteAiController.applyReady` ([app.js:6818](../../crates/remote-web/web/app.js)) で、
成功時と不成立時の扱いが揃っていない。

- 成功: `this.show("AI 処理が完了しました。", { cancellable: false, hideAfterMs: 2400 })`
  → **2.4 秒で消える**
- 不成立 (`ready` が 0 件): `this.show(details.join(" / ") || "…", { cancellable: false })`
  → **`hideAfterMs` が無く、出たまま残る** ([app.js:6828](../../crates/remote-web/web/app.js))

`displayGroup` はページを表示するたび呼ばれる ([app.js:3318](../../crates/remote-web/web/app.js))
ので、サイズ上限を超えた本では **全ページで出続ける**。

### 直し方

**「消えない」ことだけを直すのか、そもそも出すべきかを判断して報告してほしい。**
私は後者に寄っていて、理由は:

- この通知は利用者が AI を要求した結果ではなく、**ページを開くたび自動で走る処理**の副産物
- 「この画像では AI を使わない」は失敗ではなく通常の結果
- 一方で、AI を期待している利用者に何も出ないのも不親切かもしれない

**判断して、選んだ理由と一緒に報告してほしい。** 出すなら成功時と同じく自動で消す、
出さないなら本当に黙って良いのか (利用者が「効いていない」と誤解しないか) を書くこと。

**成功時とサイズ上限時で扱いが分かれている理由が他にあるなら、それも報告を。**

## 2. RTL の本でシークバーの塗りが左右逆 (利用者報告、実機)

右→左綴じの本を読むとき、**下のシークバーの青く塗られる部分が逆**になっている。

### 原因 (特定済み。ここは再確認しなくてよい)

シークバーは `<input type="range">` + `accent-color`
([styles.css の `.viewer-seek-input`](../../crates/remote-web/web/styles.css))。

`viewerSeekState` ([command-core.mjs](../../crates/remote-web/web/command-core.mjs)) は
RTL のとき **value を反転**している:

```js
value: rtl ? groups.length - 1 - groupIndex : groupIndex,
```

つまみの位置はこれで正しくなる (RTL の 1 ページ目 = 右端)。しかし
`accent-color` は **トラックの左端からつまみまで**を塗るので、RTL の読み始めでは
つまみが右端 → **トラック全体が青**になり、「ほぼ読み終わった」ように見える。

`setSeekState` ([app.js:7098](../../crates/remote-web/web/app.js)) は
`min` / `max` / `value` だけを設定し、向きに関する指定はしていない。

### 直し方

**つまみの位置・塗りの向き・ドラッグの向きの 3 つが同時に揃う形にしてほしい。**
今は 1 つ目だけ合っていて 2 つ目が合っていない。片方だけ足して 3 つ目がずれる、
という直し方をしないこと。

候補は思いつく範囲で 2 つあるが、**どちらが良いか、他に良い形があるかを判断して
報告してほしい**:

- 要素ごと `transform: scaleX(-1)` で反転する。value の反転は不要になる
- `direction: rtl` を input に付ける。value の反転は不要になる

**実機は iPhone / Android のモバイルブラウザ**なので、どちらを採るにしても
**そのブラウザで range input に効く方法か**を確認して報告してほしい (私は確認できない)。

`viewerSeekState` / `viewerSeekGroupIndex` の RTL 引数を外すなら、
**呼び出し側とテストも揃えること** ([command-core.test.mjs](../../crates/remote-web/web/command-core.test.mjs))。

## 3. 受け入れ条件

- 大きい PDF を数ページめくっても、AI の通知が画面に残り続けない

- LTR の本が退行していない (つまみ位置・塗り・ドラッグとも)
- **回帰テスト**を付ける。特に RTL / LTR の value 対応は純関数テストで固定できるはず
- web テストが緑。Rust 側に触るなら該当テストも
