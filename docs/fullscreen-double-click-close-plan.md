# 閲覧中の左クリック: 「単クリックで送らず、ダブルクリックで閉じる」モード (§1.471)

- 状態: **設計第 1 版 (2026-11-23)、独立設計レビュー前、利用者判断待ち**。対象 v5.7.0 (間に合わなければ次)。
- 要望: 5ch >>639・>>882。ViX のように「サムネイルをダブルクリックで開き、画像をダブルクリックで一覧へ戻る」。
- 利用者決定 (2026-11-23、統括経由): 「単クリックでページ送り (従来、既定)」と「単クリックでは送らず、ダブルクリックで閉じる」を選択式にする。後者では、先に送って巻き戻す処理や、従来モードへのクリック遅延を入れない。任意のコマンドを割り当てる汎用機能にはしない。
- 関連: [キー仕様](keymap-spec.md) の「マウス左クリック」行、[ナビゲーション仕様](fullscreen-navigation-consistency.md)、[リング / マウス操作計画](ring-shortcut-plan.md)、[detached リワーク計画](detached-rework-plan.md) (凍結の決まり)。

## 1. 現状 (コード参照)

- 閲覧中のキャンバスの左クリックは `src/ui_fullscreen.rs::plan_fs_canvas_click` が 1 つの `FsCanvasClickAction` に分類する。
  - 動かしていない通常の静止画: 単クリック → `PageSide` (左右半分でページ送り)。
  - 動かした表示 (ズーム・パン・回転、`fs_view_has_moved`): 単クリックは何もしない、ダブルクリック → `ResetTransform`。
  - 動かしていない表示のダブルクリック: 2 回の単クリックとしてページを 2 回送る (マニュアルどおり)。
  - 動画: 単クリック → `ToggleVideo` (egui 経路のときだけ。native presenter は自前で処理)。
  - その他: overflow (HUD「…」) が開いていれば `DismissOverflow`、各種 popup・連結読み・サイドパネルのクリック領域・シークパネル上は何もしない。編集モード・分析モード・360 度 (panorama) は最初に除外 (`None`)。3D (Depth) は Ctrl+クリックで `DepthFocusAt`、それ以外はページ送り。
- ダブルクリックの判定は `FsFrontPointerOwnership::backing_double_clicked`。egui のクリック回数を、**キャンバスが受け付けたクリックの数** (`FsBackingClickBoundary::current_accepted`) で頭打ちにする。これにより、一覧のダブルクリックで開いた直後の 2 回目のクリックや、HUD・メニューが持っていったクリックは、キャンバスのダブルクリックに数えない。フォーカス復帰直後のクリックは `primary_suppression` が止める。
- 閉じる経路: 右クリック短押しの「フルスクリーンを閉じる」は `FsWheelFrameResult.close` → `close_fs` → 既存の閉じる処理 (`handle_fullscreen_close_request` 系) を通る。F12 別ウィンドウ・複数窓・ブラウザから開いた窓・ZIP / PDF の一覧への戻り先は、すべてこの処理が決める。

## 2. 方針

1. 設定を 1 つ足す: `fullscreen_primary_click: FullscreenPrimaryClickMode { PageTurn (既定), DoubleClickClose }`。全体で 1 つ。本ごと・窓ごとにはしない。
2. `FsCanvasClickAction` に `CloseViewer` を 1 つ足す。`DoubleClickClose` のときだけ `plan_fs_canvas_click` が返す。
3. `CloseViewer` は右クリック短押しの閉じると同じく `close = true` に合流させる。閉じた後の行き先・別ウィンドウの畳み方は既存の閉じる処理に任せ、新しい経路を作らない。
4. `DoubleClickClose` では単クリックは何もしない (`PageSide` を作らない)。従来モードのコードは一切変えない (遅延なし)。
5. 状態を増やさない。例外は §4.3 の「1 回目のクリックが空振りだったか」の 1 ビットで、これは既存の `FsBackingClickBoundary` (クリック回数の頭打ち) と同じ寿命・同じ持ち主に置く。

## 3. 設定と選ぶ場所

- 型: `FullscreenPrimaryClickMode`、保存値 `"page_turn"` / `"double_click_close"`、既定 `PageTurn`。§1.772 の `page_turn_animation_style` と同じ形で、settings_kv の 1 キー、未知の値は既存の非互換の扱い (旧版は未知のキーを読まない)。**未リリースの新規キーなので移行は不要**。設定の書き出し・取り込み (`settings_transfer`、stage1 の分類) と環境設定のスナップショットにも同じ形で登録する。
- 選ぶ場所 (推奨): 環境設定 → 操作カスタマイズ → 設定 → **「マウスボタン」タブの先頭**に「閲覧中の左クリック」の 2 択ラジオを置く。
  - 「クリックでページを送る (既定)」
  - 「クリックでは送らず、ダブルクリックで閉じる」
  - 説明 (1 行): 「画像の閲覧中に適用します。動画・編集中・360 度表示のクリックは変わりません。」
  - 理由: >>640 で代替として案内した「マウスボタンに『画像フルスクリーンを閉じる』を割り当てる」と同じ画面で、マウスで閉じる方法がまとまる。
- 代案: 「右ドラッグ・右クリック」タブを「マウスのクリック・ドラッグ」に改め、右クリック短押しの隣に左クリックの行を足す / 表示 → 閲覧表示に置く。
- HUD・キーには出さない (常時切り替える性質の設定ではない)。`KeyAction` も足さない (固定入力の扱いを keymap-spec に書く)。

## 4. 新モードの挙動

### 4.1 単クリック

- キャンバスの単クリックは何もしない。ページ送り・巻き戻し・遅延は無い。
- ほかのクリック用途は今のまま: HUD「…」を閉じるクリック (`DismissOverflow`)、popup を閉じるクリック、サイドパネルの細いバー、シークパネル、ナビゲーター、3D の Ctrl+クリック (`DepthFocusAt`)。

### 4.2 ダブルクリックと ResetTransform の優先 (利用者判断 Q2)

- 推奨 (案 A): **動かした表示ではダブルクリックは今までどおり「表示を戻す」、動かしていない表示では「閉じる」**。判定は今の `can_reset` (通常の静止画は `fs_view_has_moved`、それ以外は変形の有無) をそのまま使い、`can_reset` が真なら `ResetTransform`、偽なら `CloseViewer`。
  - 拡大して見ていたページは、ダブルクリック 1 回目で元に戻り、もう 1 回で閉じる。今の「ダブルクリックで表示を戻す」を新モードでも失わない。
  - 帰結: 縦に長いページを幅合わせで表示してスクロールした後 (パンが自動配置と違う) も「動かした表示」なので、1 回目は表示を戻す。「読み始め」の自動配置だけのページは動かしていない扱い (今のクリック送りと同じ)。
- 案 B: ダブルクリックは常に閉じる。表示を戻すのはキー・メニューだけになり、新モードではマウスで表示を戻せなくなる。
- 連結読み: 今は単クリックで送らず、変形があればダブルクリックでリセット。新モードでは変形が無ければダブルクリックで閉じる (案 A と同じ規則)。連結のスクロール位置は変形に数えない (今のリセット判定と同じ)。

### 4.3 「1 回目が空振りだったか」の確認 (新しく足す唯一の状態)

今のダブルクリック判定は、キャンバスが受け付けたクリックなら用途を問わず数える。そのため新モードで次が起きる:

- HUD「…」が開いているときの 1 回目のクリックは `DismissOverflow` でパネルを閉じる。2 回目は overflow が閉じているので、そのままだと `CloseViewer` になり、**パネルを閉じるつもりのダブルクリックで閲覧まで閉じる**。
- popup・サイドパネルのバー・シークパネル・3D の Ctrl+クリックの直後のクリックも同様。

対策: `FsBackingClickBoundary` に「直前に受け付けたクリックが、新モードで何もしなかったキャンバスのクリック (以下『空振り』) だったか」を 1 ビット持つ。`CloseViewer` は **今回のクリックも空振りの条件を満たし、かつ直前に受け付けたクリックが空振りだった** ときだけ返す。条件を満たさなければ `None`。
- 寿命・持ち主: `current_accepted` と同じ。新しいクリック列・前面 UI の持っていったクリック・フォーカス喪失で一緒に消える。別のビューポート・別の viewer context に持ち越さない (既存の `viewport` 照合をそのまま使う)。
- ResetTransform は今の挙動を変えない (このビットを見ない)。従来モードでは計算しても使わない。
- 代案 (状態を足さない): 用途のある 1 回目のクリックで `FsBackingClickBoundary` を初期化し、次のクリックを 1 回目に数え直す。従来モードの ResetTransform の判定も変わる (HUD を閉じた直後のクリックで表示が戻らなくなる) ため、推奨しない。

### 4.4 開いたダブルクリックの持ち越し

- 一覧のダブルクリックで開いたとき、その 2 回目のクリックはキャンバスが受け付けていないので、受け付け数は 1 で頭打ちになり閉じない (既存の仕組み)。テストで固定する。
- 閉じた後: 閉じた 2 回目の離しは閉じたフレームで消費される。続けて 3 回目を押した場合の一覧側の扱いは今の一覧のクリック処理のまま (今回は変えない)。「選択済み項目をもう一度クリックすると開く」(既定 OFF) を ON にしていて、3 回目のクリックがその項目の上に落ちると開き直すことはあり得る。三連打の稀な操作なので割り切る。

### 4.5 対象外 (今のまま) — 利用者判断 Q3

| 場面 | 新モードでの扱い (推奨) | 理由 |
| --- | --- | --- |
| 動画 (native presenter / egui の動画) | 変えない。単クリック = 再生・一時停止 | 要望は画像。動画のクリックはページ送りではない |
| 動画→音声モード・音楽表示 | 変えない | 同上 |
| 編集モード (補正・消しゴム等の overlay 編集)・分析モード | 変えない (クリックは編集に使う) | 既存の除外 (`None`) のまま |
| 360 度 (panorama) | 変えない (ドラッグで視点、クリックは何もしない) | 既存の除外のまま |
| 3D (Depth) | Ctrl+クリックは今のまま。Ctrl なしの単クリックは送らず、ダブルクリックは閉じる | Depth は 2D の変形を止めているので、リセットはしない (今と同じ)。ほかは静止画と同じ規則 |
| HUD・上部バー・メニュー・ナビゲーター・サイドパネル・シークパネル | 変えない。そこでのダブルクリックで閉じない | §4.3 |
| ページ一覧 (overview)・類似プレビュー | 変えない | 別の面の入力 |
| タッチのタップ | マウスと同じ規則 (単タップで送らない、ダブルタップで閉じる) | egui はタップを左クリックとして渡す。機器で分けると状態が増える。選んだ人だけの設定 |
| キー・ホイール・マウスの戻る/進む/ホイールクリック・ゲームパッド・右クリック | 変えない | 要望の範囲外 |
| mIV Remote (Web UI) | 変えない | 自前のタップ処理。本体の設定は渡らない |

### 4.6 F12・複数窓・戻り先 — 利用者判断 Q4

- 推奨: **右クリック短押しの「閉じる」・Esc と同じ戻り先**。既存の閉じる処理にそのまま合流させる。
  - 通常の閲覧: 一覧へ戻る (ZIP / PDF の中なら今の規則どおりページ一覧または親フォルダ)。
  - F12 の別ウィンドウ・複数窓: その窓の閲覧を閉じる (別ウィンドウは閉じる)。ほかの窓は変わらない。
  - ブラウザから開いた窓: 右クリック短押しの閉じると同じ。
- detached の述語・viewport 経路・窓ごとの描画には触れない。クリックの分類 (`plan_fs_canvas_click`) と、その結果を既存の `close` に合流させるだけなので、凍結の決まりの「detached 周りへの症状パッチ」には当たらない。変更範囲を [detached-rework-plan.md](detached-rework-plan.md) に 1 行で記録する。

## 5. 実装の範囲 (Codex への指示の骨子)

1. `src/settings.rs`: `FullscreenPrimaryClickMode` と `fullscreen_primary_click` フィールド (既定 `PageTurn`)、serde、スナップショット。`settings_db.rs` の kv、`settings_transfer.rs` と `settings_transfer/stage1.rs` への登録 (§1.772 の `page_turn_animation_style` と同じ箇所)。
2. `src/ui_fullscreen.rs`:
   - `FsCanvasClickAction::CloseViewer` を足す。
   - `plan_fs_canvas_click`: `DoubleClickClose` のとき、`PageSide` を作る位置で `None` を返し、空振りのクリックだったことを記録する。ダブルクリックは §4.2・§4.3 の規則で `ResetTransform` / `CloseViewer` / `None`。動画・除外モード・popup・overflow・chrome の分岐は今の順のまま。
   - `FsBackingClickBoundary` に空振りの 1 ビット (`previous` と `current` の組で、`current_accepted` と同時に更新・初期化)。
   - 即時経路と合成経路 (`apply_fs_wheel_frame_proposal`) の両方で `CloseViewer` → `close = true`。合成経路の `suppress_intermediate_navigation` に `CloseViewer` も含める (閉じるフレームでホイールのページ送りを先に行わない)。
   - perf の `bump_input_seq` は既存の `fs_close_click` に乗る。
3. 環境設定 (`src/ui_dialogs/preferences/pages.rs` の `page_mouse_buttons`): §3 のラジオ。
4. テスト (§7)。UI スナップショット (マウスボタンのタブ) を更新・追加。
5. 文書: `docs/keymap-spec.md` の「マウス左クリック」行に新モードを追記 (固定入力で `KeyAction` を足さない理由も)、`docs/fullscreen-navigation-consistency.md`、マニュアル (`manual/fullscreen.html` のクリック・ダブルクリックの行、`manual/settings.html` のマウスボタン)、`docs/detached-rework-plan.md` に触れた範囲の 1 行。

## 6. 状態の組み合わせを減らした点 (CLAUDE.md の簡素化の方針)

- 新しい状態機械・待ち時間・巻き戻しを作らない。単クリックは何もしないだけ。
- 閉じた後の行き先を作らない。既存の閉じる処理 1 つに合流させる (F12・複数窓・ZIP / PDF の分岐を新モード専用に持たない)。
- 機器 (マウス / タッチ) で分けない。動画・編集・360 は今の除外の分岐を使い、新しい分岐を足さない。
- 足す状態は §4.3 の 1 ビットだけで、既存のクリック回数の持ち主に同居させる。代案 (状態を足さない) は従来モードの挙動を変えるので採らなかった。
- まれな失敗は割り切り (この機能に保存の失敗の特別な扱いは無い。設定の保存は既存の経路)。

## 7. テスト

- 設定: 既定 `PageTurn`、保存値の往復、未知の値の扱い、スナップショット・書き出しの往復 (§1.772 と同じ形)。
- `plan_fs_canvas_click` の handler テスト (新モード):
  - 動かしていない静止画の単クリック → `None` (左右どちらでも)。ダブルクリック → `CloseViewer`。
  - 動かした表示のダブルクリック → `ResetTransform` (案 A)、続くダブルクリック → `CloseViewer`。
  - HUD「…」が開いている状態の 1 回目 (`DismissOverflow`) + 2 回目 → 閉じない。popup / サイドパネルのバー / シークパネル / 3D Ctrl+クリックの直後も同じ。
  - 一覧のダブルクリックで開いた直後の 2 回目のクリック (受け付け数 1) → 閉じない。
  - フォーカス復帰で止めたクリックの次 → 閉じない。
  - 編集モード・分析モード・360 度・動画 → 今と同じ結果。
  - 連結読み: 変形なしのダブルクリック → `CloseViewer`、変形ありは `ResetTransform`。
  - 3D: Ctrl なしのダブルクリック → `CloseViewer`、Ctrl+クリックは `DepthFocusAt`。
- 従来モード: 既存テストがそのまま通ること (挙動不変)。
- 閉じる合流: 新モードのダブルクリックが `FsWheelFrameResult.close` を立て、同じフレームのホイールのページ送りが先に適用されないこと (合成経路)。
- 窓: 別ウィンドウの viewer context でのダブルクリックがその窓だけを閉じ、ほかの context の状態を変えない (既存の右クリック閉じるのテストと同じ形)。
- UI スナップショット: マウスボタンのタブ (既定・新モード選択)。
