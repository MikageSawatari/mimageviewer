## 1. 絶対に守ること

1. **合成する RGBA に枠を入れない**（D1）。枠は egui の painter でプレビュー画像の上に重ねる表示物。
   プレビュー worker・`render_frame`・書き出しは変更しない。無変調の書き出しハッシュは不変。
2. **枠の幾何は `musicvideo-core` の `evaluate` と同じ評価を通す**。キーフレーム（`Animatable` の評価）・
   変調（`ModulationBinding` の Scale / Rotation など、`scene.rs` の binding 適用）・回転を、枠のために別に
   書き直さない。評価の共通部分を関数に切り出し、`evaluate` と枠計算の両方がそれを呼ぶ形にする
   （`evaluate` の結果は不変であることをテストで固定）。
3. **表示中のフレームと同じ時刻・同じ変調値で評価する**。プレビュー結果（ラボ `app.rs` の `PreviewResult`）は
   現在、そのフレームの時刻を持っていない。時刻を持たせ、テクスチャを差し替えたときに「表示中フレームの時刻と
   変調値」を一緒に更新する。再生位置（`position_secs`）で評価すると、再生中に枠が絵より先へ進む。
   プレビューがまだ無いときは枠を描かない。
4. `musicvideo-ui` は egui と core 系クレートだけに依存（eframe / cpal / ffmpeg を入れない）。
5. `src/`（本体）・`comic-core`・`music-core` を触らない。アプリを起動しない。コミットしない。`cargo fmt` を通す。

## 2. 表示の仕様

| 状態 | 表示 |
| --- | --- |
| 画面内 | レイヤーの矩形（回転していれば回転した四角形）を、どの背景でも見えるよう 2 色（例: 黒の太線の上に白の細線）で描く。左上付近にレイヤー名 |
| 一部が画面外 | プレビュー画像の外側（中央パネルの黒い余白）まではみ出して描いてよい。中央パネルの外へは出さない（clip） |
| 全体が画面外 | 枠の代わりに、プレビュー画像の縁に、レイヤーがある方向を示す印とレイヤー名・「画面外」を出す |
| 非表示（その時刻で `visible = false`、または opacity が 0） | 破線の枠と「非表示」の表示。位置は通常どおり評価した矩形 |
| 未選択 / プレビュー未準備 | 何も描かない |

- 枠の表示の ON/OFF をプレビューの近く（ツールバーかプレビュー上）に置く。既定 ON。状態は `EditorState` の
  UI 状態で、Undo 対象にもプロジェクト保存にも入れない。
- 枠は**レイヤーの矩形**（`rect`）を示す。グローのはみ出しや、円形スペクトラムが矩形より外へ描く部分は
  対象外（ユーザー要望は「レイヤーの box」）。
- 枠のクリックやドラッグによる移動・選択は**作らない**（今回は表示だけ）。

プレビュー画像の表示矩形と正規化座標の対応は、`draw_preview` の中で 1 か所で決める（画像を置いた矩形から
枠の座標を計算する。別の場所で縮尺を再計算しない）。

## 3. テスト

1. 枠の幾何の純関数テスト: Const の矩形、キーフレームで動く矩形（キー間の時刻）、Scale 変調あり、
   回転あり、全体が画面外、一部が画面外、visible = false の時刻、opacity 0。
2. **`evaluate` との一致**: 同じ Project・時刻・変調値で、`evaluate` が出す `SceneItem` の rect / rotation と
   枠の幾何が一致する（評価の共通化が崩れたら落ちる）。
3. 無変調プロジェクトの書き出し（または `render_frame`）のハッシュが変更前と同じ。
4. 表示中フレームの時刻で評価されること: プレビュー結果の時刻が再生位置と違う状況で、枠が結果の時刻の
   位置になる（ラボ側のテスト）。
5. 各テストについて、わざと壊したら落ちることを確かめる（例: 再生位置で評価する、変調を無視する）。
