## 決まり
- mIV は、依頼で指定されたビルドを、依頼で指定された `--data-dir` (テスト用の使い捨てフォルダ) を付けてだけ起動します。インストール済みの mImageViewer と `%APPDATA%\mimageviewer` は起動・変更しません。
- **`--data-dir` を付けても、本棚の場所は分かれません**。本棚の場所の既定は利用者のピクチャ (`OneDrive\画像\mimageviewer\books` など) で、本へ追加・製本・本の構成の編集をすると、利用者の実際の本棚フォルダへ書き込みます (依頼 32 で試験画像 2 枚が書き込まれた、2026-11-11)。本を扱う操作をする前に、環境設定で本棚の場所を `C:\miv-test-v5\` の下の試験用フォルダへ変えます。依頼文に書かれていなくても、本棚へ書き込む操作の前には必ず確かめます。ほかにも、データフォルダの外の場所 (整理先・書き出し先・外部ツールなど) へ書き込む設定は、試験用の場所を指定してから使います。
- mIV の起動は、指定された exe のフルパスを PowerShell の `Start-Process` で行います。画面操作ツールの `open_application` は使いません (インストール版が起動し、`%APPDATA%` を更新したことがある)。前面化はウィンドウのクリックで行います。
- **mIV と Claude アプリは別の仮想デスクトップに置きます (毎回必須、依頼 8 でサブ PC の利用者と決めた方法)**。Claude アプリは一方のデスクトップに置いたまま、mIV はもう一方のデスクトップで起動・操作します。切り替えは `C:\miv-test-v5\vdswitch.ps1` (Win+Ctrl+← / → のキー送信) で行います。起動の前に、今いるデスクトップに Claude アプリの窓が無いことを確かめ、起動後も mIV の窓が Claude アプリと別のデスクトップにあることを確かめてから操作します。同じデスクトップに出てしまったら、操作を始める前に分け直します。依頼文に書かれていなくても、この手順は省きません (依頼 25 で抜けて、同じデスクトップで作業していたと利用者が指摘、2026-11-09)。どちらのデスクトップを使ったかを結果に書きます。
- 仮想デスクトップを使えないときだけ、次の方法で代えます。画面操作中は、この Claude アプリの窓が画面の端の小さなパネルになって最前面に残ります。このパネルはスクリーンショットに写りませんが、クリックは受け取ります。重なりはスクリーンショットでは確かめられないので、最初のスクリーンショットの後に次で確かめます (mIV の PID を渡す)。
  `powershell -NoProfile -ExecutionPolicy Bypass -File \\tsclient\C\home\mimageviewer\scripts\subpc-claude-panel.ps1 -Mode Info -ProcessId <PID>`
  `OVERLAP` と出たら `-Mode Place` で mIV の窓をパネルの横の空き領域へ移し、もう一度 `-Mode Info` で確かめます。全画面表示のテストのように移せない場合は、パネルに隠れる範囲を操作せず、確かめられなかったこととして報告します。Claude アプリの窓は最小化しません (操作のたびに前に戻ります)。
- 作業を終えた後も Claude アプリの窓が最前面に固定されたままなら、`-Mode Unpin` で固定だけを外します (Claude アプリの不具合への対処。他のアプリの窓には使いません)。
- 終わったら、自分で起動した mIV だけを終了します。他のアプリ、システム設定、セキュリティ設定は変えません。
- 画面全体へ送るキー入力 (特に Esc) は使いません。キー入力は、対象の窓が前面にあることを確かめてから送ります。
- インターネットからのダウンロードや、アカウント・パスワードの入力はしません。必要になったら利用者に頼んでください。
- 報告では、自分で見たこと・ログから読んだこと・確かめていないことを分けて書きます。スクリーンショットやログは、依頼で指定された場所に保存します。
