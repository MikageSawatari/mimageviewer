この版の変更点の要約です。すべての変更点は[更新履歴](https://mikage.to/mimageviewer/manual/changelog.html)をご覧ください。

### 主な新機能

- **ブラウザで見ている画像を、mIV の窓で開けるようになりました。** Chrome ウェブストアで拡張機能「mIV で見る」を公開しました。拡張機能を入れ、環境設定 → 起動と連携 → ブラウザ連携の「ブラウザ連携を使う」をオンにすると（既定はオフ）、画像を右クリックして「mIV で見る」で開けます。Edge 用は公開準備中です。保存先のフォルダは、いつも単ページで開きます。
- **本のサムネイルの右下に、ページ数を表示するようにしました。** ZIP・PDF・EPUB・画像だけのフォルダ・RAR などに「123P」の形で表示します。環境設定 → 表示 → サムネイルで切り替えられ、既定はオンです。
- **本をページ数で並べ替えられるようになりました。** 普通のフォルダのソートで「ページ数（少ない順）」「ページ数（多い順）」を選べます。長さ順と同じく、並びは自動では変わりません。
- **3D 写真の表示中に、動きを続けたまま拡大・縮小・パン・回転できるようになりました。** 倍率・位置・角度は通常の表示と共通です。
- **閲覧中に画像をダブルクリックして、閲覧を閉じて一覧へ戻れるようにしました。** 「設定」→「操作カスタマイズ…」の「マウスボタン」タブで「クリックでは送らず、ダブルクリックで閉じる」にすると使えます。既定はこれまでどおりクリックでページを送ります。
- **ページめくりアニメーションの動きを「めくる」と「スライド」から選べるようになりました。** 環境設定 → 表示 → 閲覧表示で選びます（既定は「めくる」）。
- **ツールバーに「ドライブ:」欄を表示できるようになりました。** ボタンを押すと、そのドライブで最後に開いていた場所へ戻ります。ツールバーの空き領域を右クリックして表示します。ドライブを切り替える操作カスタマイズのキーも同じ処理になり、一覧が切り替わるのが少し（数フレーム）遅れます。
- **一覧に並んだフォルダへも、ファイルやフォルダをドラッグして移動・コピーできるようになりました。** ドラッグ中は、落とし先のフォルダに枠と「(フォルダ名) へコピー」を表示します。
- **AI 連携で、AI アプリが mIV の使い方を説明したり、環境設定の確認と変更を任せたりできるようになりました。** どちらも「設定」→「AI 連携…」でオンにします（既定はオフ）。使うには、更新した後に AI アプリを再起動するか、MCP に再接続してください。

### その他の改善

- 一覧でフォルダのセルの背景に色を付けられるようにしました（環境設定 → 表示 → サムネイル、既定はオフ）。
- 「編集内容の復元」の確認の説明に、本の読書位置・見開きなど、引き継ぐ内容を加えました。

### 主な不具合の修正

- 「編集内容の復元」で引き継いだ本や、mIV で名前を変えた・移動した本を開くと、続きではなく 1 ページ目から開く問題を修正しました。
- ZIP や PDF を一度開いたフォルダを mIV で移動・名前の変更・削除すると、「使用中」で中断することがある問題を修正しました。
- 初めて起動した回の mIV で mIV Remote を使うと、見開きや回転などが Remote に反映されないことがある問題を修正しました。
- 動画のフルスクリーンで、長い通知が約 2 秒で消えて読み切れない問題を修正しました。
- ツールバーの 2 行目以降の空き領域で、右クリックのメニューが出なかった問題を修正しました。
- スタック表示のスクリプトで、まとめ表示の計算が終わらなくなることがある問題を修正しました。
- 設定を変えた後などに、詳細表示や選択情報のページ数が古い数のまま残ることがある問題を修正しました。
