# ブリーフ: 見開きで比較するとクラッシュする (wgpu Out of Memory)

対象: v2.13.0 出荷ブロッカー (クラッシュ)。実装 = Codex Sol /
レビュー・検収 = ClaudeCode / 実機確認 = 利用者。

前提: master (`d99c20f7` 以降)。着手前に `git log --oneline -3` を確認すること。

---

## 1. 事実 (実機 2026-08-10、後続調査で訂正)

見開き表示で `Shift+C` の比較中にページを前後移動すると**アプリがクラッシュ**する。

```
2026-08-10 11:13:28  PANIC at wgpu-27.0.1 ...: wgpu error: Out of Memory
```

同セッションの `[compare-geometry]` ログの合成キャンバス:

```
target=3584x4608  1596 フレーム   ← 単ページ
target=7680x4608   434 フレーム   ← 見開き
target=8320x7296     2 フレーム   ← 見開き (60.7 メガピクセル)
```

パニック表示は `Out of Memory` だったが、`8320` は egui-wgpu の device descriptor とアプリ共通の
`MAX_TEXTURE_DIM=8192` を超えている。利用者環境は RAM 128GB / VRAM 24GB でもあり、後続判断では
メモリ不足という読みを第一原因とせず、**texture dimension violation を真因として扱う**。

8320×7296 の RGBA は **1 枚 243MB**。修正前の`ComparePreparedPair` は
`pinned_rgba` / `current_rgba` / `diff_rgba` の **3 枚 (729MB)** を CPU に持ち、GPU 側にも
pinned / current を**完全な mip chain 付き**で持つ (合計 ~646MB)。ページ移動のたびに新しい
ペアを作る経路には、**前のペアが解放される前に次を確保できる無駄**もあった。これは上限違反と
独立した問題なので、原因の読み直し後も削減を維持する。

**今日入れた変更が原因ではない。** 見開き + 大きな画像 + 比較という条件で以前から起きえた。

## 2. やること (この順で。品質を落とすのは最後)

### 2.1 まず実際の確保量を計測する

ペアを作るときに、**CPU バッファと GPU テクスチャそれぞれの合計バイト数**をログへ 1 行出す
(`target`、mip 込みか否か、旧ペア解放の前か後か が分かる形)。以降の判断はこの数字で行う。

### 2.2 無駄を削る (画質を落とさずに済む可能性が高い)

1. **`diff_rgba` / diff テクスチャを、Diff モードのとき以外は作らない。**
   Wipe / PinnedNormal で使っていないなら、それだけで 1/3 減る
2. **新しいペアを準備する前に、前のペアの CPU バッファと GPU テクスチャを解放する。**
   ピーク時に 2 組を同時に持たない。GPU 側は `clear_gpu_pair` 相当が既にあるはず
3. mip chain が本当に必要か確認する。比較の描画は等倍〜縮小なので、
   **不要なら生成しない** (VRAM が 1/1.33 になる)

**この確保量削減はdimension上限対策と独立した純粋な改善として維持する。**

### 2.3 見開き全体と画面上の中央 gap を再現する (利用者判断更新 2026-08-10)

利用者判断:「見開きのどちらのページを選ぶか、といった操作を追加するのが大変そうなので、
いったん結合で比較としたい」。

- 現在ページ1枚へ縮退せず、左右ページを見開き全体として結合する
- 画面で見えていた中央gapを、実描画された左右ページ幅に対する同じ比率で黒く合成する
- gapを含む合成を先に完了し、その後で必要な寸法調整を行う

### 2.4 device と同じ 8192 上限へ、合成後の全体を収める

8192 は任意の品質制限ではなくdeviceのtexture上限である。合成後キャンバスが一辺でも超える場合は
全体を等比縮小し、比較準備を継続する。`8320x7296`は`8192x7184`。8192以内は変更しない。
texture作成直前にも同じ上限guardをbackstopとして残す。

## 3. やらないこと

  絵が出ない状態になるだけ

  (CLAUDE.md / 利用者方針: 設定だけで決まる決定的な動作を優先する)
