# 実装ブリーフ: 先頭・末尾の案内と、処理状況 / 先読み状況を隠せるようにする (backlog §1.89)

対象: v3.0.1 (明日夕方リリース予定)。背景は `docs/next-release-backlog.md` の §1.89。

## 1. 要望

5ch 専用スレ >>222 / >>225 (2026-08-15)。

1. ページ送りの先頭・末尾で出る「最初の項目です」「最後の項目です」が**目立つので消したい**。
2. 先読み状況の表示も**消したい**。

利用者と相談して決めた方針 (2026-08-15):

- 文言の「項目」は内部語の直訳で、ビューア上の案内として抽象的。**「先頭です」「末尾です」へ変更**する。
- 状況表示は **「そのページの内容に影響するか」で 2 つに分ける**。編集や AI の適用中に無表示だと、
  見た目が大きく変わった理由が分からなくなるため、まとめて 1 つのスイッチにはしない。

## 2. いま出ているもの (調査済みの事実)

フルスクリーンの「読込中」系は 4 か所あり、条件が違う。

| | 表示 | 位置 | 条件 | 実装 |
| --- | --- | --- | --- | --- |
| ① | 「読込中...」24pt + パス | 画面中央 | そのページに描けるテクスチャが無い | `ui_fullscreen.rs:23012` |
| ② | 「高解像度 読込中...」14pt 半透明 | 画像の左上 | `is_loading && has_any_tex && !fs_pending` | `ui_fullscreen.rs:13449` |
| ③ | 「読込中...」/「PDF 再レンダリング中...」13pt | 画像矩形の左下 | `fs_pending.contains_key(fs_idx)` | `ui_fullscreen.rs:13462` |
| ④ | 枠付きステータスボックス | 画面の左下 | 同上 ＋ **AI 有効時のみ描画** | `ui_fullscreen.rs:28665` |

**④ は `ai_upscale_enabled || ai_denoise_model.is_some()` のときだけ呼ばれる**
(`ui_fullscreen.rs:13963`)。AI 無効なら箱ごと出ない。ボックスの中身は
読込中 / AI 処理中 / AI 先読み中 / AI 処理完了 / 消去補完済み ＋ 先読み進捗バー。

境界案内は 2 実装ある。

- 静止画 / 本: `ui_fullscreen.rs:29125` の `draw_boundary_hint` (画面中央、数秒で消える)
- native 動画: `native_video.rs:8175` の `native_boundary_hint_text` (オーバーレイトースト)

## 3. やること

### 3.1 文言を変える

「最初の項目です」→ **「先頭です」**、「最後の項目です」→ **「末尾です」**。
静止画 / 本 (`ui_fullscreen.rs:29156` / `29160`) と native 動画 (`native_video.rs:8179` / `8181`)
の**両方**を変える。副文 (`[Home] 最初に戻る` 等) はそのままでよい。

**動画のシーク境界 (`native_video.rs:8161` / `8162`) の「動画先頭です」「動画末尾です」は変えない。**
「動画」が付いていることで、ファイル境界の案内と区別できる。ここを裸の「先頭です」にすると
2 つの意味が同じ文になるので、変更対象から外す。

同種の案内 (「次のフォルダに画像・動画が見つかりません」等) の文言は今回触らない。

### 3.2 設定を 3 つ足す

環境設定「表示 → 閲覧表示」(`PreferencesPage::SpreadMode`、`pages.rs:7159` の
`page_spread_mode`) に追加する。**3 つとも既定 ON** (現行利用者の表示を勝手に変えない)。

| 設定 | OFF で消えるもの |
| --- | --- |
| 先頭 / 末尾の案内を表示 | §3.1 の境界案内 (静止画 / 本 / native 動画とも) |
| 処理状況を表示 | ② / ③ / ④ の「読込中...」「AI 処理中」「AI 処理完了」「消去補完済み」 |
| 先読み状況を表示 | ④ の「AI 先読み中」と先読み進捗バー |

**① (画面中央の「読込中...」) はどの設定でも消さない。** これは状況表示ではなく、
「このページはまだ見られない」という事実そのもので、消すと真っ黒な画面の理由が分からなくなる。

両方 OFF なら ④ のボックス自体が出ない。`draw_fs_ai_status` は
`lines.is_empty() && prefetch_progress.is_none()` で早期 return するので、
行を積まないだけで自然にそうなる。**この早期 return を壊さないこと。**

### 3.3 守ること

- **OFF は表示だけを止める。** ページ移動、境界判定、先読み処理、AI 処理そのものには影響させない。
  `fs_boundary_hint` の設定・クリアや、先読みキューの動作を設定で分岐させない。
  描画側だけで判断する。
- 静止画 / 本 / detached / native 動画で、同じ設定が同じ意味になること。
- 設定名は利用者の言葉にする。「そのページの内容に影響するかどうか」で分けたので、
  必要ならツールチップか補足行で一言添えてよい (実装語は出さない)。

## 4. テスト

- 追加した設定の既定値と、保存 → 読み込みの往復。
- 表示可否を決める箇所は**純関数に切り出して**単体テストする
  (例: 設定 2 つと各状態から、ボックスに積む行と進捗バーの有無が決まること)。
  既存の `remote_enable_warning_visible` のような一行 helper + テストの形が house style。
- 文言変更のテスト (静止画と native 動画で同じ文言になること)。
- 環境設定の検索索引に新しい項目が載ること (既存の索引テストがあれば倣う)。
- 実行: `cargo test -p mimageviewer --lib ui_fullscreen::`、
  `cargo test -p mimageviewer --lib settings`、`cargo test -p mimageviewer --lib ui_dialogs::`。
- 見た目を変えるので `cargo test --test ui_snapshot`。差分が出たら
  `docs/ui-snapshot-policy.md` の手順で更新し、PNG を目視してからコミットする。
- `cargo fmt --all` と `python scripts/check_ui_glyphs.py`。

## 5. ドキュメント

- `docs/spec.md` — 設定項目を追記。
- `htdocs/mimageviewer/manual/` — 環境設定のページ (表示 → 閲覧表示) と、
  フルスクリーン表示を説明しているページ。**既定は ON** であることと、
  OFF にしても動作そのものは変わらないことを書く。実装語・バージョン番号は書かない。

## 6. 対象外

- ① (画面中央の「読込中...」) を設定対象にすること。
- ③ と ④ が AI 有効時に重複して「読込中...」を出す既存の重なり。**今回は直さない**
  (利用者と別途判断する)。設定でまとめて消える側なので、今回の変更で悪化はしない。
- 境界案内の表示時間・位置・副文の変更。
- 「次のフォルダに画像・動画が見つかりません」等、他の案内の文言。
