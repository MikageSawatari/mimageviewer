## 2. 書くもの

1. **マニュアルの新しいページ** `htdocs/mimageviewer/manual/music-video.html`（既存の通常ページと同じレイアウト・サイドバー）:
   - 何ができるか（音声から MP4 の音楽ビデオを作る別のエディタ。画像・スペクトラム・鍵盤・文字・歌詞・進捗などのレイヤー、
     音に反応するモジュレータ、キーフレーム）。
   - 起動のしかた（音声ファイルの右クリック・音楽ビューの右クリックから「音楽ビデオを作成」）。
   - 画面の構成と基本の操作（レイヤー一覧・プロパティ・モジュレータ・プロジェクト設定・タイムライン・プレビュー・再生）。
     実装の画面・ラベルの文言をコードから確かめて、その名前で書く。
   - プロジェクトの保存と開く（`.mivmv.json`、最近使ったプロジェクト、未保存の確認）。
   - MP4 の書き出し（既定の出力 1920x1080 / 60fps、エンコーダとビットレート、進捗と中止、書き出し中は他の操作をしないこと、
     既存のファイルを上書きするときの確認）。
   - キー操作（エディタの固定ショートカット。コードから一覧を取り、カスタマイズはできないと書く）。
   - 注意（歌詞の LRC の読み書き、素材ファイルが見つからないときの表示など、実装にある範囲だけ）。
   内部用語（FFmpeg 以外のライブラリ名・worker・タイムライン key・チェックポイント 等）とバージョン表記は書かない
   （CLAUDE.md の置き換え表に従う）。性能の数字を約束として書かない。

   `python scripts/gen-changelog-html.py` で再生成する（手で編集しない）。マニュアルの目次 `index.html` にも載せる。

   （プロジェクト・MP4・LRC）、data dir の `musicvideo/recent-projects.json`（最近使ったプロジェクトのパス）と
   `logs/musicvideo.log` / `logs/musicvideo-panic.log`、編集の一時データ（OS の一時領域）。両方の記述を突き合わせ、
   全称・否定の表現（「〜だけ」「〜はありません」）が今も正しいか確かめる。
