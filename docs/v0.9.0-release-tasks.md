# v0.9.0 リリース修正タスク一覧 (統合版)

`docs/v0.9.0-release-review.md` (Claude) と `docs/release-review-v0.9.0.md` (Codex) を
マージした punch list。P3 まで全件修正してからリリースする方針。

## 進行プロセス (各タスク共通)

1. **再検証**: タスク内容が現 HEAD で有効か Read/Grep で確認 (レビュー後に修正済みの可能性あり)
2. **設計**: 修正方針を本ファイルの該当タスク欄に追記
3. **設計レビュー**: `codex exec --sandbox read-only -o ...` で設計の第二意見
4. **実装**: 変更を入れて `cargo fmt` / `cargo build` / 該当テスト
5. **実装レビュー**: `codex exec --sandbox read-only -o ...` でコミット範囲レビュー、P 指摘対応

各タスクの完了マーク (`[x]`) は **実装レビュー** まで通過した時点で付ける。

## ステータス凡例

- 出典: `[C]` = Claude review, `[X]` = Codex review, `[C+X]` = 両者
- 検証: `[検証済]` = レビュー時に失敗経路確認済 / `[要検証]` = 追加確認必要
- 種別: `[Security]` / `[Data]` / `[Stability]` / `[Compat]` / `[Release]` / `[UX]` / `[Refactor]`
