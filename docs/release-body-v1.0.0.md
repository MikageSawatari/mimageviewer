## mImageViewer v1.0.0

最初の正式版です。画像・動画・PDF・ZIP をまたいで快適に閲覧できるよう、表示・検索・編集の各機能を大きく拡充しました。

このリリースノートは要点をまとめた短縮版です。全項目は README の更新履歴を参照してください: https://github.com/MikageSawatari/mimageviewer#更新履歴

## 主な新機能

- **隠蔽加工モード (Ctrl+M)**: モザイク・白塗り・黒塗り・ぼかしを非破壊で重ねられます。筆や囲みのビットマップ下地に、直線・矩形・楕円などの後編集できるオブジェクトを作成順に重ね、タイル サイズ・不透明度・ぼかし強度などをプリセット 1〜4 に保存できます。隠蔽内容は元画像とは別に保存されるため、元画像には一切手を加えません。
- **エクスポート (Ctrl+E)**: 補正・AI アップスケール / ノイズ除去・消しゴム補完・隠蔽加工・ポストフィルタを反映した画像を JPEG / PNG / WebP で別ファイルに保存できます。EXIF・XMP などのメタデータは可能な限り保持。隠蔽プリセット 1〜4 をまとめて書き出すバリエーション一括出力にも対応します。
- **360 度パノラマビュー**: equirectangular 形式のパノラマ画像を V キーで視点を動かして閲覧できます。ドラッグで見回し、ホイールで画角調整、ダブルクリックで初期視点に復帰。視点が落ち着くと高解像度版を再描画して画質を引き上げます。
- **画像・動画のウィンドウ内表示モード**: モニター全面の「全画面表示」と、ウィンドウ内に収める「ウィンドウ内表示」を切り替えられます。上部ホバーバーのボタンや F11 キーでいつでも変更でき、動画再生中に切り替えても音声・再生位置はそのまま引き継がれます。選んだモードは記憶されます。
- **動画ブックマークの一括登録**: 動画の説明欄やコメント欄に書かれたチャプター一覧（`hh:mm:ss タイトル` 形式）を、左ジャンプパネルの一括登録ボタンから貼り付けるだけでまとめてブックマーク化できます。markdown リンク形式や箇条書き記号も自動で取り除かれ、既存ブックマークと重複する行は自動的にスキップされます。
- **ファイルのドラッグ＆ドロップ**: サムネイルをエクスプローラーや他アプリへドラッグしてコピー。逆にエクスプローラーから mImageViewer へドロップすると表示中のフォルダへコピーします。

## 検索の再設計

- **コンテナ検索 (Ctrl+S) / アイテム検索 (Ctrl+G) / 現在地フィルタ (Ctrl+F)** の役割を整理しました。Ctrl+S はフォルダ・ZIP・PDF を探し、Ctrl+G は画像・PDF・動画を 1 件ずつ探し、Ctrl+F は今見ている場所を絞ります。
- Ctrl+S に「種別 (フォルダ / ZIP / PDF)」絞り込みを追加。Ctrl+G は結果を「一覧」「集約」で切り替え可能になり、動画にもサムネイルが表示されます。Ctrl+F / Ctrl+G にタグ ピッカーを追加しました。
- 検索結果の右クリックから「フォルダに移動」でグリッドを開けます。検索中のフォルダ移動は履歴から分離され、検索を抜けると元の状態に完全復帰します。

## 表示・パフォーマンス

- **PDF を開く速度を大幅改善**: 一度サムネイル表示またはオープンした PDF はページ数を記憶し、2 回目以降の Enter はほぼ瞬時にページ一覧を表示。レンダリング ワーカーを 5 プロセスに増強し、うち 1 つを優先操作用に予約。Ctrl+↑↓ ナビでは前後 1 件分を先読みします。PDF が多数あるフォルダのスクロール応答性も改善しました。
- **JPEG サムネイル生成を 2.5〜6 倍に高速化**: 大判カメラ JPEG を、表示に必要な解像度に合わせてデコード時点で縮小処理することで高速化しました。
- **サムネイル形状のフォルダ別自動調整**: ツールバーの「自動」で、フォルダ内の画像の縦横比に応じてサムネイルの形を自動調整します。判定結果はキャッシュ管理からリセットできます。
- **動画フルスクリーン HUD を 2 段構造に刷新**: 上段にフル幅シークバー、下段に再生・音量・マーカー / 項目移動・キャプチャ パレットを配置。狭いウィンドウでは左側ほど残す優先順位で省略します。Space キーで再生 / 一時停止できるようになりました。
- **消しゴム ツールのパネル UI を全面改善**: プレビュー表示・ベクター マスクのアウトライン・矩形 / 楕円ツール追加など操作性を向上しました。
- 更新通知ダイアログを見出し・箇条書きなどの書式付きで表示。ウィンドウの最小サイズを設定。選択中アイテムをフルパスで表示。

## 主なバグ修正

- 動画フルスクリーン表示のちらつき、動画切替時に HUD が他アプリを覆う問題を修正。
- 暗号化 PDF のスクロール時にパスワード要求の試行が繰り返される問題を修正。
- 検索結果を「新しい順 / 古い順」でソートした際の UI フリーズ (ネットワーク共有上) を修正。
- ドラッグ＆ドロップ コピーの失敗を通知するように改善。
- 消しゴムツールを Esc で抜けるときも AI 補完を実行してから終了するように変更。
- フルスクリーン中の F / Home / End / F1〜F6 キーが反応しないことがある問題を修正。
- グリッドのバッジ・ファイル名プレートの上端切れ、フォルダ再読み込み後のサムネイル更新漏れを修正。
