# ブリーフ: Phase 3 Step 2d — 一度しか出ない案内には、方向が変わっても正しい文言を書く

対象: v2.13.0 タッチ対応 Phase 3。実装 = Codex Sol / レビュー・検収 = ClaudeCode /
実機確認 = 利用者。

正本: [docs/touch-support-plan.md](touch-support-plan.md) §5「発見可能性をどう担保するか」。

前提 (コミット済み、`2b3b8030` まで): Step 2c で初回案内とコンテキストヘルプの左右を
`spread_mode.is_rtl()` で「前のページ」/「次のページ」に解決した。
**この Step は、そのうち初回案内側の判断を訂正する。**

---

## 1. Step 2c の何が間違っていたか

利用者報告 (2026-08-09、Step 2c の実機確認):

> LTR ファイルで右タップを次のページと認識した後に、RTL ファイルを開いたら
> **ヘルプと動作が逆になります**。併記がだめなら、
> **「左のページ」「右のページ」と書くのが正しい**はずです。

**学習フラグ (`touch_still_chrome_learned`) はグローバルなのに、読み方向はファイルごとに違う。**

初回案内は一度学習したら二度と出ない。したがって LTR の本で学習した利用者は、
その後 RTL の本を開いても再教育されず、**覚えた対応が逆のまま残る**。
「現在の読み方向で解決する」という Step 2c の判断は、**一度しか出ない画面では原理的に
半分の場合で外れる**。方向を正しく解決したこと自体は問題ではなく、
*方向に依存する文言を、方向が変わっても再表示されない場所に置いたこと*が誤りだった。

## 2. 直し方 — 初回案内は方向不変の文言にする

初回オーバーレイの左右ラベルを **「左のページへ」/「右のページへ」** にする。

これは**どちらの読み方向でも正しい**:

- LTR の本では、前のページが物理的に左にある。左タップ = 前 = 左のページ
- RTL の本では、次のページが物理的に左にある。左タップ = 次 = 左のページ
- つまり `fullscreen_click_nav_delta_for_side` は、**どちらの方向でも
  「タップした側にあるページへ動く」**。ラベルはその不変量をそのまま書く

したがって:

- **初回オーバーレイの描画から読み方向の依存を外す**。Step 2c で
  `paint_still_touch_first_run_help_overlay` に足した rtl 引数と、呼び出し元 2 か所からの
  受け渡しを**戻す** (fixture も含む)
- 外向き矢印 (◀ / ▶) はそのまま。「こちら側」を示す役割と文言が一致する
- **RTL 用スナップショット (`still_touch_first_run_help_unlearned_100_rtl_dark.png`) は削除する**。
  オーバーレイが方向に依存しなくなるので、LTR と同一画像を 2 枚持つことになる

## 3. コンテキストヘルプは方向解決のまま残す

`?` の `HelpShowContextShortcuts` は **Step 2c のまま**にする (「前のページへ移動する」/
「次のページへ移動する」を `spread_mode.is_rtl()` で解決)。**ここは変更しないこと。**

理由: コンテキストヘルプは**開いているファイルに対して何度でも開ける**ので、
陳腐化しない。むしろ「この本ではどちらが次か」を答えられるのが利点である。

役割分担を明示する:

| | 役割 | 文言 |
| --- | --- | --- |
| 初回オーバーレイ | **不変の対応を教える** (一度きり) | 左のページへ / 右のページへ |
| コンテキストヘルプ | **いまの対応を答える** (随時) | 前のページへ移動する / 次のページへ移動する |

## 4. マニュアル

`htdocs/mimageviewer/manual/fullscreen.html` の Step 2c での記述を、この役割分担に
合わせて整合させる。マニュアルはページとして随時読めるので、読み方向で意味が変わることを
説明してよい (バージョン表記を書かない / 内部用語を書かない)。

## 5. テスト

- 初回オーバーレイのラベルが**読み方向に依存しない**ことを固定する。
  Step 2c で足した方向別のラベル解決テストは、この不変量のテストに**置き換える**
- ラベルが中央矩形に潜り込まないこと (幅 480 / 800 / 1200 / 3840) は**維持**する。
  「左のページへ」は Step 2c の「次のページ」より長い
- コンテキストヘルプの LTR / RTL テストは**そのまま維持**する
