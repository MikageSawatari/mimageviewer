# P2 修正 (10 件) 実機確認チェックリスト

対象バイナリ: `target\release\mimageviewer.exe` (build-release.ps1 生成)。
各項目は「修正前の症状が出ないこと」の確認。所要 15〜20 分想定。

## 高優先 (構造を変えた修正)

### P2-8/9: ロード複合体の bundle 化 (最重要 — 回帰確認)
1. **重複デコード churn の解消**: 動画/音声を F12 別ウィンドウで再生したまま (または
   ZIP/PDF を別ウィンドウで開いたまま)、メイン窓で大きめのフォルダ (数百枚) を高速
   スクロール → サムネの出方が「detached 窓なし」のときと同等か。CPU 使用率が異常に
   張り付かないか。
2. **動画サムネ生存**: 動画が数本入ったフォルダをメイン窓で表示 (動画サムネが出る前に) →
   すぐ「ZIP または PDF を別ウィンドウで開く」→ メイン窓に戻り、**動画サムネが最終的に
   全部出る**こと (修正前はフォルダ再読込まで永久に出ない)。
3. **回帰確認 (通常フロー)**: detached を使わない普通のフォルダ閲覧・Ctrl+↑↓ 連打・
   Ctrl+G 検索・フォルダ切替でサムネが正常に出ること (bundle 化でロード基盤を触った
   ため、ここの無事が最重要)。
4. **parked live 再activate**: 動画を別ウィンドウ再生 → メイン窓クリック (park) →
   別ウィンドウをクリックして再activate → グリッド/再生が正常継続。

### P2-2: グリッド削除×別窓再生
5. 動画 (または音声) を別ウィンドウで再生しながら、メイン窓グリッドで**無関係な
   ファイル数枚を削除** → 再生が止まらないこと。削除後にメイン窓のサムネ・選択位置が
   正常なこと。
6. (可能なら) フルスクリーンで画像を見ている最中に、事前に始めた削除が完了するケース →
   表示中の画像がズレないこと。視聴中ファイル自体を削除 → 次のファイルに送られること。

## 中優先 (音声モード / 音楽ビュー)

### P2-3: parked 音楽×画像閲覧
7. 音楽を別ウィンドウ (メディア窓) で再生 → メイン窓で画像を次々開く (ページ送り) →
   **別窓のタイムライン/スペクトラムが消えたりリセットされたりしない**こと
   (修正前: 開くたびに「解析中…」に戻り、長尺ではスペクトラムが数十秒空白)。
   CPU も張り付かないこと。

### P2-1: 音声モード exit×EOF (レース、確率的)
8. 連続再生 ON で動画を音声モードにし、曲の終わり際 (残り 1-2 秒) に「動画へ戻る」
   ボタンを押す → 何回か試して、押下が無視されて次曲が音声モードで始まる事象が
   出ないこと。

### P2-5 / P2-10: 音楽ビューの入力
9. 音声ファイルをフルスクリーン再生 → リングショートカット (または右ドラッグ/
   ゲームパッド) の「ウィンドウ/全画面切替」→ F11 と同じく切り替わること (修正前: 無反応)。
10. 音声ファイルの音楽ビューで Z を押してから ↑↓ で画像へ移動 → 画像が勝手に
    ズームモードにならないこと。

### P2-4: タイムライン再ラスタ (確率的、観察のみ)
11. 長め (10 分超) の音声を開いてタイムラインが行ごとに埋まっていく様子を確認 →
    後半の行が空白のまま固着しないこと (数曲切り替えて観察)。

## 低優先 (エンジン、機会があれば)

### P2-6: 極短音声

    `ffmpeg -f lavfi -i sine=d=0.05 short.wav` 相当を用意) を開く → 「準備中」のまま
    固まらず再生されること (即 EOF でも可)。

### P2-7: SeekCompleted 喪失 (再現困難、観察のみ)
13. 通常のシーク操作が従来どおり動くことだけ確認 (重い操作中のシークで「シーク中」
    固着が出たら報告)。

## 追加 (レビューで判明した未検証組合せ、P2-11)

    ♪ ボタン → 音楽ビューになる → 「動画へ戻る」→ 正常復帰。F11 (borderless) も試す。

## 判断待ちだった P2 の修正分 (2026-07-09 最終便)
18. **KeyHold のテンキー割当**: 操作カスタマイズで「全画面ズームモード」(既定 Z) を
    NumpadEnter またはテンキーの数字に割り当て → hold で照準が出て、離すとズームすること。
    逆に上段数字キーでは発火しないこと (見開き切替 1-5 が普通に効くこと)。

    (削除確認等) を開いて閉じる → スティックを倒し続けてもページ移動などが暴発しない
    こと。一度ニュートラルに戻すと通常操作が復帰すること。
20. **極短音声の末尾**: (機会があれば) 数百 ms の短い音声で、波形の末尾が欠けずに
    描かれること。
21. **detached HWND fallback**: 通常の F12 / 別ウィンドウ操作が従来どおり動くこと
    (可視性フィルタ追加の回帰確認。特別な操作は不要、既存項目 1〜4 と併せて)。

## 実機検証 3 連発の修正分 + §1.7 (2026-07-09 深夜)

22. **クリック照準 (重なった parked 窓)**: 複数の窓 (画像 2 枚 + PDF 2 冊など) を
    カスケードで重ねて全部 park → **最前面の窓の、背面窓と重なっている領域**をクリック →
    1 クリックで最前面の窓がアクティブ化すること (修正前: 重なり領域のクリックが無反応で、
    重なっていない端をクリックしたときだけ復帰)。前面/背面を入れ替えて数回。
23. **stale window_id 再利用 (d6bf04f0) の再確認**: 動画を別窓再生 → メイン窓で操作して
    park → 画像を開く → 動画窓と画像窓が同じ窓を取り合って点滅しないこと。
24. **ゴースト連動セッション (5c9be17d) の再確認**: parked 動画/音声窓をクリックで
    再activate → メイン窓でフォルダ移動 → 再生中の窓に別画像が焼き付いて凍結しないこと。
25. **連動 park 画像窓の復帰フォールバック**: フル機能モード + F12 で画像を別窓表示 →
    メイン窓でフォルダ移動 (窓が parked still 化) → **さらに別のフォルダへ移動してから**
    parked 窓をクリック → 親フォルダが窓内に読み込まれて同じ画像で復帰すること
    (修正前: クリック無反応)。復帰後の窓内で ←→ ページ送りができること。
26. **タグトースト二重表示**: detached 動画窓の右パネルでタグを付与 → トーストが
    動画窓にだけ出て、メイン窓グリッドに出ないこと。逆にグリッドでタグ付与 →
    グリッドにだけ出て動画窓に出ないこと (修正前: 両方に出た)。
27. **グリッドタグの誤爆解消**: detached 窓 (画像でも動画でも) を開いたまま、メイン窓
    グリッドで**別のアイテム**を選択してタグ付与 (メニュー/T キー/ツールバー) →
    タグが**グリッドで選択したアイテム**に付くこと (修正前: detached 窓のアイテムに付いた)。

### §1.7 フル機能モード + メディア別窓 (新機能 smoke)

28. **設定 UI**: 環境設定 → 全般 → ビューワモード → フル機能側に
    「動画・音声は別ウィンドウで再生」checkbox が出ること。複数ウィンドウモード選択中は
    グレーアウト。ON/OFF を切り替えて OK → 開いていた別ウィンドウが閉じてトーストが出ること。
29. **基本フロー**: フル機能モード + checkbox ON でグリッドから動画をダブルクリック →
    メディア窓で再生開始。メイン窓グリッドはそのまま操作でき、画像を開くと**メイン窓の
    フルスクリーン**で表示され、動画は別窓で再生継続 (live-park)。音声ファイルでも同様。
30. **F12 トグル**: メディア窓の動画で F12 → メイン窓フルスクリーンに戻る。もう一度
    F12 → メディア窓へ戻る。画像の F12 は従来どおり (連動別ウィンドウのトグル)。
31. **カーソル非追従**: メディア窓で再生中にメイン窓グリッドのカーソルを動かす
    (クリック/矢印キー) → メディア窓の再生内容が変わらないこと。
32. **メディア窓 1 本規則**: メディア窓再生中に別の動画/音声をグリッドから開く →
    新しいメディアが同じ窓 (または新窓 1 本) で再生され、旧メディア窓が残骸として
    残らないこと。
33. **checkbox OFF の回帰**: checkbox OFF (既定) では従来のフル機能挙動
    (動画はメイン窓フルスクリーン、F12 で連動別ウィンドウ) が変わらないこと。
34. **メディア窓からのフォルダナビ consume (audit P1 修正)**: §1.7 checkbox ON で動画を
    メディア窓再生中、メディア窓にフォーカスして Ctrl+↑↓ → メイン窓のフォルダが
    移動せず、メディア窓の再生も止まらないこと。
35. **音声×フォルダ移動の温存 (audit P2 修正)**: 音声をメディア窓で再生中 (§1.7 ON
    または複数ウィンドウモード)、メイン窓でフォルダ移動 → 音声再生が止まらず
    メディア窓が live-park で残ること (修正前: 音声だけ再生ごと閉じた)。
36. **グリッド Delete キー (監査修正)**: detached 窓 (画像/動画どれでも) を開いたまま、
    メイン窓グリッドでファイルを選択して Delete キー → 削除確認が出ること
    (修正前: 無反応。右クリック削除だけ効いた)。
37. **★固定×parked 窓復帰 (レビュー P2 修正)**: ★固定 (スナップショット) 中に、
    範囲外フォルダの画像の parked 窓をクリック → 「復帰できません」トーストが出て
    **窓が parked のまま残る**こと (窓が消えないこと)。★固定を解除すると復帰できること。
