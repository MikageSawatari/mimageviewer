## 7. ファイル操作 × 複数ウィンドウ (2026-07-10 角度④修正の確認)

40. **再生中ファイルの削除**: 動画/音声をメディア窓 (または parked) で再生したまま、
    メイングリッドからそのファイルを削除 → 窓が閉じて削除が成功する
    (以前は decoder が掴んでいて削除失敗が繰り返された)。
    2026-07-10 実機: H: の動画で「削除に失敗しました (Shell 操作が中断)」×2 を検出 →
    修正済み (Sol 実装: 窓 close 後の decoder teardown が非同期で IFileOperation が
    ロック中 abort する競合 → 削除 worker 内で abort/共有違反系のみ 200ms×5 回
    リトライ、失敗分のみ再投入・キャンセル 20ms 応答)。**再確認**: 同じ手順で
    1 回の削除操作で成功すること。
41. **別窓表示中のファイルのリネーム**: 画像を別窓 (parked) で表示したまま
    メイングリッドでリネーム → 窓が閉じる。リネーム後のファイルを開き直せる。
    2026-07-10 実機: 「ファイルが消えた」報告は拡張子を消してリネームしたことによる
    もの (一覧は認識拡張子のみ表示) と確定。ファイル実体は無事。
41b. **リネームの拡張子保護 (Explorer 方式)** (2026-07-10 追加、Sol 実装): ファイルの
    リネームダイアログを開くと**拡張子を除いた部分だけが初期選択**され、そのまま
    入力しても拡張子が残る。拡張子を変えた/消した名前で確定すると「拡張子が
    ".mp4" から "(なし)" に変わります…」の確認が出て、「戻す」で編集に復帰できる。
    フォルダのリネームでは確認が出ない。大文字小文字だけの変更 (.JPG→.jpg) は
    確認なしで通る。
42. **メイン fullscreen の削除スライド退行なし**: メイン fullscreen で画像を
    表示中にその画像を削除 → fullscreen は閉じず隣の画像へスライドする (従来どおり)。
    2026-07-10 実機: **末尾の画像を削除すると (前に画像が残っていても) 窓が閉じる**
    退行を検出 → 修正済み (P2-2 の idx シフトが単純 clamp でコンテナセルに落ちていた →

    ↑↓ ナビと同じ扱いで遷移先に含む)。**再確認**: 末尾の画像を削除 → 前の画像へ
    スライドし、フォルダの表示可能アイテムが尽きたときだけ閉じる。
43. **(任意) レーティング直後の削除**: 画像に★を付けた直後 (1 秒以内) にその画像を

44. **ファイルのリネームで設定が引き継がれる**: ★・タグ・回転・補正/マスク等を付けた
    画像をリネーム → 一覧のバッジ・★・タグがそのまま新しい名前に付いている。
    動画なら再生位置・ブックマークも引き継がれる (.xmp サイドカーも改名される)。
45. **フォルダのリネームで配下の設定が引き継がれる**: ★/補正済み画像を含むフォルダを
