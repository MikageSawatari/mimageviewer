ここでは主な変更を挙げます。全項目は更新履歴（https://github.com/MikageSawatari/mimageviewer/blob/main/CHANGELOG.md）をご覧ください。

### v4.4.0 (2026-10-07)
- **RAW 画像の表示・現像を内蔵しました。** 追加の拡張機能なしで、DNG と各社カメラの RAW（23 種類の拡張子）を開けます。フルスクリーンではまず埋め込みプレビューを表示し、現像が終わると現像した画像に切り替わります。編集は現像後に使えます。Nikon の高効率 RAW（HE / HE*）と JPEG XL 圧縮の DNG は現像できませんが、使える埋め込みプレビューがあれば表示します。設定は環境設定の「ファイル処理 → RAW 現像」です。
- **クリップボードから画像を取り込めるようになりました。** 環境設定の「起動と連携 → クリップボード取り込み」でチェックを入れると、コピーした画像を自動で保存したり、コピーしたページに含まれる画像を選んで保存したりできます（既定はオフ）。ページの画像は選択画面を開いたときに取得し、ブラウザの Cookie やログイン情報は使いません。一覧画面の <kbd>Ctrl</kbd>+<kbd>V</kbd> でも、今のフォルダへ保存できます。
- **よく使うコピー・移動先を「ファイル整理先」として登録できるようになりました。** 環境設定の「ライブラリ → フォルダ・ファイル → ファイル整理先」で登録し、項目を右クリックして「ファイル整理先…」から移動・コピーします。整理先はフォルダバーの「場所▼ → 整理先」と mIV Remote のホームの「場所」からも開けます。
- **環境設定をファイルに書き出して、別の PC で取り込めるようになりました。** 設定メニューの「設定の復元…」から使います。対象は別の PC でも使える閲覧・表示などの設定で、★評価・編集内容・お気に入り・タグ・履歴などの利用データやパスは含みません。
- **一覧のサムネイルの下端に、前回の読書・再生位置をバーで表示するようにしました。** 本は最後に記録したページ位置の割合を、動画・音声は前回の再生位置を表示します。表示中はすべてのサムネイルの下端に場所を空けるため、ファイル名などの表示が少し上へ移ります。環境設定の「表示 → サムネイル」にある「本・動画・音声のサムネイルに前回の位置を表示」でオフにできます（既定はオン）。
- **ソートを、絞り込みバーの右側にも表示できるようにしました。** 「設定」→「ツールバー」で上部と右側の表示をそれぞれ選べます。すでに使っている場合は、今の上部の表示をそのまま引き継ぎます。
- **フォルダバーも、ツールバーの並べ替えの対象にしました。** 「フォルダ:」ラベルをドラッグして移動できます。既定の表示はこれまでどおりです。
- **画像色の絞り込みで、ZIP / PDF も代表画像の色で絞り込めるようにしました。** プリセット色に肌色と濃い赤も追加しました。
- **メイン画面を最小化しても、音響調整（EffeTune）の窓を表示したままにできるようにしました。** 環境設定の「動画・音声 → 動画」で選べます（既定はオフ）。
- **「EffeTune に渡す前に 0dB を超える音を抑える」の切り替えが、再生中にすぐ反映されるようになりました。** あわせて、音割れ防止を常に働かせるようにしました。
- **起動中の画面に、いま何をしているかと経過時間を表示するようにしました。** 検索の準備に 5 秒以上かかる場合は、起動中の画面を閉じて通常の画面を使えるようにします。
- **単体exe版・インストーラ版で、更新前の古い版のファイルを起動後に自動で削除するようにしました。**
- **v1.0〜v1.3 で付けたタグを、起動時にアプリ内のタグへ自動で移す処理を終了しました。** v1.4.0 以降で移し終えたタグは、これまでどおり使えます。v1.0〜v1.3 から直接更新した場合、以前のタグは取り込まれません。
- **「前回終了した場所」で起動するとき、本を直接ページ表示したまま終了すると、次の起動で見ていないページ一覧が開く問題を修正しました。** 開く前の一覧に戻ります。タスクトレイから復帰したときも同じです。
- **通常のフォルダやレーティング一覧で ZIP などを開いてから <kbd>←</kbd> で戻ると、開いていた項目が選ばれない問題を修正しました。**
- **画面が小さい PC で、初回設定などの起動時の画面のボタンが画面外にはみ出して押せないことがある問題を修正しました。**
- **最大化した状態で終了すると、次の起動時にウィンドウがちらつく問題を修正しました。**
- **A/B クイックフォルダで B を選んだまま終了すると、次の起動で A が選ばれた状態になる問題を修正しました。**
- **音響調整・VST3 を使っているときなどに、動画・音声の最後のごく短い音が鳴らずに終わる問題を修正しました。**
- **ループ再生で、2 周目以降の先頭に前の周の終わりの音が短く混ざることがある問題を修正しました。**
