## 1. 判断してほしいこと (操作の前に決めてよい)

- [ ] **Ctrl+Space ズームの感度** (keyzoom): いまは横 100 px (UI 倍率 100% のとき) で 2 倍。中ボタンドラッグのズームと同じ値。
  ClaudeCode の試行では、400 画面 px (この PC の UI 倍率で約 300 px) で約 8 倍になり、かなり速く感じた。
  Ctrl+Space だけ別の値 (例: 200 px で 2 倍) にでき、中ボタンの感触は変わらない。→ 実際にペンで触ってから決めるのが確実。
- [ ] **隠蔽 (モザイク) の Tab プレビュー** (keyzoom): 消しゴムと同じ目のボタンがある。同じ Tab で揃えるか。

- [ ] **タグの並べ替え** (list-ui): 検索語を変えても、結果に残っている画像は開いたままになる (承認済み)。リリースノートに書くか。

## 2. ページめくり (pageturn-1461-1457)

ClaudeCode が隔離データで確認済み: 通常フォルダ (PNG 4 枚) で → ← どちらもめくれる。消しゴムで消した頁が、めくり中も消した後の絵。めくり終わりの「読み込み中」は出なくなった。

設定: 環境設定 → ページめくりアニメーション ON。

- [ ] 普段の画像フォルダ (大きな JPEG など) で、→ ← の単発送りがめくりになるか。
- [ ] 本 (ZIP / PDF) で、消しゴムで編集した頁へめくると、めくり中から編集後の絵か (最初の報告の場面)。
- [ ] 同じく、**局所補正・隠蔽 (モザイク)・テキスト注釈**を入れた頁へめくったとき、めくり中から反映されているか (§1.401、今回すべて入れた分)。
- [ ] 切り抜きした頁で、暗転・枠がめくりと一緒に描かれるか。
- [ ] 見開きでのめくり (編集済みの頁を含む)。
- [ ] 戻る方向 (←) で編集済みの頁へ戻るとき。
- [ ] めくり OFF のとき、読み込みに時間のかかる頁で「読み込み中」が従来どおり出るか (消えすぎていないか)。
- [ ] F12 の別ウィンドウでめくり。
- [ ] 連打したときに止まったり、ちらついたりしないか。間に合わない頁は、編集前の絵でめくってから着地後に切り替わることがある (仕様)。
