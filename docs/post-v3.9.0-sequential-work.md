## §1.115の開始条件

古い仮説が複数回訂正されているため、現sourceと履歴を照合してから再確認手順を作る。
特にタイトルバー最大化とF11を区別し、Enterによる明示close/open、font lifecycle撤去済み範囲、
hostのvisibility/ready/placementと入力所有権を確認する。見た目が再現しないだけで構造的な
完了条件を満たしたとは扱わず、追加実装が必要かは証拠と独立レビューで判断する。
detached-rework-plan §2を維持し、症状guard・delay・追加repaint・機能制限で置き換えない。
実機操作は手順・所要時間・使い捨てdata・入力使用を具体化し、利用者了承後のみ。
通常APPDATAを使う必要がある操作は利用者自身に依頼し、agentは通常アプリを起動・停止しない。
ユーザー確認が必要になった場合は、後続項目を勝手に並行実装せず判断を求める。
