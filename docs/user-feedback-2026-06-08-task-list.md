  - ダークテーマでも可読性が落ちていないことを確認する。
  - 可能なら tooltip 配色のスナップショットまたは既存 UI helper の単体確認を追加する。

- [x] フォルダ内画像のフルスクリーン中に Backspace で一覧へ戻るようにする。
  - `docs/keymap-spec.md` 上はすでにフルスクリーン共通の Backspace が割り当て済み。
  - 通常フォルダ内画像では一覧へ戻り、ZIP/PDF 自動オープン時は既存仕様どおりページ一覧へ戻ることを確認する。
  - native 動画経路の Backspace と矛盾しないかも確認する。

- [x] 環境設定の右スクロールバー重なりを構造的に修正する。
  - 確認済み箇所:
    - キャプチャ保存ページ: 「フォルダを開く」が見切れる。
    - 先読みページ: 「枚数。」の行がスクロールバーにぎりぎり重なる。スクロールバー位置も右端から少し内側に見える。
    - フォルダページ: 右側で文字折り返しとスクロールバーが重なる。
    - 同名ファイルページ: 右側の `▼` がスクロールバーと重なる。
    - EXIF 表示ページ: ボタンが右スクロールバーと重なる。
    - VST3 プラグインページ: プラグインチェーンの `×` ボタンがスクロールバーと重なる。
    - 多くのページ: 項目区切りの横線の右端がスクロールバーと重なる。
  - 対応方針:
    - 環境設定右ペインに共通のスクロールバー用右余白 / content width ルールを作る。
    - ページ個別の `with_layout(right_to_left)` や `ComboBox` が右端に密着しないよう共通ルールへ寄せる。
    - 今後パネル追加時の注意点を `docs/preferences-layout-guidelines.md` に残す。

- [x] フォルダバーに `D:` と入力して移動した後、以後 `D:一般コミック...` のように `\` が欠ける問題を修正する。
  - `D:` 入力は `D:\` として扱う。
  - ドライブ一覧やパンくずからの遷移も同じ正規化を通ることを確認する。

- [x] ファイル選択カーソルを常時表示に変更する。
  - 設定項目は追加しない。
  - フォーカス状態やマウス hover に依存してカーソル枠が消えないようにする。

- [x] 画像閲覧時の下部シークバーとページ位置表示を追加する。
  - 対象:
    - カーソルキー上下でアクセスできるアイテムがすべて画像であるフォルダ / ZIP / PDF で表示する。
    - 画像以外が混在する場合は、シークバーではなく `画像 12 ファイル、動画 3 ファイル` のような構成表示を検討する。
  - 表示:
    - 画面下ホバーで表示する。
    - LTR は右端に `12/123`、RTL は左端に `12/123` を表示する。
    - ページ表示モード以外では、画面中央に最も近い表示中ページを現在ページとする。
  - 操作:
    - シークバーをドラッグするとリアルタイムにページが変わる。
    - 連結モードではシーク先ページが画面中央に来るようにスクロール位置を調整する。
  - ZIP/PDF と通常フォルダの分岐漏れに注意する。

- [x] 起動時の場所を選べる設定を追加する。
  - 環境設定に「開始フォルダ」ページを追加する。
  - 選択肢:
    - 前回終了したフォルダ
    - デスクトップ
    - 指定フォルダ: `[               ] [フォルダを開く]`
  - デフォルトは「前回終了したフォルダ」。
  - 指定フォルダが存在しない場合の fallback を決める。

- [x] 閲覧履歴を保存し、クリアできるようにする。
  - 現在は再起動で揮発するフォルダ履歴を設定へ保存する。

  - クリア後は現在セッションの履歴 UI も即時更新する。

## 実装順メモ

1. 既存作業ツリーのコミット作業が終わってから、まず小さく独立した修正
   (tooltip / Backspace / `D:` 正規化 / カーソル常時表示) を実装する。
2. 次に環境設定右ペインの共通 layout ルールを入れる。新規「開始フォルダ」ページと
   履歴クリア UI は、この共通ルール適用後に追加する。
3. 最後に下部シークバーを実装する。フルスクリーン描画、連結読み、ZIP/PDF、入力処理へ
   またがるため、他の UI 修正と分けて検証する。
