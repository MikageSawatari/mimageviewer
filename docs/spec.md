# mimageviewer 仕様書

## 1. アプリケーション概要

Windows 11向けネイティブ画像ビューワー。
ViX（32bit旧来アプリ）の使い勝手を継承しつつ、Rustによるメモリ安全性とGPUアクセラレーションを実現する。

---

## 2. ウィンドウ構成

アプリケーションウィンドウは **1つ**。フルスクリーン表示時のみ別ウィンドウ（ボーダーレス）を生成する。

```
┌─────────────────────────────────────────────────────────┐
│ メニューバー: ファイル | お気に入り | 設定               │
├─────────────────────────────────────────────────────────┤
│ フォルダバー: [←][→] [⬆][▲][▼] [フォルダパス...] [♡][履歴▼][📌] │
├─────────────────────────────────────────────────────────┤
│ ツールバー: [列数] [縦横比] [ソート] [お気に入り]      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   サムネイルグリッド (仮想スクロール)                   │
│                                                         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.1 メニューバー

| メニュー | 項目 |
|---------|------|
| ファイル | フォルダを開く… (Ctrl+O) / 現在地フィルタ (Ctrl+F) / 終了 |
| お気に入り | このフォルダを追加… / 編集 / コンテナ検索 (Ctrl+S) / アイテム検索 (Ctrl+G) / [登録済みフォルダ一覧] |
| タグ | タグを編集… / 選択中のファイルから mIV タグをクリア / [登録済みタグ一覧] |
| 設定 | サムネイル列数 / 比率 / ソート順 / キャッシュ管理… / サムネイル画質… / 統計… / 回転情報をリセット… / 環境設定… |

- トップレベルメニューのいずれかをクリックして開いている間は、`ファイル` /
  `お気に入り` / `動画` / `タグ` / `設定` / `ヘルプ` の別項目へマウスを
  横移動して hover するだけで、開いているメニューが切り替わる。未オープン状態の
  hover だけではメニューを開かない。

### 2.2 フォルダバー

- テキストボックスにフォルダのフルパスを入力
- **Enter** キーでそのフォルダを開く
- フォルダ移動時に自動更新される
- **← / → 履歴ボタン**: フォルダ移動履歴を戻る / 進む。履歴操作中は通常の
  フォルダ履歴に重複して積まない
- **⬆ 親フォルダボタン**: `Backspace` と同じく親フォルダへ移動し、元フォルダを選択状態にする。Ctrl+F フィルタが現在フォルダに効いている間は disabled になり、Esc / × で検索を閉じるまで親へ抜けない
- **▲ / ▼ ツリー順ボタン**: `Ctrl+↑/↓` と同じく、深さ優先のツリー順で前 / 次の
  画像・動画・ZIP・PDF フォルダへ移動する
- **場所▼ メニュー**: デスクトップ / ピクチャ / ダウンロード / 利用可能なドライブ
  (`C:\` など) へ直接移動する。既知フォルダは Windows Known Folder API を優先し、
  OneDrive やリダイレクトされた Desktop に追従する。検索中と ★固定中は disabled
- **♡ / ♥ お気に入りボタン**: 未登録の現在フォルダではお気に入り追加ダイアログを開く。
  登録済みの現在フォルダではお気に入り編集ダイアログを開く。検索・索引の
  ルートになるため、追加対象は実フォルダのみで、ZIP / PDF / 変換済みアーカイブ
  閲覧中は追加できない
- **履歴▼ メニュー**: 最近開いたフォルダをフルパスで最大 20 件表示し、選択したフォルダへ移動する。最近開いたフォルダ履歴は再起動後も保持され、環境設定 → ツールバーのフォルダバー設定からクリアできる
- **検索中の挙動** (Ctrl+S お気に入り検索 / Ctrl+G 全文検索 アクティブ時):
  検索は透明な一時オーバーレイ扱い。検索中のフォルダ移動は ←/→ の戻る・進む履歴にも
  履歴▼ の最近開いたフォルダにも一切記録されず、検索を抜けると検索前の履歴状態が
  そのまま復元される。
  - **←/→/履歴▼**: disabled (検索中はフォルダ履歴の概念が適用されない)
  - **⬆ 親フォルダボタン**: 検索結果の仮想階層を 1 段ドリルアップする動作に転用
    (BS と同じ)。最上位 (Ctrl+G の集約ビュー / Ctrl+S の結果一覧) では disabled
  - **▲ / ▼ ツリー順ボタン**: 前 / 次のヒットフォルダへ移動 (キーボード Ctrl+↑/↓ と一致)。
    最上位では disabled
  - **検索の終了**: ←/BS では検索状態から抜けない。閉じるには <kbd>Esc</kbd>、検索バーの
    × ボタン、または <kbd>Ctrl</kbd>+<kbd>G</kbd> / <kbd>Ctrl</kbd>+<kbd>S</kbd> 再押下 (toggle)
  - **例外**: 右クリックメニューの「フォルダに移動」は検索を明示終了して実フォルダへ
    着地する正当なナビゲーションなので、その遷移 (検索前フォルダ C → 着地フォルダ X)
    だけは履歴に残し、X で ← を押すと C に戻れる
- **📌 代表サムネ固定ボタン** (フォルダバー右側): 選択中のアイテムを現在のフォルダ /
  ZIP / PDF の代表サムネに固定 / 解除する。左クリックでトグル (既に同じアイテムが
  ピン留め済みなら解除、そうでなければ設定)、右クリックで常に解除。表示は
  `設定 → 環境設定 → ツールバー → 代表サムネ固定 (📌) ボタンを表示` でオフ可能
- フォルダバー右側に現在のサムネイル表示数を `(表示中/全体)` 形式で表示する。
  例: ★フィルタで 100 件中 20 件が表示されている場合は `( 20/100)`。
  分子は分母と同じ桁数に右寄せし、検索結果表示中は非表示

### 2.3 ツールバー

- 列数（1〜10）、縦横比（7種）、ソート順（4種）、お気に入りフォルダのボタンを配置
- 各セクション・個別項目の表示/非表示をカスタマイズ可能
- すべて非表示にするとツールバー自体が消える

### 2.4 サムネイルグリッド

- 設定で指定した **列数** の可変グリッド（行数は画面に応じて自動）
- 各セルはアスペクト比を維持してサムネイルを表示（余白はセル背景色で埋める）
- セルサイズ = ウィンドウの残余領域 ÷ 列数
- **仮想スクロール実装**（下記詳細参照）

## 3. サムネイルグリッド詳細

### 3.1 仮想スクロール

```
総スクロール高さ = ceil(ファイル数 / 列数) × セル高さ

描画対象行 = 現在スクロール位置から見えている行 ± バッファ2行
それ以外の行 = 高さだけ確保、GPUテクスチャ未割り当て
```

- スクロールオフセットは App 自身で管理（egui の自動スクロールは使わない）
- オフセットは常に `cell_size` の整数倍にスナップ（行単位）
- 最大オフセットも行境界にスナップ → 最終行の下に余白が生じる
- マウスホイールは egui の MouseWheel イベントを消費して1行単位で移動

### 3.2 並列サムネイルロード手順

1. フォルダを開く → ファイル一覧を取得（瞬時）
2. グリッドレイアウト・スクロール高さを計算 → 空枠を即座に描画
3. **フォルダごとに専用 rayon スレッドプールを新規作成**（旧フォルダのタスクとプール競合しない）
4. キャンセルトークン（`Arc<AtomicBool>`）を旧タスクへ送信して中断
5. **フェーズ1**：可視範囲の画像を優先して並列ロード
6. **フェーズ2**：残りの画像を並列ロード（キャンセル確認しながら）
7. 完成したサムネイルを `mpsc::channel` でメインスレッドへ送信
8. メインスレッド: `Pending` なサムネイルがある間は毎フレーム `request_repaint()` を呼び、受け取り次第 GPU テクスチャ登録

### 3.3 サムネイル生成

- 表示用: セルの実ピクセルサイズにリサイズした ColorImage を直接 GPU へ送信（高画質）
- キャッシュ用: 長辺 512px にリサイズ → WebP (lossy, q=75) でエンコード → SQLite に保存
- アイドル時にキャッシュ由来のサムネイルを元画像から再デコードして高画質化（設定で ON/OFF）
- JPEG などの EXIF Orientation は通常画像と ZIP 内画像の両方でデコード時に適用する。既存の古い ZIP サムネイルキャッシュはそのまま使われ、削除すると現在の向きで再生成される。

### 3.4 ページ単位先読みと Eviction

- `thumb_prev_pages`（デフォルト 2）/ `thumb_next_pages`（デフォルト 4）ページ分のサムネイルを GPU メモリに保持
- 範囲外のサムネイルは `Evicted` 状態にして TextureHandle を drop → VRAM 解放
- `thumb_vram_cap_percent`（デフォルト 50%）で GPU メモリ使用量の安全ネット

## 4. フルスクリーン表示 ✅

### 4.1 ウィンドウ仕様

フルスクリーン表示には 2 つのモードがあり、環境設定 `video_in_window_mode`
（既定 false = フルスクリーン）で切り替える。動画 HUD のトグルボタンと静止画
ホバーバーの ⊞ トグルボタン（どちらも × ボタンの左）、および <kbd>F11</kbd>
ショートカット（消しゴムモード中は除く）でも切り替えられ、設定は動画・静止画で
共有する。

- **フルスクリーンモード**（既定）: ボーダーレスウィンドウ（タイトルバー・枠なし）、
  モニター解像度サイズ、メインウィンドウとは別ウィンドウとして生成
- **ウィンドウ内モード**: 動画も静止画もメインウィンドウのクライアント領域内に
  表示する。タイトルバー・ウィンドウ枠は残り、ウィンドウのリサイズ・移動に追従する。
  ウィンドウ内動画と静止画をホイールで往復しても表示モードが一貫する

### 4.2 表示仕様

- 画像をモニター解像度に合わせて表示（バイキュービック縮小/拡大）
- 前後の画像をプリフェッチ（`prefetch_forward` / `prefetch_back` で枚数設定可能）
- 表示はページ構成 (1 ページ / 見開き 左→右・右→左、表紙単独あり) と連結方式
  (ページ単位 / 縦連結 / 横連結) を独立して選べる。<kbd>1</kbd>〜<kbd>5</kbd> はページ構成、
  <kbd>6</kbd> は連結方式 (ページ単位 → 縦連結 → 横連結)、<kbd>7</kbd> は横方向
  (左→右 / 右→左)、<kbd>0</kbd> はズーム/フィット
  (ページ全体 / ページ全体+余白カット / 横幅 / 縦幅 / 100%原寸) を切り替える。
  連結モードでは余白カットフィットをスキップする。ページ単位へ切り替えるとページ全体、
  縦連結へ切り替えると横幅フィット、横連結へ切り替えると縦幅フィットへ自動で戻る。
  見開き中に横方向を変えた場合は、表紙単独あり/なしを
  保ったまま見開きの左開き / 右開きも連動する。連結方式は画像 /
  ZIP 内画像 / PDF ページを仮想配置し、縦連結はホイール・↑↓・PageUp/PageDown・ゲームパッド上下、
  横連結はホイール・←→・PageUp/PageDown・ゲームパッド左右でスクロールする。巨大キャンバスは
  作らず、GPU テクスチャは可視範囲 + 前後 2 ページ程度、最大 20 ページ程度に抑え、同時可視ページ数が
  16 ページを超えるような極端なズームアウトはズーム下限を引き上げて防ぐ。見開き内のページ間隔
  (既定 4px、0px で密着) と連結読みのページ/見開きユニット間隔 (既定 20px) は環境設定で変更できる。
  見開き構成の縦連結では、表紙や端数の単独ページも見開きページと同じ倍率で中央寄せする。
  ZIP の章区切りは、連結モードでも画像テクスチャ化せず、前後ページと同じサイズの区切りページとして表示する。
  連結読みのホイール・矢印/D-pad・左スティック速度も画面サイズ比 (%) で調整できる。
  連結モードでは比較、
  360度パノラマ、分析、編集系モードは起動せず、確定済みのページ単位補正・注釈・マスク結果だけを
  表示に反映する。
- マウスを画面上部に移動でファイル情報ヘッダーバーを表示（操作ボタン付き: ℹ / ↶ / ↷ / ▶ / ✕）
- 静止画フルスクリーン中にマウスを画面下部へ移動すると、フォルダ / ZIP / PDF のフルスクリーンナビ対象がすべて画像の場合だけ画面下端フル幅のページシークバーを表示する。LTR は右端、RTL は左端に `12/123` 形式の位置を表示し、ドラッグ中はリアルタイムにページを移動する。縦 / 横連結モードではシーク先ページを中央に置く。ZIP の章区切り (`ZipSeparator`) は混在判定から除外する。動画など画像以外が混在する場合はシークバーを出さず、画像 / 動画 / その他の件数サマリーを表示する
- 画面右 1/4 にマウスを移動でメタデータパネルをホバー表示（ピン留め可能）。開いた後はパネル内にカーソルがある間、左端まで移動しても表示を維持する
- メタデータパネル: AI 生成プロンプト (A1111/ComfyUI) + EXIF 撮影情報 + 外部メタデータサイドカー (画像と同名 JSON/TXT を読み取り専用で表示) を表示。HTTP(S) URL はクリック可能リンクとして表示する
- S キー・▶ ボタンでスライドショー。間隔設定可能。各ページが描画できる状態になってから設定秒数を数え、右上の小さな円形インジケータで次の切替までの進行を示す。ZIP 内の区切り表示は同じ間隔で進む。**動画はスキップして継続**する（動画では止まらない）。フォルダ末尾に到達したときの動作は設定で選べる（フォルダ内でループ＝既定 / 次のフォルダへ進む / 最後で停止）。「次のフォルダへ進む」は手動フォルダ移動と同じ前順走査で次の静止画フォルダへ進み、移動先に画像が無ければ停止する。**スライドショー中のフォルダ内移動（矢印キー・ホイール・クリック・Home・End）は再生を止めない**（一部スキップしつつ継続できる）。フォルダ移動操作 (Ctrl+↑↓) や S / Space / Esc は停止する。Space は再生中は停止、停止中はチェック ON/OFF
- R / L キーまたは回転ボタンで非破壊回転（SQLite に保存）
- アニメーション GIF・APNG はフルスクリーンでそのまま再生
- 動画はフルスクリーンでインライン再生。下部 HUD の速度ボタンから 0.5x〜3.0x の
  倍速再生を選択でき、音声は pitch を維持して再生する。速度ボタンの右クリック
  またはダブルクリックで 1.0x (等倍) に戻せる。選択した速度は動画切替と
  アプリ再起動後も維持される。外部プレイヤーは
  Shift+Enter で起動する。
- 動画のシークは target 前の keyframe を画面へ出さずに target まで preroll する。
  連続キー押しやシークバー操作は最新 target にまとめ、1 seek 世代が 150ms を超える
  遅いシークでは中央に「シーク中...」を表示する。
- アナモフィック動画 (NTSC DVD など SAR != 1:1 の動画) は表示比 (DAR) を補正して
  正しいアスペクトで表示する。タイルモードのセル比率も同じ DAR を反映する。
- 動画タイルモード (S キー) の上部バーは通常再生時と同じ高さ・配色で、現在の動画の
  タイトル / 解像度 / fps / コーデック / 長さ / タイル間隔 / サムネイル抽出進捗を
  表示する。ホイールで別動画に切り替わったときも、メタ情報の到着前からファイル名が
  追随表示される。右側のボタン列で、× (動画に戻る)、細かいグリッド / 大きいグリッド
  アイコン (列数 ±1。Ctrl+ホイールと等価で、ショートカットの発見性を上げる目的) を
  操作できる。タイルを開いた直後は現在の再生位置より後の最初のタイルを、時刻ラベルまで
  含めた強調背景つきのキーボードカーソルとして表示し、←/→ で 1 タイル、Ctrl+←/→ で 1 行分移動、
  Space / Enter でカーソル位置から再生する。Shift はタイル中の左右移動では無視し、
  Ctrl が含まれる場合だけ 1 行分移動にする。S / Esc / × で閉じた場合は
  再生位置を変更しない。
- 動画の下部 HUD は 2 段構造で、上段にフル幅のシークバー (ヒット領域 24pt、マーカー
  表示込み)、下段に再生制御 / ループ・連続再生 / 前/次ファイル / マーカー移動 /
  キャプチャパレット / 時刻 / 音量を配置する。前/次ファイルボタン (↑/↓ キー相当) は
  連続再生ボタンの隣に置き、「左右=動画内、上下=ファイル切替」のキーボード規約と
  「連続再生=末尾で次へ」の意味的隣接を視覚化する。キャプチャパレットは
  [前フレーム][クリップボードコピー][ファイル保存][次フレーム] の 4 ボタン常駐構成で、
  ファイル保存ボタンは Ctrl+S と等価。マーカーボタン (前/次のチャプター・ブックマーク・
  ピン、J/K キー相当) は対象アイテムが無い場合グレーアウトで disabled 表示する。
  ウィンドウ幅が狭いときは「左にあるボタンほど残す」優先順位で右側から順に省略する
  (キャプチャパレット → マーカー → 前/次項目 → 右クラスター縮小)。省略されたボタンは
  キーボード ショートカット (Ctrl+S / Ctrl+Shift+←/→ / J/K / ↑/↓) で同等の操作が可能。前/次フレームボタンまたは Ctrl+Shift+←/→ で
  実 decoded frame の前後 1 フレーム単位に移動し、移動後は
  一時停止状態を維持する。再生中に押した場合も押下時点でまず一時停止し、
  隣接フレームの探索完了後に対象フレームへ移動する。前フレーム探索は現在フレームの
  直前を seek target にして、target 以前の keyframe から decoder が直前 frame を選ぶ。
  前/次フレームボタンの長押しは、前回のフレームが画面へ
  反映された後に最短約 100ms 間隔で次の frame-step seek を発行する。
- Windows のタスクバーで mIV アイコンを hover したときは、動画フルスクリーン中も
  現在位置近傍のフレームをアプリのプレビューサムネイルとして表示する。
- 保存済み再生位置がある動画は通常、前回位置からレジューム再生する。挙動は
  **位置復元マトリクス**(環境設定「位置の復元」)で「メディア (動画 / ZIP・PDF) ×
  エントリ方法 (一覧から開く / Ctrl+↑↓ 移動)」のセル単位に [続きから / 最初から] を選べる:
  - 動画 × 一覧から開く: `video_open_resume`(= 互換維持のため旧 bool
    `video_grid_open_starts_from_beginning` を保存先に流用、accessor 経由)。
  - 動画 × Ctrl+↑↓ 移動: `video_nav_resume`(既定 = 続きから)。
  - ZIP/PDF × 一覧から開く: `book_open_resume`(既定 = 続きから)。
  - ZIP/PDF × Ctrl+↑↓ 移動: `book_nav_resume`(既定 = 先頭から = 従来のフォルダ先頭着地)。
  video の判定は `video_resume_for_open`、本の判定は `DeferredFsReopen.resume_to_last_page`
  (grid 経路は book_open_resume / nav 経路は book_nav_resume) で行う。
- 動画フルスクリーン中にホイール / ↑↓ / Home / End などで別の動画へ移動する場合、
  native presenter の HWND / D3D11 presenter / overlay を保持したまま動画 source だけを
  切り替え、背後のウィンドウが露出しないようにする。ホイール連続入力中は 120ms
  操作が止まるまで動画 decoder の作成を遅延し、その間は保存済み resume サムネイル
  (無ければ黒背景) と上部バーのファイル名を表示する。画像⇄動画の遷移は対象外。
- 動画メタ情報パネルは FFmpeg が読める埋め込み metadata の title / artist /
  description に加え、外部ツールが `comment` / `PURL` / `webpage_url` として埋め込む元動画 URL
  を表示する。元動画 URL と説明文中の HTTP(S) URL はリンクとして表示し、
  クリック時は動画再生を一時停止して既定ブラウザで開く。
- 動画メタ情報パネルにはデコード backend / フレーム表示経路 / デインターレース状態を
  併記する。「GPU経路」は ファイル open 時の能力フラグ (= GPU video device
  が使えるか)、「フレーム表示」は per-frame の実プレゼン経路 (`d3d11_shared` →
  GPU、`cpu_upload` → CPU)、「デインターレース」は Settings モード (Auto / On / Off) と
  bwdif フィルタの動的状態 (適用中 / プログレッシブ / 待機中 / 失敗) の組み合わせ表示。
  HW デコード + デインターレース ON 時は decoder backend が HW のまま、フレーム表示は
  CPU (= D3D11 → CPU 転送 + bwdif + swscale + CPU upload) になる。
- 動画音量は既定 0dB。下部 HUD / Shift+↑↓ / 環境設定から -∞dB〜+18dB の
  dB フェーダーで手動調整でき、音量バーの右クリックまたはダブルクリックで 0dB に戻せる。
  0dB 超の boost 部分は HUD で黄色表示し、音声ポンプ側の safety limiter を通す。
  safety limiter のゲインリダクション量が 1dB 以上に達した場合は音量表示右側に
  赤いインジケータを約 500ms 表示する (ceiling に触れただけ・タイムストレッチ由来の
  微小オーバーでは点かない)。
- 保存済み再生位置 (動画) と読書位置 (ZIP/PDF) の記憶件数の確認・全件クリアは
  **環境設定 → 位置の復元** ページに集約 (動画は `settings.video_resume_positions`、本は
  `book_resume_db` を対象)。動画クリアは settings 経路のため OK 適用時、本クリアは
  `book_resume_clear_requested` one-shot 経由で App が即時 `book_resume_db.clear_all()`。
- 環境設定 → 動画では `audio_normalize.db` の音量ノーマライズ測定値件数を確認し、
  確認ダイアログ経由で全件クリアできる。クリアしても現在再生中に適用済みの gain はその場では
  変更せず、次回以降に必要な動画を再スキャンする。
- HUD のミュートボタン / M キーで切り替えたミュート状態は動画切替と次回起動へ
  引き継がれる。環境設定の `video_start_muted` は起動時にセッション初期ミュートを
  true にする安全スイッチであり、起動後の動画切替では HUD の現在状態を優先する。
- VST3 が有効なとき、動画再生中の VST3 パネルからチェーンの ON/OFF、個別 GUI 表示、
  動画の右上 1/4 表示を切り替えられる。パネル位置はドラッグ終了時に保存され、
  次回表示時に復元する。解像度やモニター構成変更で画面外になる場合は画面内へ戻す。
- 動画ブックマークは B キー / 🔖 ボタンで現在位置に追加できる。左ジャンプパネルの
  ✏ ボタンから任意名称を付けると、チャプター名と同じように行タイトルや J/K
  ジャンプ時のトーストに表示される。
- 動画コメント等に書かれているチャプターリストを左ジャンプパネル上部の一括登録
  ボタンから貼り付けて一括ブックマーク化できる。1 行 1 件で
  `hh:mm:ss タイトル` または `mm:ss タイトル` 形式 (時刻部分が markdown link 表記でも可、
  小数秒 `mm:ss.mmm` も受け付ける)。
  既存のブックマークと時刻が ±1 秒以内の行は重複として skip される。
  同じダイアログから現在のブックマーク一覧をクリップボードへエクスポートでき、
  「秒単位にする」チェックボックスで整数秒 (floor、外部のコメント自動リンク化と互換) と
  ミリ秒精度 (mIV 内ラウンドトリップ用) を切り替えられる。チェックボックスは永続化せず、
  ダイアログを開き直すたびに「秒単位」が既定。
  誤登録の救済として、同じダイアログ内で「この動画のブックマークをすべて削除」
  (2 段階確認付き) も実行できる。ダイアログ右上の × ボタンで全体を閉じられる。
- 動画ピン留めは左ジャンプパネル上部の 📌 ボタン / シークバーホバー preview の
  ピンボタンで現在位置 (またはホバー位置) に設定する。1 動画につき 1 件のみで、
  既存ピンがある状態でボタンを押すと新位置で上書きされる。解除は左ジャンプパネルの
  ピン行右側の × ボタンで行う。ピン留めしたフレームはグリッドの動画サムネとして
  表示される (sidecar 画像と Shell API サムネより優先)。
- 左ジャンプパネルのピン / ブックマーク / チャプターサムネイルは、初回に取得できた
  WebP を DB に保存し、次回以降は再デコードせず DB から即表示する。シークバー hover
  中は hover preview を優先し、未取得のジャンプパネル用サムネ要求は後回しにする。
  時刻表示は通常 `M:SS` / `H:MM:SS` だが、小数秒を持つ行または同じ秒に複数マーカーが
  ある行では `M:SS.mmm` / `H:MM:SS.mmm` でミリ秒まで表示する。
- 動画ループ再生は L キー / HUD ループボタンで 4 段階サイクル切替する
  (ループなし → 全体 → チャプター → ブックマーク → ループなし)。設定キー
  `video_loop_mode` (旧 `video_loop: bool` は移行用に残存) に保存され、動画を
  切り替えてもモードが維持される。チャプターまたはブックマークが無い動画では当該段階を
  スキップしてサイクルが進む。チャプターループは次のチャプター手前または末尾で現在の
  チャプター開始へ自動 seek する。ブックマークループも同様にブックマーク区間を繰り返す。
  当該動画にデータが無い場合は全体ループとして動作 (ボタン表示はユーザー設定モードを維持)。
  ループボタンの上には現モードを示す「CH」テキストまたはブックマークアイコンが重ねて描画される。
- 動画連続再生は HUD の連続再生ボタンで 3 段階サイクル切替する
  (オフ → 連続再生 → 連続再生 + ループ → オフ)。設定キー
  `video_continuous_mode` に保存され、動画切替とアプリ再起動後も維持される。
  連続再生中は同一動画ループと競合するため、ループボタンと L キーは無効になる。
  EOF で現在の `visible_indices` 内の次の動画を先頭から自動再生し、連続再生 + ループでは
  末尾から先頭の動画へ戻る。
- 画像表示中に右 Ctrl を押している間だけ、補正・ポストフィルタ・AI アップスケール/
  デノイズ・消しゴム補完結果を外した元画像を一時表示する。
- フルスクリーン終了時は、画像・動画とも最後に表示していた項目をグリッドの
  カーソル位置に戻し、そのセルが見える位置までスクロールする。
- ビューポートは起動時から非表示で維持し、表示時のちらつきを防止
- 上部ホバーバー / 左右パネル / 動画 HUD のいずれも表示されていない状態が
  約 3 秒続いたらマウスカーソルを自動的に隠す。マウス操作で即時に
  再表示し、キー操作だけでは再表示しない。動画再生時は native presenter (D3D11 + 別 egui_ctx) 側でも同じ
  閾値 (`CURSOR_HIDE_IDLE_SECS`) で同等の挙動を実現する。

## 5. グリッド表示対象

サムネイルグリッドには以下を表示する。それ以外のファイルは無視する。

| 種別 | 表示内容 |
|------|---------|
| **フォルダ** | 代表画像サムネイル＋フォルダ名（画像がなければフォルダアイコン📁）。代表画像はフォルダ内を再帰的に探索（最大3階層）し、最初に見つかった画像をソート順で選択。**ユーザーが📌で手動指定**したアイテムがあれば自動選定を上書きする |
| **画像ファイル** | サムネイル画像 |
| **動画ファイル** | サムネイル画像（Windows Shell API 経由）。フルスクリーン HUD でユーザーが指定したフレームがあればそれを優先 |
| **ZIP ファイル** | 1枚目の画像サムネイル＋ZIP バッジ（ダブルクリックで中を開く）。**ユーザーが📌で手動指定**したエントリがあれば自動選定を上書きする |
| **PDF ファイル** | 1ページ目のサムネイル＋PDF バッジ（ダブルクリックで中を開く）。**ユーザーが📌で手動指定**したページがあれば自動選定を上書きする |

#### 代表サムネの手動ピン (folder thumb pin)

ユーザーは親コンテナ (フォルダ / ZIP / PDF) の代表サムネを **その中の任意のアイテム**
(画像 / 動画 / サブフォルダ / 入れ子の ZIP/PDF / ZIP エントリ / PDF ページ) に手動で
固定できる。

- **設定経路**:
  - フォルダバーの **📌 ボタン**: 選択中のアイテムを現在のコンテナの代表サムネに
    する (左クリック: トグル、右クリック: 解除)
  - **P キー**: グリッドでは選択中アイテム、画像フルスクリーンでは現在表示中アイテムを
    現在のコンテナの代表サムネにする (トグル)
  - グリッドおよびフルスクリーンの **右クリックメニュー → 「📌 代表サムネに固定 /
    解除」**: 個別アイテムから設定
- **永続化先**: `%APPDATA%/mimageviewer/folder_thumb_pins.db` (コンテナ単位 1 行)
- **優先順位**: 手動ピン > 自動代表選定 > フォルダ/ZIP/PDF アイコン fallback
- **無効化条件**: pin 先のファイルが存在しない / mtime/size 変化で identity が変わった
  場合、自動的に新キャッシュキーで再生成 (古い WebP は `delete_missing` で掃除される)
- **対象外**: 検索アグリゲートビュー (Ctrl+G)、RAR/7z/LZH の変換キャッシュ ZIP を内側から
  閲覧中、空フォルダ、`ConvertibleArchive` 未変換アイテム (= disabled、変換完了後に
  設定可能)
- **設定**: `環境設定 → ツールバー → 代表サムネ固定 (📌) ボタンを表示` でフォルダバー
  のボタンの表示有無を切替 (規定 ON)。右クリックメニューは常時表示

### 5.1 対応画像フォーマット

#### 内蔵デコーダー（image クレート）

| フォーマット | 拡張子 |
|------------|--------|
| JPEG | .jpg, .jpeg |
| PNG | .png |
| GIF | .gif |
| WebP | .webp |
| BMP | .bmp |

#### WIC 経由（Windows Imaging Component）

| フォーマット | 拡張子 | 必要なコーデック |
|------------|--------|----------------|
| HEIC / HEIF | .heic, .heif | HEIF 画像拡張機能 |
| AVIF | .avif | AV1 Video Extension |
| JPEG XL | .jxl | JPEG XL Image Extension |
| TIFF | .tiff, .tif | 標準搭載 |
| RAW（各社カメラ） | .dng, .cr2, .cr3, .nef, .nrw, .arw, .srf, .sr2, .raf, .orf, .rw2, .pef, .ptx, .rwl, .iiq | Raw Image Extension |

#### 動画（サムネイル表示 + フルスクリーンインライン再生）

MP4, AVI, MOV, MKV, WMV, MPG, MPEG。フルスクリーン再生では FFmpeg LGPL DLL
バックエンドを使い、対応環境では D3D11VA ハードウェアデコードを利用する。
D3D11VA 非対応 codec は CPU デコードで再生し、D3D11VA 対応 codec の HW 経路失敗は
SW fallback で隠さず再生エラーとして表示する。

### 5.2 自動除外

- macOS / iPhone の AppleDouble メタデータファイル（`._*`）は自動的に除外

### 5.3 グリッド内のアイテム順

フォルダ・ZIP・PDF・対応アーカイブ（コンテナ系）を先頭ブロック、画像・動画
ファイル（メディア系）を後続ブロックの 2 段構成で表示する（Explorer / Finder
と同じ慣習）。
ソート順は設定で選択可能で、両ブロック内に同じソート順が適用される:
ファイル名順 / 数値順（自然順）/ 更新日昇順 / 更新日降順。

## 6. フォルダツリー走査（Ctrl+↑↓）

フォルダツリーを**深さ優先（前順）**でたどる。

```
例：
  c:\folder-1\a
  c:\folder-1\b
  c:\folder-1\b\test1
  c:\folder-1\b\test2
  c:\folder-1\c

c:\folder-1\b を表示中に Ctrl+↓ → c:\folder-1\b\test1 へ
c:\folder-1\b\test2 を表示中に Ctrl+↓ → c:\folder-1\c へ
c:\folder-1\a を表示中に Ctrl+↑ → c:\folder-1 へ（最初の子なので親）
```

- **Ctrl+↓（次）**：子フォルダがあれば最初の子へ、なければ次の兄弟へ、なければ祖先の次の兄弟を再帰検索
- **Ctrl+↑（前）**：前の兄弟の最後の子孫へ、最初の子なら親へ
- 画像のないフォルダ・画像を含まない ZIP は `folder_skip_limit`（デフォルト 5、最大 30）回まで自動スキップ

### 7.3 ゲームパッド操作

ゲームパッドは閲覧専用の固定割り当てとして扱う。編集、削除、レーティング、

| 方向パッド / 左スティック | グリッドでは選択移動。画像フルスクリーンではページ送り。縦連結では上下がスクロール、左右がページ送り。横連結では左右がスクロール、上下がページ送り。左スティックは連結方向を連続スクロールする。動画フルスクリーンでは左右がシーク / タイルカーソル移動、上下が前後ファイル移動 |

## 8. 設定項目

設定は SQLite データベース `%APPDATA%\mimageviewer\settings.db` に自動保存される
(2026-05 移行。旧 `settings.json` からは初回起動時に自動 migration し、旧ファイルは
`settings.json.migrated-<ts>` にリネームされる)。詳細は
[settings-sqlite-migration.md](settings-sqlite-migration.md) を参照。

### 永続化と復旧の仕組み

- **アトミック保存**: SQLite トランザクション内で全テーブルを DELETE+INSERT してから
  `commit()` する。VST3 chain など大型 row は hash で変更検出し、未変更ならスキップ。
  書き込み中の電源断・force kill で半端な状態が残らない (= WAL + commit 境界)。
- **世代バックアップ (10 世代)**: 起動 1 回につき最初の **user save** で 1 段ローテートし、
  `VACUUM INTO` で `settings.db.bak1`〜`settings.db.bak10` に過去 10 セッション分の
  consistent な snapshot を保持する。同セッション内の追加保存は in-place 更新のみで
  bak には伝播しない (= 1 起動 = 1 世代)。
- **自動復旧**: 起動時に main DB が壊れていたら (`PRAGMA integrity_check` 失敗 /
  `NotADatabase` / `DatabaseCorrupt`)、`settings.db` / `settings.db-wal` / `settings.db-shm`
  を 3 セットで `.corrupted-<ts>-<seq>` に quarantine 退避し、`bak1`→`bak10` を新→古の
  順に試行して最初に開けたものから復元する。全滅した場合のみビルトイン default に落ちる。
  `DatabaseBusy` / `CannotOpen` 等の transient I/O エラーは 50ms backoff で 3 回 retry し、
  それでも失敗すれば quarantine せず save 抑止のみ行う (= 一時的なアクセス不能で本物の
  DB を失わない)。
- **I/O エラー時の保存抑止**: 起動時に main DB が transient I/O エラーで開けなかった
  セッション、または全復旧経路が失敗したセッションでは、当該セッション中の
  `Settings::save()` をすべて no-op にする (`MAIN_UNREADABLE_THIS_SESSION` +
  `settings_db::SAVE_SUPPRESSED`)。永続化はそのセッション分諦め、次回起動でリトライする。
- **アップグレード前バックアップ**: 直近に保存したバイナリと現バイナリの
  バージョンが違うとき、初回 load で現状の `settings.db` を `VACUUM INTO` で
  `settings.db.preupgrade-v<old>` に複製する。スキーマ破壊が自動復旧で
  救えなかった場合の最終ライフライン。同じ前バージョン名の snapshot が既に
  存在するなら上書きしない。
- **診断ログ**: 復旧経路で起きたイベント (SQLite open エラーの primary/extended code /
  quarantine / bak recovery / preupgrade / save 抑止) は
  **`<data_dir>/logs/settings.log` に常に append** される。logger の初期化状態に
  依存しない独立 sink なので、起動ごく初期の設定復旧フェーズでも確実に残り、
  ユーザー報告時の調査に使える。

#### 検索クエリ構文（Ctrl+F / Ctrl+G / Ctrl+S 共通）

パースは `src/search_query.rs` の `parse()` / `matches()`。

| 書き方 | 意味 |
|--------|------|
| `A B` | A と B の両方を含む (AND) |
| `-A` | A を含まない (NOT) |
| `"A B"` | スペース込みのフレーズ完全一致 |
| `-"A B"` | フレーズを含まない (NOT + フレーズ) |
| `#タグ名` | タグ検索（`#` 込みで一致） |

- 大文字小文字は区別しない
- 閉じクォート `"` がない場合は行末までを 1 トークンとして扱う（寛容パース）
- `-` 単体や末尾にある `-` はノイズとして無視する（`jean-claude` のような語内 `-` は通常の文字として扱う）

#### OR 検索モード (v0.7.2+、設計 [search-expansion-design.md §20](search-expansion-design.md))

各検索バー右端の **`□OR`** チェックを入れると include トークンを OR 結合する (既定は AND)。
**NOT (`-word`) は常に AND** のまま (チェック有無に関わらず除外は効く)。

| クエリ | AND モード (既定) | OR モード |
|---|---|---|
| `klee paimon` | 両方を含むものだけ | いずれかを含むもの |
| `klee #klee` | キーワード "klee" と タグ "#klee" の両方 | キーワードかタグのいずれかで "klee" を含むもの |
| `klee #klee -sleep -nsfw` | `klee AND #klee AND NOT sleep AND NOT nsfw` | `(klee OR #klee) AND NOT sleep AND NOT nsfw` |

状態は session-local (ウィンドウを閉じるとリセット)。Ctrl+S / Ctrl+F / Ctrl+G それぞれ独立に
保持される。

#### 最小クエリ長ポリシー (Ctrl+G のみ適用、v0.8.0)

Tantivy bigram インデックスで偽陽性を抑えるため、Ctrl+G は以下の最小長を要求する:

| クエリ種別 | 最小文字数 | 例 |
|---|---|---|
| 日本語 (CJK を 1 文字でも含む) | **2 文字** | `街並` OK / `街` NG |
| 英数字のみ | **3 文字** | `sdx` OK / `sd` NG |
| タグトークン (`#...` 始まり) | **制約なし (例外)** | `#a` OK / `#原` OK |

判定は各 include トークン単位。**タグトークン (`#name`) はこの最小長制約の対象外** —
`#` プレフィックス込みで最低 2 文字確保され、`tags` フィールドの bigram に直接当たるため
1 文字タグ名でも引ける ([global_search.rs::validate_query](../src/global_search.rs))。
また Ctrl+G では **NOT-only クエリは禁止**
(`-bad` のような除外だけの検索は Tantivy で候補を絞り込めず全件走査になるため)。
Ctrl+F (ローカル検索) はこれらの制約を受けない。

#### 検索の経路と索引

検索は「コンテナを探す」「アイテムを探す」「今いる場所を絞る」の 3 軸。
設計の正典は [search-container-item-redesign.md](search-container-item-redesign.md)。

| ショートカット | 呼称 | 対象 | 検索経路 | 備考 |
|---|---|---|---|---|
| Ctrl+S | コンテナ検索 | お気に入り全体のフォルダ / ZIP / PDF を名前で | コンテナ索引 `search_index.db` (SQLite LIKE) | 「種別」ドロップダウン (すべて / フォルダ / ZIP / PDF) で絞れる。動画は対象外 (動画はアイテム) |
| Ctrl+F | 現在地フィルタ | **現グリッドの表示中アイテムのみ** (非再帰・索引なし) | worker 上のオンデマンド判定 | 構造アイテム (フォルダ / ZIP / PDF) もファイル名で一貫して絞り込む。画像 / 動画は PNG tEXt + EXIF + XMP + 動画メタ + タグ + 外部メタデータサイドカー、PDF はファイル名 + document info。検索中は item 単位の処理済み数 / 総数を表示する。フィルタ元フォルダでは BS / Alt+↑ / ⬆ による親移動を止めるが、結果から子フォルダへ入った後の BS は通常どおり戻れる。PDF ページ表示中は無効、ZIP 表示中はファイル名フィルタに固定 |
| Ctrl+G | アイテム検索 | **お気に入り全体 (`auto_index_metadata=true`) の画像 / PDF / 動画** | アイテム索引 (Tantivy bigram) で候補絞り込み → STORED 原文を `matches()` で phrase/NOT/AND 正確判定 (streaming) | ZIP はコンテナなので対象外。動画は `video_meta_text` と `tags`、PDF は `pdf_meta_text`、画像と同名 JSON/TXT は `sidecar_text` (値のみの自由語検索、mIV タグとは別系統) に分けて検索対象フィルタから選べる。結果は一覧 / 集約の 2 ビューを切替でき、ヒットが多いと自動で集約に寄る。検索中はバー / アドレス欄 / 空グリッド中央に「検索中」を表示し、0 件確定と区別する。検索バーは狭い幅では折り返し、Ctrl+G のドロップダウン操作中は背後のグリッドをホイールスクロールしない |

#### AI メタデータ検索の Negative Prompt 除外

PNG の tEXt / iTXt / zTXt チャンクに AI 生成メタデータ（AUTOMATIC1111 / Forge の `parameters`、
ComfyUI の `prompt` JSON、Midjourney の `Description`）が含まれる場合、**Negative Prompt は検索対象から除外される**。

- 実装: `png_metadata::build_searchable_from_chunks()` が、検出したフォーマットに応じて
  正プロンプト + サンプラ/モデル等のパラメータだけを連結した検索用テキストを生成する
- ComfyUI では KSampler ノードの `positive` / `negative` 入力先を辿って正側の CLIPTextEncode のテキストのみを採用
- フォーマット検出に失敗した場合は Unknown 扱いで全 tEXt チャンクの値を含める（取りこぼし回避）
- Author / Comment / Software など AI 以外の標準 tEXt チャンクは従来通り検索対象に残る

### 8.7 レーティング

- 対象:
  - 単一ファイル単位 (`is_rating_leaf`): 通常画像 / 動画 / ZIP 内画像 / PDF ページ
  - コンテナ (`is_container_ratable`): フォルダ / ZIP ファイル / PDF ファイル本体
  - ページとコンテナは独立に管理される (同じ `rating.db` だがキー形式が異なるので衝突しない)
  - ZipSeparator・ConvertibleArchive は対象外
- 付与:
  - F1〜F5（★1〜★5）、F6 で解除。グリッドでは選択/チェック済み (`ratable_targets` = `accepts_rating`) に、フルスクリーンでは表示中ページに適用
  - Shift+F1〜F5 / Shift+F6: `current_folder` (現在一覧表示中のフォルダ / ZIP / PDF 本体) にコンテナ★を付与 / 解除。グリッド・フルスクリーン両方で動作
  - チェック済みアイテムがある場合は一括適用（適用後チェックはクリア）
- キー (`rating_path_key`):
  - ページ単位: `App::page_path_key` と同じ形式 (`normalize_path(path)::entry` / `::page_N`)
  - コンテナ: `normalize_path(path)` のみ (`::` セパレータが付かないのでページキーと衝突しない)
- 保存先: `%APPDATA%\mimageviewer\rating.db`（SQLite）
- 表示:
  - サムネイルセル左下に半透明の背景付きで★の数を描画
  - ページ★は金色 (255,215,50)
  - コンテナ★は銀青色 (180,220,255) + 先頭に 📁 アイコンを付加
  - フォルダバー（「フォルダ:」欄）の右端にも現在表示中のコンテナ★を 📁★★★ で表示
  - フォルダバー右端の件数表示は、レーティングフィルタ適用後の表示サムネイル数と
    フィルタ前の全サムネイル数を `(表示中/全体)` で示す
- フィルタ:
  - ツールバー「★: なし 1 2 3 4 5」の各バケットをトグル
  - ページ・コンテナ両方に同じフィルタが適用される (フォルダ一覧を★絞り込みできる)
  - 検索フィルタと AND 結合
- Ctrl+A: 現在のフィルタで表示中のチェック可能なアイテム（フォルダ/画像/動画/ZIP・PDF 本体/ZIP 内画像/PDF ページ/変換前アーカイブ）を全てチェックに入れる

### 8.8 テキスト注釈

- フルスクリーンのテキスト注釈モード (`Ctrl+T`、または画像補正パネル ヘッダーの吹き出しアイコン) で、
  ページ単位に非破壊の注釈オブジェクトを編集できる。元画像は書き換えない。分析 / 補正 / 消しゴム /
  隠蔽 / 動画再生中は入場できない。見開き表示中は左ページの単ページ編集に切り替わり、終了で復帰する。
- 種別は単体テキスト、吹き出し、メッセージウィンドウ、オノマトペ、スタンプ。
- セリフ / 単体テキスト / オノマトペは、フォント、サイズ、色、横書き / 縦書き、揃え、行間、字間、
  太字、斜体、袋文字、自動縦中横、記法による縦中横 / 横倒しを編集できる。
- 文字効果として、追加の外フチ、ドロップシャドウ、外側発光、背景プレート、Echo を
  テキストブロック単位で設定できる。組み込みプリセットには、字幕、中抜き、ネオン、
  Echo などの文字効果付きスタイルを含む。
- 吹き出しは、形状 (16 種)、塗り、輪郭、しっぽ (先端 / 付け根ハンドル)、装飾、すぐ下の吹き出しとの結合、
  文字に合わせた自動サイズを編集できる。メッセージウィンドウは、背景、枠、影、名前プレート、
  立ち絵枠、続き指標を編集できる。
- スタンプは同梱絵文字、またはユーザー画像。ユーザー画像は選択時に長辺 1024px へ縮小し、PNG/base64 を
  `StampSource::Embedded` として注釈へ埋め込むため、元ファイルの移動 / 削除や別マシンでも欠落しない。
  配置したユーザー画像は `comic_user_stamps.db` に MRU 履歴 (上限 48 / ピッカー表示 24、内容ハッシュで
  重複排除) として残り、ファイルを選び直さず再利用できる。履歴の削除 / prune は配置済みスタンプを壊さない。
- フォントは吹き出し / メッセージウィンドウは Yu Gothic 既定。オノマトペや装飾フォントは編集用追加パック
  から供給され、未導入時は追加自体をブロックする (システム既定へのフォールバックはしない = 後からフォント
  追加で保存済みの見た目が変わる事故を防ぐ)。
- 編集中のプレビュー解像度 (`text_preview_scale`: 原寸 / 1/2 / 1/4 / 1/8) を選べる。テキスト注釈モード中
  のみ下地を 1/N に縮小して合成 / GPU upload を軽くし、モード終了で原寸へ焼き直す。保存 / コピー / 比較 /
  `Ctrl+E` は常にフル解像度 (別経路)。設定は永続化される。
- 永続化は中央 `comic.db` (キーは `page_path_key` 系。ZIP / PDF・ネスト ZIP も対応) が正本。設定の
  バックアップ ON のときはフォルダ直下 `mimageviewer.dat` (サイドカー) にも dual-write し、フォルダ
  ごと移動しても保持される。注釈のあるページはサムネイル左上にピンクの「文」バッジを表示する。
- 注釈は最前面 (パイプライン最終段。ポストフィルタの後・切り取りの前) として、表示と
  保存 / コピー / 比較 / `Ctrl+E` 書き出しに焼き込まれる。サムネイルには焼き込まない。

### 8.9 開発者 / 診断

不具合報告時に、利用者がコマンドライン引数や `%APPDATA%` の手探りをせずに
ログを集められるようにするための機能群。

- **動作ログ (`mimageviewer.log`) は常時記録**: 旧仕様ではリリースビルドで
  `--log` 引数を付けないと記録されなかったが、「不具合が起きる前に有効化して
  いないと痕跡が残らない」問題があったため常時 ON にした。`--log` 引数は後方互換で
  受け付けるが現在は no-op。`logger.rs` が 16 MiB で `mimageviewer.log.bak` に
  ローテーションし、起動時に前回分を `mimageviewer.log.prev` に退避するため、
  長時間連続起動でもディスク使用量は上限固定。
- **`panic.log` のローテーション**: panic フックが書く `panic.log` は
  セッションを跨いで append し続けるため、同じ panic の連発で無制限に膨らみ得た。
  4 MiB 超で `panic.log.bak` に 1 世代退避してから作り直す (`main.rs`
  `append_panic_log_entry`)。
- **`perf_log_enabled`** (bool, デフォルト false): 性能ログ
  (`perf_events.jsonl`、構造化イベントログ) を記録するかの設定。フレーム単位の
  イベントを大量に吐くため常時 ON にはしない。起動時に 1 度だけ読まれ、ON なら
  `Settings::load()` 後に `perf::init_with_path` を呼んで有効化する
  (`perf::init` の START/FILE は `OnceLock` なので `--perf-log` 指定済みなら no-op)。
  変更は次回起動から反映。`--perf-log` 引数は従来どおり起動直後から全イベントを
  記録する開発者向け経路。
- **環境設定「開発者」タブ** (`PreferencesPage::Developer`): 上記 `perf_log_enabled`
  のトグルと、「ログを zip にする」ボタンを置く。
- **診断 zip 書き出し** (`diagnostics.rs` `export_diagnostics_zip`): logs ディレクトリの
  ログ群 (動作ログ・`panic.log`・`settings.log`・worker ログ・現行 `perf_events.jsonl`)
  と `system_info.txt` (バージョン/OS/GPU) を 1 つの zip にまとめ、デスクトップ
  (`SHGetKnownFolderPath(FOLDERID_Desktop)` で解決) に
  `mImageViewer_diag_<日時>.zip` として保存する。rotate 済みの perf 世代
  (`perf_events.1.jsonl` 等) は巨大なので除外する。

### Ctrl+E エクスポート

- フルスクリーン静止画 (`Image` / `ZipImage` / `PdfPage`) で `Ctrl+E` を押すと、現在の表示結果をファイルに書き出す。見開き表示中は左右ページを現在の配置のまま 1 枚の見開き画像として書き出す。動画や区切りアイテムでは無効。
- `Ctrl+E` のほか、**画像補正パネルのヘッダー右側に並ぶ処理順アイコン列** (`消しゴム / 補正レイヤー / 隠蔽加工 / エクスポート`) のエクスポートアイコン (`draw_export_icon`) からも開ける。補正パネルはホバー表示のオーバーレイなので、クリック時は `adjustment_mode` を `false` にして閉じてから `open_export_dialog_for_current` に合流する (= ビューモードへ戻して合成結果を書き出す)。`open_export_dialog_for_current` は補正 / 消しゴム / 隠蔽 / 分析モード中は弾く (`is_overlay_edit_mode_active() || adjustment_mode || analysis_mode`) ため、`Ctrl+E` 直接押下はこれらのモード中は無効。アイコン経路は補正パネルを閉じることでこのガードを通過する。
- 保存先は前回保存先 (`Settings::export_last_directory`) が存在すればそれを既定表示し、なければ元の場所を使う。ダイアログの「元の場所」ボタンで、通常画像は画像ファイルの親フォルダ、ZIP 内画像は ZIP ファイルの親フォルダ、PDF ページは PDF ファイルの親フォルダ、見開き合成は左ページ側の元フォルダへ戻せる。
- 出力名は既定で `<元名>_edited`。バッチ出力では `_0` (現在の設定) / `_1`〜`_4` (隠蔽プリセット) を付ける。同じ名前が存在する場合はセッション単位で `_0001` などを挟み、上書きしない。
- 出力形式は JPEG 95 / PNG / WebP。元形式が書き出し非対応の場合は `Settings::export_fallback_format` に従う。形式変換、PDF、見開き合成ではメタデータ保持は無効。
- 出力サイズは「そのまま」「1/2 サイズ」「1/4 サイズ」から選ぶ。crop / 見開き / 隠蔽プリセット合成後の画像を基準に Lanczos3 で縮小し、既定値は `Settings::export_default_scale` に保存する。
- JPEG / PNG / WebP の同形式出力では、`Settings::export_embed_metadata` が有効なら元画像の EXIF / XMP / PNG text / WebP metadata を転記する。ZIP 内画像は worker がエントリバイトを読み、パスの無いメタデータ元として扱う。JPEG の Orientation は表示で回転済みの画素と一致するよう正規化する。
- 永続化設定は `Settings::export_embed_metadata` (メタデータ保持)、`Settings::export_last_directory` (前回保存先)、`Settings::export_batch_selection` (現在 / プリセット 1〜4 のチェック状態)、`Settings::export_fallback_format` (非対応元形式の JPEG / PNG 選択)、`Settings::export_default_scale` (出力サイズ)。
- 保存は `ctrl-e-export` worker で順次実行する。隠蔽プリセットの合成、画像エンコード、メタデータ転記、ファイル書き込みはいずれも worker 側で行い、UI は進捗モーダルを `try_recv` で更新する。キャンセルは次のエントリ開始前に反映され、処理中の 1 件は完了まで待つ。
- 現在表示中の実フォルダへ保存した場合は、フルスクリーンを抜けて一覧へ戻ったタイミングでフォルダを再読み込みし、新しい出力ファイルのサムネイルを反映する。ZIP / PDF / 検索結果などの仮想フォルダでは自動再読み込みしない。

## 10. AI 機能詳細

### 10.1 AI モデル一覧

| モデル名 | 用途 | アーキテクチャ | サイズ | ライセンス |
|---------|------|--------------|--------|-----------|
| realesrgan-x4plus | アップスケール「写真・CG (ノイズ除去強)」 | Real-ESRGAN | ~33MB | BSD-3-Clause |
| realesrgan-x4plus-anime | アップスケール「イラスト・アニメ」 | Real-ESRGAN (6B 軽量版) | ~18MB | BSD-3-Clause |
| realcugan-x4-conservative | アップスケール「漫画 (トーン保持)」 | Real-CUGAN | ~5.4MB | MIT |

すべてのモデルは exe に `include_bytes!` で埋め込まれ、初回起動時に `%APPDATA%/mimageviewer/models/` に展開される（サイズ一致ならスキップ）。

### 10.2 JPEG ノイズ除去

JPEG 圧縮で発生するブロックノイズ・モスキートノイズを AI で除去する機能。

- **対象**: フルスクリーン表示中の画像（補正パネルから選択）
- **選択肢**: なし / JPEG (RealPLKSR)
- **処理順序**: ノイズ除去 → 補正 → アップスケールの順に適用
- **設定**: `AdjustParams.denoise_model` フィールドに保存 (グローバルまたはページ個別)
- **UI**: 補正パネルの「AI ノイズ除去」チェックボックスで切替。`ai_feature_mode=high_quality`
  のときだけ実行され、`disabled` / `light` では保存済み設定を保持したまま実行しない

### 10.3 AI アップスケール

ONNX Runtime + DirectML EP でタイル分割 4x アップスケールを実行。
環境設定「全体設定」の `ai_feature_mode` で利用範囲を選ぶ:

- `disabled`: 低スペック環境向け。AI アップスケール / AI ノイズ除去を実行しない。
  表示が重い環境ではこの設定を推奨する
- `light`: 軽め。自動判別は漫画を `Real-CUGAN 4x conservative`、
  それ以外を `Real-ESR General V3` に振り分ける。手動選択もこの 2 モデルに制限し、
  ノイズ除去は実行しない
- `high_quality`: GPU 負荷高め。全アップスケールモデルとノイズ除去を許可する。
  GPU によっては表示や処理に時間がかかるモデルが含まれる

`high_quality` では、画像タイプ自動判別（イラスト/漫画/3D/写真）に基づき、以下の
3 モデルに自動振り分け:

- イラスト・アニメ → `Real-ESRGAN Anime 6B`
- 漫画 → `Real-CUGAN 4x conservative`（スクリーントーン保持）
- 写真 / 3D → `Real-ESRGAN x4plus`（ノイズ除去強）

補正パネルから手動で次の補助モデルも選択可能（自動選択の対象外）:

- `4x-NMKD-Siax-200k`: 写真向け、フィルム粒子や布目など質感を残す
- `Real-ESR General V3`: 高速軽量、補正量控えめで破綻しにくい

モデル範囲の制限は実行時に適用される。ページ個別 / お気に入り標準 / グローバル
プリセットに保存済みの重いモデル設定は削除せず、モードを `high_quality` に戻すと再び有効になる。

### 10.4 非破壊 AI 修復（消しゴムモード）

フルスクリーンで E キーを押すと消しゴムモードに入り、画像の任意領域をマスクして MI-GAN で補完する。
元画像ファイルは一切変更しない（非破壊）。修復情報はマスクとして DB に保存され、表示時にリアルタイム適用。
タイル分割方式（512×512、64px オーバーラップ、線形ブレンド）で元解像度を維持。

- **ツール**: 筆、囲み、直線、縦線、横線、矩形、楕円、選択
- **描画/消去モード**: 筆/囲みはビットマップ下地を直接追加・削除。直線/矩形/楕円などのオブジェクトは
  作成順に `add` / `subtract` として重なり、消去モードでも既存オブジェクトは丸ごと削除しない
- **画像端の編集**: 筆と囲みはドラッグ点が画像外にはみ出しても保持し、画像範囲に重なる部分だけを
  クリップしてマスクへ反映する。同じマスク編集 UI を使う隠蔽加工でも同じ挙動にする
- **ホイール操作**: 消しゴム / 隠蔽加工中の画像上ホイールは、修飾キーなしでも
  `Ctrl+ホイール` でもズーム専用。パネル上の修飾なしホイールはパネルスクロールに使う
- **選択表示**: 選択ツール中は全ベクタをアウトライン表示し、合成マスクでは透明になる `subtract`
  オブジェクトもクリック対象として視認できるようにする
- **マスク永続化**: SQLite (`mask.db`) に deflate 圧縮した 1bit/pixel マスクと Shape JSON を保存。次回表示時に自動適用
- **マスクスロット**: 消しゴムは `F7` / `F8`、隠蔽加工は `F9` / `F10` でスロット 1 / 2 を適用。
  `Shift` を付けると現在ページまたはグリッドの対象ページから適用済みマスクを削除する
- **PDF 対応**: ズーム再レンダリングでサイズが変わった場合、マスクを最近傍法でリスケール
- **復元**: マスク全削除でいつでも元画像に戻せる

### 10.5 補正レイヤー

フルスクリーンの画像補正パネル右上に並ぶ処理順アイコンから「補正レイヤー」を開き、
マスク付きの非破壊フィルタを画像ごとに重ねられる。サムネイル画像には補正レイヤー結果を反映せず、
設定があるページにはバッジで示す。

- **UI**: `local_adjust_lab` と同じ左パネル + 右ツールパネル構成。左パネルはレイヤー一覧、
  効果選択、手描きツール選択を持ち、右上の `×` または `Esc` で閉じる。右パネルは
  ツール設定 / マスク設定 / 効果パラメータを表示する
- **レイヤー**: 1 レイヤーにつき 1 効果。全体 / 手動 / 線形・円形グラデーション /
  輝度・カラー範囲 / 被写体 / 領域分割のマスクを選べる。追加後も `マスク種類変更` で
  効果を残したままベースマスクを差し替えられる
- **効果**: `local-adjust-core` の全 `LocalEffect` を効果ピッカーから検索して選択できる。
  効果パラメータはコピー / ペースト / リセットに対応し、スポイトや位置ハンドル付き効果は
  画像上クリック / ドラッグで操作できる
- **プレビュー**: 変更直後は補正レイヤー抜きの下位画像を即時表示し、CPU worker の非同期合成が
  完了した時点で補正レイヤー込みの表示へ差し替える
- **書き出し**: Ctrl+E / キャプチャ保存では補正レイヤー結果を含める。補正レイヤーが有効な場合は
  最新の `local_adjust_cache` が揃ってから書き出す

## 11. セキュリティ方針

- 画像デコードは `image` クレート（純粋Rust・メモリ安全）を基本とする
- HEIC / AVIF / JXL / TIFF / RAW は Windows の WIC (Windows Imaging Component) 経由でデコード。
  WIC 呼び出しは `unsafe` ブロックに局所化（`src/wic_decoder.rs`）
- NVIDIA NGX 呼び出し部分も `unsafe` ブロックに局所化（Phase 2、未実装）
