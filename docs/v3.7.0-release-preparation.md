利用者の離席前指示により、リリース公開は帰還後に行う。署名付きバイナリの作成・検証までは
継続し、SimplySignログイン期限切れで停止した場合は生成済み成果物を保持して再ログインを待つ。
エージェントによるログインGUI操作や期限切れ後の反復試行は行わない。
利用者が帰還しSimplySignログイン済みと明示したため、portableの署名・パッケージを再開する。
再開経路の独立レビューは完了済みで、同一成果物の前提を再確認してから実行する。
署名済み成果物の引渡し後、利用者から「動作大丈夫そうです。公開作業お願いします」と
実機動作の了承と公開の明示依頼を受領した。公開commit・push・tag・Release作成を進める。
この動作了承だけで個々の性能計測が実施済みとは扱わず、必須記録の有効範囲を確認する。
記録照合で現行版のperf smoke（CLAUDE §9.6）とidle-health 4状態（§9.7）が未計測と判明し、
利用者へ報告した。利用者は「今回に限りこの性能計測を省略し、未計測と記録して公開する」と
明示回答した。v3.7.0だけの限定waiverとして公開を進め、性能計測をPASSとは扱わない。
自動テスト・署名検証・実データ保護・以降の版の必須計測要件は変更しない。
mikage.toへのアップロードは利用者がGitHub Release公開後に行う。こちらはGitHub公開を担当する。

  製品の必須実機検証を免除するという意味ではない。
