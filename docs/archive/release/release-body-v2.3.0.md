## mImageViewer v2.3.0

音声ファイルを波形とスペクトラムで見ながら聴ける「音楽再生ビュー」を追加し、別ウィンドウ表示を作り直して「複数ウィンドウ」モードを新設しました。ファイルやフォルダの名前を変更しても、レーティングやタグなどの設定が引き継がれるようになっています。

このリリースノートは要点をまとめた短縮版です。全項目は README の更新履歴を参照してください: https://github.com/MikageSawatari/mimageviewer#更新履歴

## 主な新機能

- **音楽再生ビュー**: 音声ファイル（MP3 / FLAC / WAV / M4A / AAC / OGG / Opus / WMA）を一覧からそのままフルスクリーンで再生できます。曲全体を行に分けたステレオ波形のタイムラインと、半音ごとのバー＋88 鍵のピアノ鍵盤が音にあわせて光るスペクトラム表示で、曲の構造を目で追いながら聴けます。波形の下には音量・推定ベース音・推定キーの分析レーンも並びます。レーティング（★）・タグ・ブックマーク・検索は画像や動画と同じ仕組みで使え、シーク・倍速（音程はそのまま）・ループ・連続再生や、音量の自動調整（ラウドネス）・VST3 プラグインにも対応します。
- **音声モード**: 動画の再生中に上部バーの ♪ ボタンまたは <kbd>Z</kbd> キーで、映像を消して音声だけを聴けます。音は途切れず、再生位置・音量・VST3 の状態はそのまま引き継がれます。音声モードのまま前後のファイルへ移動したり、連続再生を続けたりできます。
- **ビューワモード（複数ウィンドウ）**: 環境設定に「ビューワモード」を新設しました。「複数ウィンドウ」では画像を開くたびに新しいウィンドウとして残り、一覧のフォルダ移動やページ送りをしても各ウィンドウは独立したままです（このモードのウィンドウは表示専用）。動画・音声は専用のメディアウィンドウを使い回します。別ウィンドウで再生を続けたまま他のウィンドウを操作でき、ウィンドウの開閉・切り替えまわりを大きく安定化しました。
- **フル機能ウィンドウでも動画・音声だけを別ウィンドウで再生**: 「フル機能ウィンドウ」を選んだまま「動画・音声は別ウィンドウで再生」をオンにすると、動画・音声だけが独立したメディアウィンドウで再生されます。再生を続けたままメインウィンドウで画像を閲覧でき、<kbd>F12</kbd> でメインウィンドウ表示と切り替えられます。
- **名前を変更しても設定が引き継がれます**: これまでは名前を変更すると、レーティング（★）・タグ・回転・補正・マスク・ブックマーク・再生位置・続きから読むページ・PDF のパスワードなどが古い名前に残ったままでした。アプリ内で名前を変更したときは、これらを新しい名前へ自動的に引き継ぎます。フォルダなら中のファイル、ZIP / PDF なら中のページの設定もまとめて引き継ぎます（エクスプローラーなどアプリの外で変更した場合は対象外です）。
- **削除するとレーティング・タグ・補正などのデータも一緒に消えます**: これまでは、ファイルを削除しても付けていたレーティング・タグ・補正・回転などのデータが残ってしまうことがありました。今回から、削除するとこれらも一緒に消えます。以前の削除で残ったデータは「設定 → サムネイルキャッシュ管理 → メタデータを整理…」でまとめて掃除できます。
- **アニメーション WebP の再生に対応**: これまで先頭のコマだけを静止表示していた Animated WebP を、GIF / APNG と同じようにフルスクリーンで自動再生します。
- **モアレを目立ちにくくするポストフィルタ**: トーンを貼った漫画や大きなスキャン画像に出る縞模様（モアレ）を、表示前に縮小して和らげる「1/2 縮小」「1/4 縮小」を追加しました。

## 操作・表示の改善

- **ホイールクリックや最小化を割り当てられます**: 「操作カスタマイズ…」の「マウスボタン」で、戻る / 進むボタンに加えてホイールの押し込み（短いクリック）にも一発アクションを割り当てられます（既定はなし）。リングショートカットやマウスボタンに「ウィンドウ最小化」も追加しました。
- **ZIP / PDF / 対応アーカイブの開き方を選べます**: 全体の設定に関わらず、その場で「ページを開く」「一覧を開く」を選べる操作を追加しました。右クリックメニューのほか、キー・リング・マウスジェスチャにも割り当てられます。
- **連結読みでもスライドショーを再生できます**: 縦・横の連結スクロール表示では、ページを切り替える代わりに待ち時間ごとに少しずつスクロールします。待ち時間・スクロールにかける時間・1 回のスクロール量を個別に設定できます。
- **細かな使い勝手**: A / B のクイックフォルダがドライブごとの最後の場所も覚えるようになりました。お気に入りの登録上限を 100 件に増やしました。詳細表示・ツールチップの「長さ」「コーデック」列を音声ファイルにも対応させました。隠蔽加工のブラシで、カーソル位置に適用範囲を表示するようにしました。

## 安定性・パフォーマンス

- 複数ウィンドウ利用時のサムネイル読み込みの安定性と効率を改善しました（別ウィンドウの表示中に重複して読み込まれる問題、動画サムネイルが出なくなる問題を修正）。
- 別ウィンドウで音楽を再生しながら画像を閲覧する際の負荷を大幅に軽減しました。
- 再生中・表示中のファイルを削除したり名前を変更したりしたとき、そのファイルを表示している別ウィンドウを自動的に閉じ、削除が失敗しないようにしました。
- 長い音声ファイルを続けて切り替えたときに、メモリ使用量が一時的に大きく増える問題を修正しました。
- 壊れた音声 / 動画ファイルを開いた際の異常動作（フリーズ等）を防ぐようにしました。

## 主なバグ修正

- スタック表示のフラット読書中に <kbd>Shift</kbd>+<kbd>↓</kbd> / <kbd>Shift</kbd>+<kbd>↑</kbd> のスタックジャンプが効かない問題を修正しました。
- 動画のシークバーの上でもホイール操作が効くようにしました。
- 音声モード中のシーク・前後移動・右クリック操作・ブックマーク表示、音楽タイムラインの自動スクロールやシークを修正しました。
- レーティング一覧から開いた本での戻る操作、見開きのページ移動を修正しました。
- トレイから終了したときに、動画・音声の再生位置が保存されない問題を修正しました。
- 重なり合った別ウィンドウをクリックしたとき、最前面のウィンドウが確実に操作対象になるようにしました。
- 別ウィンドウで再生中の動画にタグを付けたときに通知がメインウィンドウにも二重表示される問題と、別ウィンドウを開いたまま一覧でタグを付けると別ウィンドウの表示中項目に付いてしまう問題を修正しました。
- テンキーへのキー割り当て、ゲームパッド操作の細かな不具合を修正しました。
