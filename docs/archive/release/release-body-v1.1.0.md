# v1.1.0 Release Notes Draft

## 補正パイプラインの再構成

画像補正、AI アップスケール / デノイズ、ポストフィルタを最終表示段へ移動しました。消しゴム、補正レイヤー、隠蔽加工、crop は source 解像度の edit pipeline として先に確定し、その後に最終段の見た目を重ねます。

- 補正スライダーの drag 中に edit 系 cache を再計算しないため、反応が大幅に軽くなります。
- アップスケール ON/OFF でマスク解像度が変わらず、マスク消失や resize ずれを避けます。
- AI 系は edit 後の安定した source 解像度結果を入力にするため、既存画像の見た目が以前と少し変わる場合があります。品質改善方向の変更として一括移行し、legacy pipeline トグルはありません。

## 補正レイヤー性能改善

- `local-adjust-core` の pixel loop と post-filter 系処理を Rayon で並列化しました。
- 手描きブラシ stroke 中は in-memory 更新を優先し、重い効果再計算を 150ms idle まで遅延します。
- release 時は遅延をキャンセルして 1 回だけ確定再計算します。

## エクスポート出力サイズ

Ctrl+E のエクスポートダイアログで「そのまま」「1/2 サイズ」「1/4 サイズ」を選べるようになりました。crop / 見開き / 隠蔽プリセット合成後の画像を基準に Lanczos3 で縮小します。

## 互換性メモ

- 既存の `.miv` / DB データ形式は変更しません。
- サムネイルは色調補正のみを反映し、edit 系・AI・post_filter は反映しません。
- post_filter は最終段の表示効果になったため、消しゴム / 隠蔽加工 / 補正レイヤーとの重なり方が旧版と異なることがあります。
