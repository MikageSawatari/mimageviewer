# サイト用サムネイル表示時間の計測 (2026-09-27)

`htdocs/mimageviewer/guide-fast-browsing.html` の「計測した表示時間」の出どころ。
計測者: ClaudeCode (計測用プログラムの実行のみ。アプリの画面は起動していない)。

## 条件

- コード: `v4.1.0` (8d95fffe5) を作業ツリー `C:\home\mimageviewer-bench` に取り出し、
  `cargo build --release --features dev-tools --bin bench_scroll` でビルド
- 対象: `D:\home\image10000` (102,627 件 = PNG 102,625 + ZIP 1 + MP4 1。利用者の生成画像のコピー)、
  SATA HDD (WD80EAZZ)
- 機材: Windows 11 Pro、Intel Core Ultra 9 285 (24 コア)、メモリ 128 GB。ワーカー 22 本
- data dir は `--data-dir C:\home\mimageviewer-bench\target\bench-data` に分離 (利用者の `%APPDATA%\mimageviewer` は不使用)
- 一覧 5 列 × 4 行 (20 枚)。`bench_scroll` は 1 行 30 ms でスクロールを再現し、停止後の時間を測る
- 1 回の実行で 2 パス: `With cache` = カタログ (保存済みキャッシュ) を使う。`--delete-cache` 付きの回では
  カタログが空なので「キャッシュなし・ファイルを初めて読む」になる。`Without cache` = 同じ回の 2 パス目で、
  キャッシュを使わず作り直すが、ファイルは 1 パス目で OS のファイルキャッシュに載った後
- ほかのセッションのビルドなど負荷がある中での計測。場面ごとに 3 回測り、ページには最良値を使った
