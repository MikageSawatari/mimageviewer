## P0（基本操作が壊れている / 主要機能が無反応）

### ☐ B1. 一覧の操作ボタン（削除/複製/↑/↓）が機能しない
- 症状: 左オブジェクト一覧で選択→削除/複製/↑/↓ を押しても効かない。フォーカスが外れるだけ。
- 関連: `object_list_actions_ui` (ui_text.rs)。ロジックは正しく見える → write-back / canvas 再描画 /
  入力レイヤ（sink）/ 選択クリアのどこかが原因。
- task #7

### ☐ B2. 編集パック / オノマトペの DL ボタンが無反応
- 症状: 「編集用追加ファイルが必要です」の右 DL ボタン・オノマトペ追加パックボタンを押しても何も
  起きない。
- 関連: `editing_addon` ダウンロード起動の配線（ボタン→DL 開始）。公開済み `editing-pack-v1` から
  取得できること。
- task #8

### ☐ B3. ウィンドウ「枠」タブで右パネル幅が変わり、セリフに戻れない
- 症状: ウィンドウ選択→枠タブで右パネル横幅が変化。その状態でセリフタブをクリックしても切替不可
  （パネル幅変化でクリックがパネル外判定）。枠詳細の「種類」が横にはみ出している。
- 関連: `window_body_ui`（枠タブ）内の widget が PANEL_W を超える → パネルが広がる。幅を固定し
  はみ出す widget を折返し/縮小。
- task #9

## P1（機能不全 / 入力・表示の不具合）

### ☐ B4. 「下の吹き出しと結合」が効かない
- 症状: 結合トグル ON でも union 描画されない。
- 関連: トグル→`b.merge_with_below`→ベイクの union 経路（comic-core）。
- task #10

### ☐ B5. セリフ本文の IME 確定 Enter で改行が入る
- 症状: multiline TextEdit で IME 変換確定の Enter が「確定＋改行挿入」になる。
- 関連: egui IME 既知問題。確定 Enter を改行として扱わない（ime_composing 直後の Enter 抑制等）。
- task #11

### ☐ B6. 追加ダイアログのタイトル文字色・×ボタンが見づらい
- 症状: 吹き出し追加等のダイアログ上部タイトル文字色が見づらく、右上 × も見づらい。ラボは適切。
- 関連: 暗フレーム上のタイトルバー/× のコントラスト（visuals override / タイトル色）。
- task #14

---

## P2（使い勝手 / 設計変更要望）

### ☐ B7. 一覧の操作行をリスト直下に置き、溢れ時のみスクロール
- 要望: ↑↓複製削除 の操作行が body 最下部に離れて使いづらい。ラボのように一覧の直下に付け、
  左パネルから溢れるときだけ一覧＋操作行をスクロールさせる。
- 関連: `draw_text_panel` の allocate_ui / ScrollArea レイアウト再構成。
- task #12

### 💬 B8. システムフォントへのフォールバックを廃止
- 要望: 既定でシステムフォント表示になるフォールバックを無くす。フォントが使えない場合は追加
  させない（後からフォント追加で保存済みの見た目が変わるのを防ぐ）。
- 検討点: 既定フォント（COMIC_FONT_KEY）の扱い、フォント未ロード時の挙動、既存ドキュメントとの
  互換（未リリースなので破壊的変更可）。方針をユーザーと確認してから着手。
- task #13
