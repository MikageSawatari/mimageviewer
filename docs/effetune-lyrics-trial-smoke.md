# 歌詞連携の試作 実機確認の手順

試作の確認用ビルドで、音響調整の Visualizer に歌詞が音と合って出るかを確かめる手順です。
設計の正本は [effetune-lyrics-trial-plan.md](effetune-lyrics-trial-plan.md) の §6.2・§6.3。
この試作は配布しません。所要時間の目安は 30〜40 分です (#11 は任意)。

## 0. 先に知っておいてほしいこと

- 確認用ビルドは隔離したデータフォルダで起動します。mIV の設定・キャッシュ・ログは普段のものと分かれます。
- 音響調整の Visualizer のレイアウトも、試作では普段のものと分かれます (試作の host の名前を変えています)。
- **分けられないもの**: 音響調整 (Mixwright) の設定画面の内容とエフェクトのプリセットは DAW と共有です。
  確認中は **設定画面を変えず、プリセットを保存しない** でください。エフェクトの追加・変更は、保存しなければ問題ありません。
- 初回の起動時に、音響調整の画面の案内 (ツアー) が出るかもしれません。閉じてかまいません。

## 1. 準備

1. インストール版・常駐 (トレイ) の mIV をすべて終了します。
2. PowerShell で次を実行して起動します。

```powershell
Set-Location G:\home\mimageviewer-lyrics
Start-Process -FilePath .\target\dev-runtime\mimageviewer-core.exe -ArgumentList '--data-dir', 'G:\home\mimageviewer-lyrics\target\lyrics-trial\data', '--perf-log'
```

3. 起動したら、次を実行して記録ファイルができていることを確かめます (`perf_` で始まるファイルが 1 つ出れば OK)。

```powershell
Get-ChildItem G:\home\mimageviewer-lyrics\target\lyrics-trial\data\logs
```

4. mIV で `G:\home\mimageviewer-lyrics\target\lyrics-trial\assets` を開きます。
5. `beep-60s.flac` を開いて再生を始め、ツールバーの **音響調整** ボタンで音響調整の窓を開きます。
6. 音響調整の窓の上部の **Visualizer** ボタンで Visualizer に切り替えます。

## 2. 測定用レイアウトを作る

演出 (行が動くアニメーション) が測定に混ざらないよう、Lyrics を 1 つだけ置いた設定で比べます。

1. Visualizer で **Edit** を押して編集画面にします。
2. **追加** から **Lyrics** を選びます。キャンバスにできた Lyrics を、ハンドルで大きく広げます (数字が読みやすい大きさに)。
3. Lyrics を選んだ状態で、右側の設定を次のとおりにします。

| 項目 | 値 |
| --- | --- |
| 表示 | 一覧 |
| スクロール | ステップ（縦） |
| ステップ遷移時間 | 0 |
| 現在行の位置 | 50% |
| 単語のハイライト | オフ |
| オフセット | 0 |
| フェードイン時間 | 0 |
| フェードアウト時間 | 0 |

4. 編集を終えます (変更はその場で反映され、自動で残ります)。

比べる瞬間は「**中央の行の数字が次の数字に変わった瞬間**」と「**ビープの鳴り始め**」です。
数字は 2 秒ごとに 01, 02, … と進み、ビープも 2 秒ごとに鳴ります。

## 3. 確認

それぞれの結果を「OK / 気になる点」で教えてください。**#2 の値は符号 (＋ / −) も**教えてください。
操作は表の順番どおりに進めてもらえると、記録の分析がしやすくなります。

| # | 操作 | 見るところ |
| --- | --- | --- |
| 1 | 測定用レイアウトで `beep-60s.flac` を 1.0 倍で再生する | 数字の切り替わりとビープが合っているか。早い / 遅いと感じるか |
| 2 | Lyrics の **オフセット** を ±0.05 秒ずつ動かし、いちばん合う値を探す (正の値で歌詞が遅れて出ます) | いちばん合う値と、そのとき使っていた出力機器 (スピーカー / ヘッドホン / Bluetooth など)。機器を替えられるなら、替えたときの値も |
| 3 | オフセットを 0 に戻す。再生中に一時停止して 3 秒待ち、再開する | 停止中に数字が進まないか。再開後すぐ合うか |
| 4 | シークバーをクリックして前後に飛ぶ。続けて ← / → キーで飛ぶ | 飛んだ先の数字に切り替わるまでに、目立つ遅れがあるか |
| 5 | 下部 HUD の速度ボタンで 0.5 倍、続けて 2 倍にする (オフセットは 0 のまま) | 数字の切り替わりがビープに付いてくるか。終わったら 1.0 倍に戻す |
| 6 | L キーでループを「全体ループ」にして、曲の終わりまで再生する | 曲頭に戻ったとき 01 に戻るか。終わったらループを戻す |
| 7 | ↓ キーで別の曲 (`sjis-test.flac` など) に移り、↑ キーで `beep-60s.flac` に戻る | 前の曲の歌詞が残らないか。切り替えた直後に別の曲の歌詞が一瞬出ないか |
| 8 | 再生中に音響調整の窓を閉じて、ツールバーから開き直す | 開き直した直後から正しい数字か |
| 9 | `beep-video.mp4` を再生する (映像の中央に秒数が出ます) | 映像の秒数・ビープ・数字がそろうか |
| 10 | 次の各ファイルを再生する: `sjis-test.flac`、`upper-case.flac`、`embedded-timed.mp3`、`embedded-timed.m4a`、`embedded-plain.flac`、`plain-lrc.flac`、`no-lyrics.flac` | 歌詞が出るか、文字化けしないか (`sjis-test` は「番目」が付きます)。時刻なしの 2 つ (`embedded-plain`・`plain-lrc`) は曲の進みに合わせて流れるか。`no-lyrics` で前の歌詞が残らないか |
| 11 | (任意) mIV Remote で曲を再生してから終了し、PC で別の曲を再生する | Remote を終えた後に古い歌詞が戻らず、新しい曲の歌詞に切り替わるか。Remote 中は音響調整の窓は開けません (仕様) |
| 12 | Visualizer のプリセットから **Lyric Stage** を選び、手元の実際の曲と同名の `.lrc` で再生する (お持ちなら) | 実用上ずれが気になるか (主観で構いません。演出込みの見え方です) |

## 4. 終わったら

1. mIV を終了します。
2. 次のフォルダのファイルを、そのままの場所に置いておいてください (こちらで読みます)。
   - `G:\home\mimageviewer-lyrics\target\lyrics-trial\data\logs\perf_*.jsonl` (位置と時計の記録)
   - `G:\home\mimageviewer-lyrics\target\lyrics-trial\data\logs\mimageviewer.log` (プラグイン内の往復時間と描画間隔の記録)
3. 結果は # ごとに「OK / 気になる点」と、#2 の値 (符号つき) と出力機器を教えてください。
