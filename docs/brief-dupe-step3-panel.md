## 2. 右パネルを「情報」/「類似」の 2 タブにする

対象は [ui_metadata_panel.rs](../src/ui_metadata_panel.rs)。
**タブの実装は同ファイルの `draw_tag_picker_tabs` が先例。新規に作らない。**

- 既定は「情報」。**現在の見え方を変えないこと** (タブが増える以外)
- タブの選択状態はパネルを閉じても保つ (どちらを見ていたか)

### 2.1 「類似」タブの中身

いま見ている画像の別バージョンを**距離の近い順**に並べる。1 行 = サムネイル + 違い + 場所。

**違いの見せ方は §7 に従う。事実だけを書き、解釈を書かない。**

| 出す | 出さない |
| --- | --- |
| `2400×3200` (この画像は `1200×1600`) | 「高画質」「こちらを残すべき」 |
| `PNG` / `JPEG` / `WebP` | 「可逆だから上位」 |
| `4.2 MB` | 「大きいので元」 |
| 帯の名前 (§2.2) | **距離の生値** |
| 属するフォルダ / 本の名前 | |

### 2.2 帯 (§9.5、実測値)

| 表示 | PDQ-256 距離 |
| --- | --- |
| **ほぼ同一** | ≤ 8 |
| **別バージョン** | 9〜48 |
| (出さない) | 49 以上 |

2 つの帯は**見出しで区切って混ぜない**。距離の数値は出さない。

### 2.3 行の操作

- **クリックでそこへ移動する。これがこの機能の主目的** (§0)。
  既存の「この場所を開く」経路に乗せる。新しいナビゲーション経路を作らない
- **`X` で比較スロットへピン留め** → 既存の `FsCompareToggle` / `Wipe` / `Diff` へ。
  **新しい比較 UI を作らない** (§9.4)

### 2.4 出せない状態を型で表す (§5.2)

**無言で 0 件を返さない。** 次を区別して文言を出し分ける:

| 状態 | 表示 |
| --- | --- |
| 索引が未作成 | 「索引がありません」+ 環境設定へ誘導 |
| 索引を読み込み中 | 「準備中」 |
| この画像が索引に無い | 「この画像は索引に含まれていません」 |
| `quality = 0` (featureless) | **「この画像は特徴が少ないため判定できません」** |
| 索引にあり、該当なし | 「別バージョンは見つかりませんでした」 |

Step 2b の API が既に型で返しているはずなので、**UI 側で `Option` に潰さないこと。**

## 3. UI スレッドを止めない ([ui-responsiveness.md](ui-responsiveness.md) §4 必読)

- **索引のロードは UI スレッドで行わない。** 100 万行の読み出しは秒単位。
  「類似」タブを最初に開いた時点でワーカーに投げ、それまで「準備中」を出す
- **検索そのものは同期でよい。** 在メモリの線形走査で 100 万件 1.6 ms の実測 (§4.1)。
  画像を切り替えるたびに引き直してよい
- 行のサムネイルは既存のサムネイル経路に乗せる。**この UI から同期デコードしない**
- 結果の構築でパスの `metadata()` / `is_file()` を呼ばない (§4 チェックリスト)

## 4. 既存の規約

- **キー操作を足すなら `KeyAction` 経由** ([keymap-spec.md](keymap-spec.md))。
  `ini_name()` / `context()` / `trigger()` / `default_chords()` / `ALL_ACTIONS` /
  `docs/keymap.ini.default` を揃える。**固定キーにする場合は理由を keymap-spec に書く**
- **UI 文字列の絵文字・環境依存記号を使わない** ([CLAUDE.md](../CLAUDE.md) のグリフ節)。
  コミット前に `python scripts/check_ui_glyphs.py` を通す
- **TextEdit を足すなら `crate::ime_focus` の helper 経由**。Enter/Escape は
  `dialog_enter_pressed` / `dialog_escape_pressed` を使う
- パネルのサイズ確保は既存の `Area` + `Frame::popup` の規約に従う
  (CLAUDE.md「パネル (Area + Frame::popup)」節)
- **detached viewer の述語・viewport 経路に触れないこと。**
  触る必要が出たら、実装せずに質問として残す (リワーク中の凍結ルール)
