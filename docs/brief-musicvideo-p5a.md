## 2. 作業範囲（D17 の 1〜5）

1. **円形スペクトラムの内側の円を割合に**（`musicvideo-core` の `SpectrumShape::Radial`、`raster.rs` の
   `radial_spectrum_bars`、`scene.rs` の `modulate_spectrum_shape`、`preset.rs`、UI の円形の設定欄）
   - `radius_px` を廃止し、外径（矩形の短辺 / 2）に対する割合 `inner_ratio`（0〜1、範囲外は丸める）にする。
     バーは内側の円から矩形の端まで伸びる（現在の `available` の考え方は維持）。太さは px のまま。
   - 既定値: `default_project` の円形は従来の見た目（380 / 550）に合わせる。`new_radial_spectrum_layer` は従来の
     `min(w, h) * 0.24` を新規矩形の外径で割った値。UI 側の形切り替えで円形にしたときの既定（`lib.rs` の 380.0）も割合にする。
   - UI: 「内側の円 NN %」のように % で表示・入力し、「バーは枠の端まで伸びます」の短い説明を添える。
   - `ModulationTarget::SpectrumRadius` は内側の円の割合への加算に変える（UI の量の表示は %）。項目名は内容に合わせる。
   - 未リリースなので保存形式の移行は作らない（コミットメッセージに一言）。
2. **`Scale` 変調をレイヤー全体の拡大縮小に**（`scene.rs` の評価と、各レイヤー種別の描画）
   - 矩形の中心を基準に矩形を拡縮するのに加え、そのレイヤーの見た目の px 値に同じ倍率をかける。対象をコードから
     列挙して漏れなく扱う（少なくとも: Text / TimeText / Lyrics の文字の大きさと装飾の太さ・オフセット、グロー半径・広がり、
     角丸、進捗バーの枠線、スペクトラムの太さ・最小高さ、鍵盤の px 値があればそれも）。割合で持つ値には倍率をかけない。
   - 倍率の適用は scene（評価結果）で 1 か所にまとめ、プレビューと書き出しが同じ経路を通ること（D1 / H3b）。
     描画側に種別ごとの倍率処理を散らさない。
   - UI の項目名を「全体の拡大縮小」にする。静的な矩形の幅・高さの編集では文字の大きさ等を変えない。
   - 拡縮が 1.0 のとき（割り当てなし）の書き出し画素は変わらないこと。
3. **割り当ての量の初期値を対象の単位に合わせる**（`musicvideo-ui/src/modulators.rs` の追加時 `amount: 0.25`）
   - 対象ごとの既定表を 1 か所に置く。目安: 不透明度 0.25、全体の拡大縮小 0.05、回転 5°、角丸 8px、グロー半径 8px、
     グローの濃さ 0.25、塗りの明るさ 0.2、スペクトラムの太さ 2px、内側の円 3%。割り当て先を変えたとき、量が
     まだ初期値のままなら新しい対象の初期値にする（利用者が変えた量は上書きしない）。
4. **画像レイヤーの枠への合わせ方**
   - 画像レイヤーの設定欄に `Fit` の選択（切り抜いて埋める / 全体を収める / 引き伸ばす）を出す。通常の編集として履歴・
     Undo・未保存判定に乗せる（既存の編集入口と同じ）。
   - 「＋ レイヤーを追加 → 画像」で足した画像（`ImageLoadTarget::AddLayer`）は、画像の縦横比を保って出力に収まる大きさで
     中央に置き、`Contain` にする。画像の大きさは読み込み完了時に分かるので、その時点で矩形を決める（追加の非同期状態を
     増やさない）。背景（既定の背景レイヤーと「背景画像を開く」= `Replace`）は従来どおり `Cover`。
5. **レイヤー一覧の操作ボタンを固定位置に**（`musicvideo-ui/src/lib.rs` の `layer_list`）
   - 見出し・説明・操作ボタン（一覧の上へ・一覧の下へ・削除・＋ レイヤーを追加）を一覧の上に固定し、レイヤー名の一覧だけを
     スクロールさせる。レイヤーが増えてもボタンの位置が動かないこと。
   - 既存の UI レイアウトテスト・IME テスト（`layout_tests.rs` 等）を新配置に合わせる。

## 3. テスト

- 円形: 内側の割合と矩形から内径・バーの最大長が決まる。矩形を 2 倍にすると内径・バー長も 2 倍。
- `Scale` 変調: 円形で内径が比例して大きくなる（書き出し RGBA で確認するテストを 1 つ）。文字レイヤーで文字の大きさが
  倍率どおりに変わる。拡縮 1.0 で全種別の RGBA が変わらない（既存の画素テスト・ハッシュで確認）。
- H3b（プレビューと書き出しの一致）のテストに、`Scale` 変調ありの円形スペクトラムのケースを 1 つ足す。
- 量の初期値: 対象を変えたとき初期値のままなら追従し、利用者が変えた値は保持される。
- 画像: AddLayer で縦横比どおりの矩形と `Contain`。Replace は `Cover` のまま。`Fit` の変更が Undo / Redo に乗る。
- 一覧: レイヤー数を増やしてもボタンの矩形が変わらない（layout テスト）。
- 各新テストが、意図的に壊した実装で落ちることを確かめて記録する。
- 確認コマンド（`MSBUILDDISABLENODEREUSE=1`）:
  ```
  cargo test -p musicvideo-core -p musicvideo-ui -p musicvideo-editor
  cargo fmt --check
  python scripts/check_ui_glyphs.py
  .\scripts\build-dev.ps1
  ```
  本体（`mimageviewer`）の mvexport に触れた場合は `cargo test -p mimageviewer --lib -- mvexport` 相当の focused も回す
  （filter なしの本体 lib 全件は `.\scripts\test-lib-full.ps1` 経由。必要な場合だけ）。
