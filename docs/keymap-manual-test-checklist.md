# キー入力 / 操作カスタマイズ 手動検証チェックリスト

Win32 key edge queue / 日本語キーボード固有キー / テンキー分離 / native 動画経路を触ったときの手動確認メモ。全コマンドを総当たりするのではなく、入力トランスポートと文脈ごとの代表経路を確認する。

## デバッグ表示

`MIV_KEY_DEBUG=1` を設定して起動すると、ログに `[key-debug]` 行が出る。画面右上のオーバーレイも必要な場合だけ、追加で `MIV_KEY_DEBUG_OVERLAY=1` を設定する。

PowerShell 例:

```powershell
$env:MIV_KEY_DEBUG = "1"
cargo run --bin mimageviewer-core
```

オーバーレイも使う場合:

```powershell
$env:MIV_KEY_DEBUG = "1"
$env:MIV_KEY_DEBUG_OVERLAY = "1"
cargo run --bin mimageviewer-core
```

確認するログの見方:

- `raw main down ... vk=... scan=...` はメインウィンドウの Win32 key edge queue に届いた生キー。
- `raw native-video down ...` は native 動画 HWND に届いた生キー。
- `consume ... chord=...` は `consume_action` 系で実際に消費された操作。
- `pressed ... chord=...` は `pressed_action` 系で成立した操作。連続判定は短時間で間引かれる。
- `native_match ... chord=...` は native 動画側の `matches_vk_action` で一致した操作。

## 事前準備

| 結果 | 確認項目 |
|---|---|
|  | 通常起動ではデバッグログ / デバッグ表示が出ない |
|  | `MIV_KEY_DEBUG=1` 起動で `[key-debug]` ログが出る |
|  | `MIV_KEY_DEBUG_OVERLAY=1` 併用で右上にデバッグ表示が出る |
|  | 何かキーを押すと `raw main down/up` がログまたはオーバーレイに出る |
|  | 操作が発火したキーでは `consume` または `pressed` が出る |

## 日本語キーボード / テンキー

一時的に、発火しても影響が小さい操作へ割り当てて確認する。例: 表示切替、ショートカット一覧、スタック表示など。

| 結果 | 確認項目 |
|---|---|
|  | `^` キーをキャプチャでき、実キーで発火する |
|  | `@` キーをキャプチャでき、実キーで発火する |
|  | `￥` キーをキャプチャでき、実キーで発火する |
|  | `＼` キーをキャプチャでき、実キーで発火する |
|  | メイン `1` と `Numpad1` を別々にキャプチャできる |
|  | メイン `1` と `Numpad1` に別操作を割り当て、別々に発火する |
|  | 通常 Enter と `NumpadEnter` を別々にキャプチャできる |
|  | `FsZoomMode = NumpadEnter` でテンキー Enter だけが照準 / ズームになり、本体 Enter では発動しない |
|  | `FsZoomMode = Enter` (確認中は競合する `FsClose` を解除) で本体 Enter だけが照準 / ズームになり、テンキー Enter では発動しない |
|  | 設定を戻した後、`FsZoomMode = NumpadEnter` のままでも本体 Enter の既定「一覧へ戻る」が維持される |
|  | Shift+数字が物理数字キーとして発火する |

## ウィンドウ / 文脈ごとの入力到達

同じ代表操作を使い、ウィンドウ種別でキーが届くかを確認する。デバッグ表示またはログで `raw` と `consume` / `native_match` の両方を見る。

| 結果 | 文脈 | 確認項目 |
|---|---|---|
|  | サムネイル一覧 | 代表キーが `raw main` と `consume` を出して発火する |
|  | 画像フルスクリーン | 代表キーが `raw main` と `consume` / `pressed` を出して発火する |
|  | 分離ビューア / スタンドアロン FS | 代表キーとテンキーが届く |
|  | native 動画 | 代表キーが `raw native-video` と `native_match` を出して発火する |
|  | native 動画 | `?` でショートカット一覧を開閉できる |
|  | native 動画 | F11 または割り当て変更後のキーでウィンドウ / 全画面切替が動く |

## IME / TextEdit 優先

テキスト入力欄ではショートカットより入力が優先されることを確認する。

| 結果 | 場所 | 確認項目 |
|---|---|---|
|  | 検索欄 / フィルタ欄 | 文字入力中に割り当てキーが操作として暴発しない |
|  | 名前編集 / タグ入力 | IME 変換中の Enter / Esc が変換操作として効く |
|  | テキスト注釈 | 本文入力中に `?` や割り当てキーが本文入力を奪わない |
|  | 操作カスタマイズの押して入力 | IME composing 中はキャプチャしない |

## 代表操作サンプル

全アクションを押すのではなく、各 dispatch 経路から代表を確認する。

| 結果 | 文脈 | 操作 |
|---|---|---|
|  | サムネイル一覧 | 親フォルダへ移動 / 最大化切替 / お気に入り・ドライブ・場所ジャンプ |
|  | サムネイル一覧 | レーティング、ピン留めタグ付与、サムネイル列数変更 |
|  | 画像フルスクリーン | レーティング、ページ移動、ウィンドウ / 全画面切替、ルーペ修飾キー解除 |
|  | 動画フルスクリーン egui 経路 | 再生 / 停止、シーク、小 / 大ジャンプ、音量 |
|  | native 動画 | 再生 / 停止、シーク、小 / 大ジャンプ、音量、F11、`?` |
|  | 編集モード | 固定扱いの Esc / 修飾なし矢印が変わっていない |

## 操作カスタマイズ UI

| 結果 | 確認項目 |
|---|---|
|  | キーボード図で日本語配列とテンキーが画面内に収まる |
|  | キークリックから、文脈別に割り当て状態を確認できる |
|  | コマンド一覧から編集しても、別タブへ勝手に移動しない |
|  | 競合表示で相手の日本語操作名が読める |
|  | 競合相手の片方だけ割り当て解除でき、他のキーは残る |
|  | OK で保存、キャンセル / × は変更破棄確認が出る |
|  | 保存後に再起動して割り当てが保持される |

## 終了条件

- 高リスクの物理キー (`^` / `@` / `￥` / `＼` / テンキー / `NumpadEnter`) がキャプチャと発火の両方で確認済み。
- main / 画像 FS / native 動画の少なくとも 3 経路で `raw` と解決ログを確認済み。
- TextEdit / IME がショートカットに奪われない。
- 通常起動ではデバッグ表示も余計なログも出ない。
