# ネスト ZIP ツリーナビ 実機確認ガイド (v1.3.0)

`feat/nested-zip-tree` の実機確認用テスト ZIP と、確認したい動きのチェックリスト。
正本の設計は [nested-zip-tree-plan.md](nested-zip-tree-plan.md)。

## テスト ZIP の生成

```bash
python scripts/make_nested_zip_test.py        # 主要 3 つ
python scripts/make_nested_zip_test.py --big  # + 900 頁の負荷用も
```

出力先: `dist/ziptest/` (gitignore 対象、コミットしない)。各ページ画像は
**本名・ページ番号・★COVER バナー・構造の説明**入りなので、どの本のどの頁を見て
いるか・代表サムネ・見開きペアが目視で分かる。表紙ページ (page 1) に「この本はどこに
あり、何を確認するか」が書いてある (= 自己説明的)。

| ZIP | 役割 |
| --- | --- |
| `nested_tree_test.zip` | メイン。複数本 / 内側アーカイブ / サブフォルダ / 単一ラッパー / 深いネスト / 混在階層を 1 つに詰めた |
| `single_book_wrapper.zip` | 単一フォルダラッパー (開いた瞬間に自動降下する D1 ケース) |
| `simple_flat.zip` | フラット (ルート直下に画像のみ)。**退行確認のベースライン** |
| `big_nested.zip` | 6 本 × 150 頁 = 900 エントリ。UI が固まらないかの負荷確認 (`--big`) |

## nested_tree_test.zip のルート階層 (開いた直後の期待)

ルートに以下が並ぶ。**コンテナ (フォルダ型セル) が先・画像が後**:

1. `01_inner_archives` (フォルダ型バッジ)
2. `02_plain_subfolders` (フォルダ型バッジ)
3. `03_single_wrapper` (フォルダ型バッジ)
4. `04_deep_nest` (フォルダ型バッジ)
5. `05_mixed` (フォルダ型バッジ)
6. `root_a.png` / `root_b.png` (画像)

> ※ 並び順はソート設定に従う。コンテナが画像より前に来ること、代表サムネ (各セルの
> 絵柄) が各サブツリーの先頭頁になっていることを確認。

## チェックリスト (機能別)

### A. 基本ナビ (入る / 戻る)
- [ ] `01_inner_archives` を Enter / ダブルクリックで開くと `chapterA.zip` /
      `chapterB.cbz` / `chapterC.zip` の 3 セルが出る (= ZipDir)
- [ ] `chapterA.zip` を開くと頁 (p1..p11) が出る
- [ ] **Backspace で 1 段ずつ戻る** (頁 → chapter 一覧 → ルート)
- [ ] ルートで Backspace すると ZIP を抜けて**実フォルダ親**へ出る
- [ ] ゲームパッドの accept / back でも同じ出入りができる

### B. 内側アーカイブ vs サブフォルダのバッジ
- [ ] `01_inner_archives` の子 (`chapterA.zip` / `.cbz`) は **ZIP バッジ**
- [ ] `02_plain_subfolders` の子 (`vol_X` / `vol_Y`) は **フォルダ型バッジ**
- [ ] `.cbz` (`chapterB.cbz`) も内側アーカイブとして入れる

### C. 見開き (本ごとリセット = 今回の主目的)
- [ ] `chapterA.zip` (11 頁・奇数) を開いて見開き表示 → **表紙 (p1) が単独**、以降 2 頁ずつ
- [ ] `chapterC.zip` (3 頁・奇数) を開く → **表紙が単独**、本 A の最終頁と連結しない
- [ ] 本 A の最後まで送っても**本 B/C の頁が出てこない** (= 1 冊単位で完結。本連結の解消)
- [ ] 右綴じ / 左綴じ・縦/横の連続読みが各本で正しい向き
- [ ] `vol_Y` (2 頁) のような短い本でも表紙単独 + 2 頁目

### D. 単一ラッパーの自動降下 (D1)
- [ ] `03_single_wrapper` を開くと中間の `only` フォルダを**飛ばして頁に直接**着地
- [ ] `single_book_wrapper.zip` を開くと `the_only_folder` を飛ばして**いきなり頁一覧**
      (= ルート崩し)。その状態で Backspace すると**即 ZIP を抜ける** (中間段に止まらない)

### E. 深いネスト
- [ ] `04_deep_nest` → `{inner1.zip, inner2.zip}` の 3 段ナビができる
- [ ] `inner2.zip` を開くと中の `deeper` を自動スキップして頁に着地
- [ ] 各段で Backspace が 1 段ずつ正しく戻る

### F. 混在階層
- [ ] `05_mixed` を開くと **`extra.zip` (コンテナ) が先・`m_01`/`m_02` (画像) が後**
- [ ] `05_mixed` の**代表サムネは直下画像 `m_01`** (サブ本 extra.zip ではない)

### G. ソート
- [ ] `chapterA.zip` (p1..p11、非ゼロ詰め) を**番号順**ソートで開くと p1,p2,…,p10,p11
- [ ] **ファイル名順**ソートにすると p1,p10,p11,p2,… の順になる (= ソートが効いている)

### H. 既存データの生存 (DB 移行ゼロの確認)
- [ ] ある頁に補正・レーティング・回転・タグを付け、別の本へ移動して戻ると**保持**されている
- [ ] ZipDir セルの代表サムネが表示される
- [ ] (回帰) `simple_flat.zip` を開くと**従来通りフラット表示** (ZipDir セルが出ない)・
      見開き/連続読みが従来通り

### I. 応答性 (負荷)
- [ ] `big_nested.zip` (900 頁) を開く / 本に出入りする / スクロールしても UI が固まらない
- [ ] 各本に入った直後、サムネが順次出る (永久 Pending で固まらない)

### J. 検索との併用
- [ ] ZIP 階層内で Ctrl+F すると ZipDir / 画像が**ファイル名で絞り込め**る
      (ルートが ZipDir のみの階層でもコンテナが消えない)
- [ ] Ctrl+F を抜けると元の階層表示に戻る

## Ctrl+↑↓ DFS ナビ (実機 3 巡目 #6 反映、実機 4 巡目で確認)

Ctrl+↑↓ を「兄弟本のみ移動」から「実フォルダと同じ DFS 前順トラバーサル」に置換済み。
ZIP の中身が実フォルダツリーの一部であるかのように Ctrl+↑↓ で出入りできる。

**グリッド (全ノードに停止)**:

- [ ] `nested_tree_test.zip` のルートで **Ctrl+↓ → `01_inner_archives` の中に入る**
      (旧仕様の「次の実 ZIP へスキップ」をしない)
- [ ] そのまま Ctrl+↓ 連打で `chapterA.zip → chapterB.cbz → chapterC.zip →
      02_plain_subfolders → vol_X → vol_Y → 03_single_wrapper (頁一覧へ自動降下) →
      04_deep_nest → inner1.zip → inner2.zip → 05_mixed → extra.zip` の前順で進む
- [ ] `extra.zip` (最後のノード) でさらに Ctrl+↓ → **ZIP を抜けて次の実 ZIP/フォルダへ**
      (= ZIP 内に閉じ込められない)
- [ ] Ctrl+↑ は同じ道を逆順にたどる (例: `02_plain_subfolders` で Ctrl+↑ →
      `chapterC.zip` = 前の枝の最後の子孫へ降りる)
- [ ] 最初のノードまで戻って Ctrl+↑ → ルート (本一覧) → さらに Ctrl+↑ で ZIP を抜けて
      前の実フォルダへ
- [ ] Ctrl+↓ → Ctrl+↑ で**元の階層に戻る** (対称性)
- [ ] 各停止階層でアドレス欄パンくず / 見開き設定 / ピンバッジがその階層のものになっている
- [ ] `simple_flat.zip` (フラット): Ctrl+↓/↑ とも即 ZIP を抜けて隣へ (退行なし)
- [ ] ゲームパッド / ツールバー ▲▼ でも同じ動き

**フルスクリーン (直下画像のあるノードだけに停止)**:

- [ ] `chapterC.zip` の頁をフルスクリーン中に Ctrl+↓ → `02_plain_subfolders`
      (直下画像なしの分岐ノード) は**自動スキップ**され、`vol_X` の先頭頁が開く
- [ ] 本A (画像あり) と本B (直下画像なし・サブ本のみ) が兄弟のとき、本Aのフルスクリーンで
      Ctrl+↓ → 本Bを自動スキップして**本Bの中の最初の本の先頭頁**が開く (フルスクリーンは
      閉じない)。その後の Ctrl+↑↓ も効き続ける (lock 残留なし)
- [ ] 最後の本のフルスクリーンで Ctrl+↓ → ZIP を抜けて次の実フォルダの先頭画像へ
- [ ] ルート直下画像 (root_a.png) のフルスクリーンで Ctrl+↓ → 最初の本の先頭頁へ降りる
- [ ] レーティングフィルタで移動先の本の頁が全部 hidden の場合のみ、フルスクリーンが
      閉じてグリッドにその階層が出る (従来のフォールバック)

## 既知の制限 (将来 / 今回は未対応で OK)

- 複数本 ZIP を**自動フルスクリーン**で開くと、ルートが ZipDir のみのとき本一覧表示に
  留まる (先頭本への自動進入は将来)
- **cross-book「続きから」**: 続きからの記録はルート階層のみ (本の中の頁は記録されない)。
  深い階層への resume は将来
- ドリル中の **Ctrl+G** は ZIP ルートに戻る (状態ロスト、データ破壊なし。ソート変更は修正済み)

不具合を見つけたら、どの ZIP のどのチェック項目か (例: 「nested C-3」) を添えてもらえると
追いやすい。
