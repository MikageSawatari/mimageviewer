# ページ番号常時表示 実装要件

最終更新: 2026-06-12

## 背景

5ch の漫画ビューワスレで、mImageViewer v1.3.0 公開後に以下の要望があった。

> イメージビューアとしてではなく、漫画ビューアとしてみた場合、  
> (現在のページ)/(総ページ数) が常時表示されているのがいい

v1.3.0 時点では、フルスクリーン下部にマウスを持っていった時だけページシークバーとページ表示が出る。
今回の要望はシークバー常時表示よりも、「現在ページ / 総ページ数」を常に把握したい、という意味合いが強い。

## 方針

- まずはシークバーを常時表示せず、ページ番号だけを常時表示する。
- 画像表示領域を狭めず、画像の上に小さなオーバーレイとして出す。
- 表示位置は右下を初期仕様にする。
- 邪魔に感じるユーザー向けに、環境設定で OFF にできるようにする。
- 漫画ビューア用途を重視し、デフォルトは ON を第一候補にする。

シークバーを常時表示すると、画像の表示領域をどう確保するか、下部 HUD との重なり、マウス操作範囲などの調整が増える。
743 の要望にはページ番号だけで十分応えられる可能性が高いため、初回実装では範囲を絞る。

## 表示仕様

### 通常の単ページ表示

- 表示形式: `12 / 180`
- 左側は現在表示中のページ番号。ユーザー表示は 1 origin。
- 右側は現在の本・フォルダ・ZIP/PDF 内の総ページ数。

### 見開き表示

- 表示形式: `12-13 / 180`
- 見開きの片側だけが存在する場合は `12 / 180` のように単ページ表示へ落とす。
- 見開きの組み合わせを 1 ページずらしている場合も、実際に表示しているページ範囲を出す。

### 縦連結 / 横連結表示

- 表示形式: `12 / 180`
- 基準ページは、画面中央に最も近いページとする。
- 縮小時に複数ページが見える場合でも、`12-15 / 180` のような範囲表示は初回実装では行わない。

理由:

- 連結表示では表示中ページ数がズーム率で大きく変わる。
- 範囲表示は縮小時に表示がうるさくなりやすい。
- ユーザーが読んでいる位置に近いのは、先頭ページより画面中央基準。

## 見た目

- 右下に小さな pill 風の半透明背景を出す。
- 背景: 半透明の黒。目安は `Color32::from_black_alpha(140)` から調整。
- 文字: 白または白に近い色。
- 角丸は控えめ。既存 UI と合わせて 4px から 6px 程度。
- 余白は横 8px、縦 4px 程度。
- 画面端から 12px 程度離す。
- フォントは本文より少し小さめ。視認性を優先しつつ、漫画の邪魔にならないサイズ。

下部シークバーが表示されている時は、シークバーと重ならないように少し上へ逃がす。
既存の下部シークバー表示状態 (`fs_seek_overlay_visible` など) を使える場合は、その状態を参照する。

## 設定

`Settings` に bool を追加する。

候補名:

```rust
#[serde(default = "default_true")]
pub fullscreen_page_number_overlay: bool,
```

環境設定 UI には、フルスクリーン表示や見開き設定に近い場所へチェックボックスを追加する。
候補:

- `src/ui_dialogs/preferences/pages.rs`
- `page_spread_mode`
- ラベル案: `ページ番号を常時表示`

初期値は ON を想定する。
既存ユーザーに対しても、設定未定義時は ON になる。

## 実装候補箇所

主な候補:

- `src/settings.rs`
  - 設定フィールド追加
  - `Default` 初期化
  - 必要なら `sanitize` / 設定互換テスト更新
- `src/ui_dialogs/preferences/pages.rs`
  - 環境設定のチェックボックス追加
- `src/ui_fullscreen.rs`
  - フルスクリーン描画後にページ番号オーバーレイを描画
  - 既存の下部シークバー表示と重ならないように位置調整

ページ番号テキスト生成は小さな helper に分離するのが望ましい。

候補:

```rust
fn fullscreen_page_number_label(&self, fs_idx: usize) -> Option<String>
```

この helper は描画に依存しないロジックにして、単体テストしやすくする。

## ページ番号計算の考え方

- 総ページ数は、現在の fullscreen 対象のナビゲーション単位に合わせる。
- ZIP/PDF/ネストアーカイブ/検索結果などで、表示中の index とユーザーが期待するページ番号がずれないよう注意する。
- 区切り画像や非画像アイテムがある場合、ページ番号に含めるかは既存のフルスクリーンナビゲーションの考え方に合わせる。
- ユーザー向け表示は 1 origin にする。

見開き:

- 既存の見開き解決結果を使い、実際に描いている page index を集める。
- 2 ページなら `min-max / total`。
- 1 ページなら `page / total`。

連結表示:

- 既存の縦連結 / 横連結で計算している表示ページ rect または unit 情報から、画面中心に最も近い page index を選ぶ。
- 画面中心点と各ページ rect の中心点の距離で判定する。
- 縦連結なら Y 距離、横連結なら X 距離を優先してよい。

## 非対象

初回実装では以下は行わない。

- シークバーの常時表示
- ページ番号の表示位置カスタマイズ
- フォントサイズや色の詳細カスタマイズ
- 連結表示での表示範囲 `12-15 / 180`
- 画像表示領域をページ番号分だけ縮めるレイアウト

## 手動確認

- 単ページ表示で `1 / N`、中間ページ、最終ページが正しい。
- 見開き表示で `12-13 / N` になる。
- 見開き最終ページが片側だけの場合に `N / N` になる。
- 見開きの 1 ページずらし後も、実際の表示ページと一致する。
- 縦連結でスクロールすると、画面中央に近いページ番号へ切り替わる。
- 横連結でスクロールすると、画面中央に近いページ番号へ切り替わる。
- 下部シークバーを表示した時、ページ番号 overlay と重ならない。
- 左右パネル、補正パネル、メタデータパネル表示時に邪魔な重なりがない。
- 環境設定で OFF にすると表示されない。
- 設定変更が保存され、再起動後も維持される。
