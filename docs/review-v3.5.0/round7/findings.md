### 修正境界と回帰条件

識別子を記録する T01 の方針は適切。Undo / Redo 1 件の処理で必要なページをまとめて解決する、または一覧世代と対応したキー索引を共有するなど、**復元側で同じ一覧をページごとに走査しない**構造にする。旧 index へ戻すだけでは T01 が再発する。hint を再導入する場合も所有者・キーの照合と並べ替え後の解決が必要。

別窓・並べ替えの正確性テストに加え、大量の一括適用 / 解除の Undo / Redo でキー解決回数が N×M にならないことを確認する。R08 (一括書出し準備) や R11 (別 viewer への失効配送) と異なる、今回増えた復元処理のコストであり、延期承認を推定しない。
