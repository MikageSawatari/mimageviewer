# テキスト注釈の複数選択・整列・均等配置

実装済み: v2.5.0（2026-07-17）

## 目的

テキスト注釈モードで複数オブジェクトをまとめて選び、PowerPoint 系の編集ソフトと同様に
整列・均等配置できるようにする。移動中は他オブジェクトの端・中央・等間隔位置へ吸着し、
canonical source pixel 座標で結果を保存する。

## 選択モデル

- `App::text_selected_ids: Vec<u64>` が順序付き複数選択。末尾を主選択とする。
- 既存の `text_selected: Option<u64>` は単一オブジェクトの詳細編集・変形ハンドルとの互換用に残し、
  複数選択の末尾と同期する。
- キャンバスでは Ctrl+クリックでトグル、Shift+クリックで追加、空き領域ドラッグで本体境界を
  完全に囲んだオブジェクトを矩形選択する。
- 一覧では Ctrl+クリックでトグル、Shift+クリックで直前の起点から範囲追加する。
- 複数選択時は各本体の枠とグループ全体の枠を描画し、ドラッグは全オブジェクトへ同じ移動量を
  適用する。メッセージウィンドウは移動後に `WindowPosition::Free` とする。

## 整列と均等配置

- 2 個以上で、左端・左右中央・右端・上端・上下中央・下端の 6 種を利用できる。
- 基準は「選択範囲」（既定）と「画像」を切り替えられる。
- 3 個以上で横方向・縦方向の均等配置を利用できる。中心間隔と端の隙間の 2 方式を選べ、
  両端のオブジェクトは固定する。
- 座標変更は平行移動だけで、サイズと回転は変えない。
- 整列箱は回転込みの本体 AABB。吹き出しのしっぽ、線幅、影、発光、装飾は含めない。

## スマートガイド

- グループ移動後の本体 AABB の左・中央・右／上・中央・下を、非選択オブジェクトの同じ候補と
  毎フレーム比較する。
- 画面上 6 px 相当を canonical 座標へ逆変換した範囲内で最短候補へ吸着する。
- 左右または上下に隣接オブジェクトがある場合、両側の隙間が等しくなる位置も候補とし、
  吸着時に両方の隙間をガイド表示する。
- 変形ハンドルと Space+ドラッグのパンを優先し、スマートガイドは本体移動時だけ有効にする。

## 永続化・Undo

複数選択はセッション内 UI 状態であり DB へ保存しない。整列、均等配置、グループ移動による
オブジェクト変更は既存の `mark_comic_dirty` と `commit_comic_undo_on_settle` に乗せ、
1 回の操作を 1 undo snapshot にまとめる。保存形式と `comic.db` の schema は変更しない。

## 回帰確認

- 異なる大きさの本体を左・右・中央へ整列しても片軸以外が変わらない。
- 中心均等／隙間均等の両方式で両端が固定される。
- グループ移動で吹き出しの pivot としっぽ先端が同量移動する。
- MessageWindow のプリセット位置が Free へ切り替わる。
- Undo/Redo、単一選択の変形ハンドル、透過スタンプの hit-test、Space+パンが退行しない。
