## 1. 現時点で見つけた問題

### P0: 縦書き約物の実装がテスト不足だった

`。` / `、` / `…` / `「」` のような約物は、通常の横書き glyph を
中央に積むだけでは漫画のセリフとして破綻する。

今回の確認で、`layout.rs` には縦組み用の発想があった一方、実際の
配置 / raster 経路が十分に検証されていなかったことが分かった。対策として:

- `。` / `、` などの句読点を縦書きセル右上へ配置する。
- `…` / `‥` / `ー` / ダッシュ / 括弧類は、フォントが縦組み用 Unicode
  presentation form を持つ場合はそれを使い、無い場合は 90 度回転で代替する。
- `vertical_period_sits_in_upper_right_cell`、
  `vertical_ellipsis_gets_vertical_form_or_rotation`、
  `vertical_corner_quotes_get_vertical_form_or_rotation` を追加し、退行を拾う。

### P1: フォントフォールバックはまだ弱い

`ab_glyph` 単一 face のため、選択フォントが対象文字を持たない場合は
`.notdef` glyph になる。フォント選択 UI は日本語フォントを優先しているが、
ユーザー追加フォント、絵文字、記号、縦組み presentation form では未カバーがあり得る。

本体統合前に cosmic-text 等の fallback 方針を再確認するか、少なくとも
「未対応 glyph がある」警告を出す。

### P1: 表示と保存の WYSIWYG は継続監視

ラボは常に baked overlay を表示しているので方向性は良い。ただし、本体統合では
表示、Ctrl+E 書き出し、キャプチャ / クリップボードが別経路になりやすい。
統合時は「表示には出るが保存で消える」を P0 として扱う。

## 2. 縦書きテキスト

### P0 サンプル文字列

以下を縦書きで貼り、同じフォント / サイズで焼き込み表示を確認する。

```text
「……。」
「えっ!?」
びっくり!!!!
2026年6月4日
AIで作ったよ
{LOVE}してる
あー、そう……？
（テスト）【重要】《確認》
小さいっゃゅょ、ゎ。
```

期待:

- `。` / `、` はセル右上に寄る。
- `…` / `‥` は縦方向の点列、または違和感の少ない回転表示になる。
- `「」` / `（）` / `【】` / `《》` が横書きのまま寝ない。
- `!?` / `?!` は縦中横、`!!!!` / `????` は縦に積まれる。
- 2〜3 桁数字は縦中横、長い数字列は過密にならない。
- `{LOVE}` など横倒し記法の文字が隣列へはみ出さない。
- 行頭禁則で `。` / `」` が折返し後の先頭に来ない。

### P1 追加観点

- フォントを Yu Gothic / Meiryo / MS Gothic / ユーザー追加フォントで切り替える。
- 文字サイズ 12 / 24 / 48 / 120 / 300 px で破綻しない。
- 字間 / 行間を負方向と正方向に振っても bounds が潰れない。
- 袋文字を太くしても、縦書き約物の位置が不自然にずれない。
- マーカー記法 ON/OFF で `[]` / `{}` が意図通り「記法」または「文字」になる。

## 3. 吹き出し本体

### P0

- 楕円 / 角丸 / 矩形 / Burst / Cloud を追加できる。
- 自動サイズ ON で本文変更に追従し、極端に細長い形になりすぎない。
- 自動サイズ OFF でリサイズ後の寸法が保持される。
- 塗りなし / 枠なし / 半透明塗り / 太枠で表示と焼き込みが一致する。
- 回転後も本文、しっぽ、装飾、選択ハンドルが同じ見た目に追従する。

### P1

- Burst の深い谷でも文字が外へ飛び出さない。
- Cloud の凹みで文字が読みにくくならない。
- 複数オブジェクトの z-order 変更、複製、削除、Undo / Redo が破綻しない。
- 透明背景に近い画像 / 暗い画像 / 複雑な背景で袋文字の可読性を確認する。

## 4. しっぽ

### P0

- 三角しっぽが本体輪郭と一体化して、付け根に二重線が出ない。
- 思考しっぽが丸の連なりとして表示される。
- しっぽ先端ドラッグで話者方向を指せる。
- しっぽ付け根の自動 ON で、先端方向へ自然に付く。
- 付け根ハンドルをドラッグすると手動位置に切り替わる。
- 本体移動時にしっぽ先端も一緒に移動する。

### P1

- 縦長吹き出しの下しっぽが太すぎない。
- 横しっぽ、下しっぽ、斜めしっぽをそれぞれ確認する。
- 回転中 / 回転後のしっぽ tip/base ハンドルが見た目と一致する。

## 5. 装飾と結合

### P0

- きら / 花 / 泡を追加した時、同じ位置に完全重なりしない。
- seed 再生成で位置が変わり、保存 / 再読込では同じ位置に戻る。
- 泡グラデが中心より縁で濃い。
- 「下の吹き出しと結合」で内側の枠線が消え、一体に見える。

### P1

- 回転した吹き出し同士の結合で内側線が残らない。
- 半透明や異色の結合は v1 の限界として不自然さを記録する。
- 外側装飾がヒットテスト外になることを把握する。

## 6. メッセージウィンドウ

### P0

- Top / Middle / Bottom / Center / Free の位置プリセットが期待位置へ置かれる。
- FullWidth / Inset / AutoFitText が切り替わる。
- 日本語ワードラップで行頭禁則 / 行末禁則が効く。
- overflow 警告が、横長行 / 縦長列 / 折返し OFF の両方で出る。
- `indicator_auto` ON で、本文が溢れた時だけ続き指標が出る。
- 名前欄は上部で頻繁に編集でき、名前プレートの見た目へ反映される。

### P1

- GradientScrim の濃い側が Top / Bottom 設定と一致する。
- DoubleLine が単線より太く見え、角で破綻しない。
- 立ち絵 placeholder が content rect から除外され、本文と重ならない。
- 回転 / 手動リサイズで position が Free になり、プリセットリンクが解除される。

## 7. テキスト編集 / IME / ショートカット

### P0

- 日本語 IME 変換確定 Enter が余計な改行として入らない。
- 通常 Enter は複数行改行になる。
- Escape が IME 変換中のキャンセルを邪魔しない。
- TextEdit フォーカス中に Delete / Ctrl+Z / Ctrl+Y / Ctrl+C/V/X/A が
  オブジェクト操作へ漏れない。
- TextEdit 非フォーカス時は Delete / Undo / Redo がオブジェクト操作になる。

### P1

- 記号挿入ボタンが選択範囲を正しく囲み、caret が閉じ記号の前に戻る。
- クリップボード貼り付けで改行 / Unicode / 絵文字を含んでも panic しない。
- テキスト編集直後の Undo が、1 文字ずつではなく自然な塊で戻る。

## 8. フォント

### P0

- 起動直後に既定日本語フォントで文字が出る。
- フォント見本ダイアログで大量フォントを開いても UI が固まらない。
- 日本語 / 英語 / すべて の絞り込みが動く。
- ユーザー追加 TTF / OTF / TTC を選択できる。

### P1

- 選択フォントが日本語 glyph を持たない時の表示を確認する。
- 縦組み presentation form 未対応フォントで、回転 fallback が効く。
- TTC の face 選択が実フォント名とずれる可能性を記録する。

## 9. 保存 / 復元

### P0

- `.comic.json` 保存後、アプリ再起動 / 画像再読込で同じ見た目に戻る。
- object id / selected / z-order / preset link / seed / tail stash が崩れない。
- 古い sidecar に新フィールドが無くても `serde(default)` で読み込める。
- 壊れた JSON を読んでも panic せず status に失敗が出る。

### P1

- 同じフォルダの `a.jpg` と `a.png` は `a.jpg.comic.json` /
  `a.png.comic.json` で衝突しない。
- 画像ファイル名に日本語 / 空白 / 記号が入っていても保存できる。
- プリセット削除後も、既存オブジェクトの見た目が変わらない。

## 10. 表示 / パフォーマンス

### P0

- 4K / 8K 画像でドラッグ中に極端に固まらない。
- ドラッグ中の bake throttle 後、停止したら最終状態へ追いつく。
- zoom / pan / 回転 / リサイズ中に選択ハンドルと焼き込み表示が大きくずれない。
- 高 DPI 表示でハンドルサイズが操作可能な大きさを保つ。

### P1

- 大量オブジェクト 50 / 100 個で操作感を確認する。
- 太い袋文字 / 大サイズ文字 / 多数装飾でメモリ使用量が跳ねすぎない。
- 背景画像なしの状態、画像ドロップ中 overlay、再読込時の状態遷移を確認する。

## 10.5 スタンプ（画像ステッカー）

### 事前準備

- emoji アセットは任意。`bash scripts/setup-twemoji.sh` で `vendor/twemoji/svg/` に
  curated catalog (~120 種) を取得する。未取得でも「画像ファイルから追加」は使える。

### P0

- 「スタンプ追加」→ ピッカーが開く。カテゴリタブ / 検索 / 最近使った行 / 絵文字グリッドが出る。
- 絵文字クリックで画面中央に挿入され、選択状態になる。
- 「画像ファイルから追加」で PNG/JPG/WebP のユーザー画像をスタンプにできる。
- 本体ドラッグで移動、回転ノブで回転、四隅ドラッグで**アスペクト固定の一様スケール**になる。
- 右パネルで 大きさ / 不透明度 / 左右上下反転 / 縁取り(色・太さ) が効き、焼き込みに反映される。
- 「別のスタンプに変更」でピッカーが開き、選択中スタンプの絵柄だけ差し替わる(位置・サイズ保持)。
- 保存 → 再読込でスタンプ(ソース参照 + ジオメトリ)が同じ見た目に戻る。
- 縁取り ON で画像の輪郭の外側に縁が出る(不透明画像でも縁が見える)。

### P1

- ユーザー画像ファイルを移動/削除した sidecar を開くと、欠落プレースホルダ(灰枠＋×)が出る。
- emoji アセット未配置でもピッカーが開き、「画像から追加」「最近使った」は機能する。
- 同じ絵文字を複数貼っても decode は 1 回 (キャッシュ)。大きく貼っても SVG 由来で破綻しにくい。
- 回転 + 縁取り + 不透明度を同時にかけても破綻しない。
- 縦長/横長画像でアスペクトが維持される。

## 11. 本体統合時の追加 P0

lab ではなく mImageViewer 本体へ入れる時に必ず見る。

- Image / ZipImage / PdfPage の保存キーが一致する。
- 表示、Ctrl+E、キャプチャ保存、クリップボード、比較ピンのすべてで
  `conceal -> annotation -> crop` になる。
- 右 Ctrl 元画像プレビューでは注釈が非表示になる。
- crop 変更で注釈が最終出力範囲に合わせてクリップされる。
- サムネイルは焼き込みせず、注釈ありバッジだけを出す。
- annotation bake が stale / 実行中の時、保存をどう扱うかを明示する。
- UI スレッドでフォント列挙、フォントファイル読み込み、高解像度 bake をしない。

## 12. 最小リグレッション手順

リリース前や大きな修正後に最低限これだけ行う。

1. `cargo test -p comic-core`
2. `cargo check -p comic_lab`
3. 任意画像を開き、縦書き吹き出しに `「……。」` を入力する。
4. 同じ吹き出しで `びっくり!!!!`、`えっ!?`、`2026年`、`{LOVE}` を確認する。
5. 吹き出しを回転、リサイズ、しっぽ tip/base ドラッグ、保存、再読込する。
6. メッセージウィンドウを追加し、長文で overflow と indicator_auto を確認する。
7. フォントを 2 種以上切り替え、見た目と操作の固まりを確認する。
