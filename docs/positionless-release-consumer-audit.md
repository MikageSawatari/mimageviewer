## Verdicts

C: shared click adjudication requires a real click; `click=None` cannot activate it. Independent keyboard/accessibility/touch activation remains valid. H: terminate an existing hold/drag or save its already edited value. R: ordered terminal/ordinal/cancellation/input stripping transport; never synthesizes a position. F: conflated hold termination with operation completion; fixed in this change. T: test/fixture, excluded from production sites. Definitions belong to the shared producer/API review.

## Raw release ordinals

`released_buttons_with_click_counts` and the ordered button projection consume every release, including `(button, None)` for the positionless terminal. Grid, front-pointer, touch correlation, fullscreen/music/navigator and parked activation do not skip this ordinal. Revised ordered consumers retire only the old owner before handling later fresh input. Pre-existing aggregate oldUp+freshDown hold handling (also reachable with known Up) is a separate ownership boundary: H classifies terminal non-authorization, not a redesign of that existing input processing.
