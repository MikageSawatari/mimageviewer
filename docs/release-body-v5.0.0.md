## mImageViewer v5.0.0

このリリースノートは要点をまとめた短縮版です。全項目は更新履歴のページをご覧ください: https://mikage.to/mimageviewer/manual/changelog.html

## 最初の起動で起きること

- **⚠️ この版にしてから最初の起動で、アイテム検索（<kbd>Ctrl</kbd>+<kbd>G</kbd>）の索引を作り直します。** 作り直している間は、アイテム検索の結果が揃いません。タグ・★評価・閲覧履歴・サムネイルキャッシュはそのまま残ります。
- **⚠️ 音響調整を、EffeTune Mixwright を元に mImageViewer 用に作った「mIV Sound」に切り替えました。** 最初の起動で、これまでの音響調整のデータを一度だけ引き継ぎます（元のデータは消しません）。**DAW で使う EffeTune Mixwright や、デスクトップ版の EffeTune とは、プリセットを共有しなくなります。** 行き来するときは、プリセットの書き出し・読み込みを使ってください。引き継げなかったときは、タスクトレイに常駐しているものも含めて mImageViewer をすべて終了してから、1 つだけ起動してください。

## 主な新機能

- **同じ PC の Claude Desktop や ChatGPT (Codex) から、mImageViewer のライブラリを検索・整理できるようになりました。** 「設定」→「AI 連携…」で使う AI アプリを登録し、許可の範囲を選びます。ファイルの移動・名前の変更・削除は頼めません。**AI 連携は既定では無効です。** 有効にすると、許可した情報を AI アプリが受け取り、その提供元へ送ります。mIV 自身がインターネットへ情報を送ることはありません。
- **画像や本の表紙の内容を、PC 内の AI で説明文にして保存できるようになりました。** 右クリックの「AI 説明文を作る」で始め、情報パネルの「AI 説明」で読めます。作成は PC 内で行い、画像や説明文を外へ送りません。初めて使うときに追加のモデルをダウンロードします。Vulkan 対応で VRAM 8 GB 以上の GPU が必要です。説明文は右クリックの「AI 説明文を削除」で消せます。
- **保存した AI 説明文で、画像や本を探せるようになりました。** アイテム検索と現在地の絞り込み (<kbd>Ctrl</kbd>+<kbd>F</kbd>) の「検索対象」に「AI 説明」を加えました。
- **音声に画像・スペクトラム・鍵盤・文字・歌詞などを重ねて、MP4 の音楽ビデオを作れるようになりました。** 一覧で音声ファイルを右クリックして「音楽ビデオを作成」を選びます。
- **音響調整のビジュアライザーに「mIV Original」を追加し、再生中の曲の歌詞も表示できるようになりました。** 曲と同じ名前の .lrc ファイルか、曲に埋め込まれた歌詞を使います。
- **ポータブル版でも音響調整とユーザー VST を使えるようになりました。**
- **製本の管理で、本棚の本の並び順を決められるようになりました。**
- **メニューの「変換」と「動画」を「ツール」にまとめました。**
- **フォルダバーの「非表示 N 件」から、一覧に出していないファイルの名前と理由を確かめられるようになりました。**
- **見開き表示の情報パネルで、左右どちらのページの情報を見るかを選べるようになりました。**
- **ツールバーの場所▼に「ビデオ」と「ミュージック」を加え、フォルダバーで二重引用符で囲んだパスでも移動できるようにしました。**

## 主な修正

- ほかのアプリでフォルダを移動・削除しても、左のフォルダツリーに古いフォルダが残る問題などを修正しました。
- 一覧で★の絞り込みを選んでいるとき、★を付けた親フォルダへ戻ると、絞り込みがまた一時的に解除される問題を修正しました。
- 現在地の絞り込みを使ったまま別のフォルダへ移ると、一覧が一部しか表示されないことがある問題と、絞り込み中に履歴の ← / → が反応しない問題を修正しました。
- アイテム検索の結果で、名前がすべて小文字になる問題と、大きさが 0.0 KB と表示される問題を修正しました。
- 一部のファイル種類を非表示にしていると、以前の版で読んだ PDF が続きのページではなくページ一覧で開く問題を修正しました。
- 消しゴムで消したページへめくるとき、アニメーションに消す前の画像が出る問題を修正しました。
- 補正レイヤーで取り消し・やり直しが効かないことがある問題と、「加工内容を選択」の窓が横へ広がる問題を修正しました。
- 音響調整の窓が前に出ないことがある問題と、初めて開いたときに「エフェクトが無い」と説明される問題を修正しました。
