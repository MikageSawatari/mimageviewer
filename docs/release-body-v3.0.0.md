## 外出先から、自宅 PC のライブラリを見られるようになりました

自宅の PC で mImageViewer を起動したままにしておくと、外出先のスマートフォン・タブレット・ノート PC のブラウザから同じライブラリを開けます。画像も、漫画（ZIP / PDF）も、動画も、手元の端末にコピーせずそのまま見られます。**既定ではオフです。**

- 画面はスマートフォンでの操作を前提にしています。左右のタップでページ送り、中央のタップで上下バーの表示切り替え、上へスワイプでメニュー、下へスワイプで一覧、ピンチで拡大です。初回に操作の説明を表示します。
- 見開き表示、ページ位置の指定、明るさなどの画像補正、カラー化、AI（拡大・ノイズ除去）、ポストフィルタ、表示トリムを、本体と同じように操作できます。レーティング・ブックマーク・読んだ位置・見開き設定・補正は**自宅 PC 側に記録される**ので、帰宅後は続きから読めます。
- 動画と音声は、自宅 PC 側で変換しながら配信します。画質を選べます。ZIP / PDF に加えて RAR / 7z / LZH も開けます。
- 接続には Tailscale と PIN の**両方**が必要です。mImageViewer 自身はインターネットに出ず、自宅 PC の中だけで待ち受けます。Tailscale に参加していない端末からは、URL を知っていても届きません。
- ホーム画面に登録すると、次からアイコンを押すだけでアプリのように開けます。手順は[マニュアル](https://mikage.to/mimageviewer/manual/tut-remote.html)にあります。
- ファイルの操作（コピー・移動・削除・名前の変更）、タグの付け外し、画像の編集はできません。同時に操作できるのは常に 1 台です。
- 有効にすると、**すべてのドライブについて、mImageViewer で表示できるファイルが閲覧できるようになります。**自分が管理している端末からだけお使いください。詳しくは[マニュアル](https://mikage.to/mimageviewer/manual/tut-remote.html)をご覧ください。

## 主な追加・改善

- **環境設定を検索できるようにしました。** 左のツリーの上にある入力欄に言葉を入れると、該当する設定項目が右側に並びます。選ぶとそのページが開き、その項目までスクロールして数秒間ふちどりで示します。「デノイズ」「ビューア」のような言い換えでも見つかります。
- **上部バーに、使用頻度の低い操作をまとめたボタンを追加しました。** ナビゲータの 2 つの設定・ピクセルグリッド・ルーペの固定・分析モードを、指でも押しやすい大きさの一覧から選べます。分析モードは上部バーからこの一覧の中へ移りました。
- **消しゴムと隠蔽加工にも、塗りつぶし（バケツ）を追加しました。** ツールを「バケツ」（<kbd>K</kbd>）に切り替えると、補正レイヤーと同じく、クリックした色に近い範囲を一度に塗れます。
- **ドット絵向けの拡大方法「ドット絵拡大」を追加しました。** ポストフィルタの「基本」から選べます。ニアレストは等倍でないズームでドットの大きさが不揃いになりますが、この方法では揃ったまま拡大され、ドットの境目だけがなじみます。
- **拡大していない画像も、左ドラッグで動かせるようにしました。** これまでは画面に収まっている画像はドラッグしても動かず、固まったように見えていました。動かしたあとも、クリックでのページ送りはそのまま使えます。位置を戻すのはこれまでどおりダブルクリックです。
- **フルスクリーンのシークバーに目盛りを表示するようにしました。** 動画・音楽の再生位置がつかみやすくなります。
- **比較表示の操作を整理しました。** ワイプの境界線は、左 <kbd>Ctrl</kbd> を押しているあいだ消えます。元画像を表示するキー（既定は右 <kbd>Ctrl</kbd>）は、比較表示中は効かなくなりました。
- **RAR / 7z / LZH も、親フォルダの代表サムネイルに固定できるようにしました。** 変換済みのものが対象です。
- **キーの割り当て候補一覧に検索欄を追加しました。**

## 主な修正

- **キーを押しっぱなしにしたときの連続ページ送りが、引っかからずに全ページを表示できるようになりました。** スムーズにめくりながら通過するページも 1 枚ずつ表示するために、連続めくりのあいだはサムネイルの画質で表示します。指を離して止まったページはフル画質に戻ります。通過中も色味は変わりません。1 回だけ押したときは画質を落とさないので、ゆっくり読むときの見え方はこれまでどおりです。
- **ニアレスト（ドット感を残す拡大）が、画像によって効いたり効かなかったりする問題を修正しました。** 注釈・画像補正・AI のどれを使っているかで結果が変わっていました。
- **PDF を続けて開いたときに、前の文書のページが表示されてしまうことがある問題を修正しました。**
- **タッチ操作を直しました。** ナビゲータに触れるとページが送られてしまう問題、360 度ビューと分析モードでピンチしても拡大縮小できなかった問題を修正しました。
- **縦向きで撮影した動画を、正しい向きで再生するようにしました。** サムネイルと再生とで違う向きになっていました。
- **切り取り（トリミング）の範囲が、画像の解像度によってずれる問題を修正しました。** 範囲を作ったときの解像度も一緒に保存するようにしました。すでにずれた状態で保存されているものは、お手数ですが再度設定し直してください。
- **PDF が「表示するファイルがありません」になったとき、理由を表示するようにしました。** 読み取りに失敗した場合とパスワードが必要な場合を、中身が空のフォルダと区別して示します。
- **連結読みの途中で、横方向のキー操作で動画に入ってしまう問題を修正しました。**
- **注釈の色を選ぶときに、加算合成を選べないようにしました。** 選ぶと不透明度が 0 になり、通常合成に戻せなくなる問題があったためです。

## 制限

- **360 度ビューでは、高画質へ切り替わったときに消しゴム・隠蔽加工・補正レイヤーの結果が反映されません。** この制限がある画像では、画質の表示の下にその旨を出すようにしました。あわせて、360 度ビュー中は画像編集モードに入れないようにしました。
