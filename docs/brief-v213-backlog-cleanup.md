# ブリーフ: v2.13.0 で出荷した項目をバックログから外す

## 前提 (必ず守ること)

- **アプリを起動しない**。
- **git 操作をしない** (commit / add / stash / branch / reset いずれも)。master の作業ツリーに
  未コミットのまま残す。統合はこちらで行う。
- 作業ツリーは他セッションと共有している。**触るのは
  `docs/next-release-backlog.md` の 1 ファイルだけ**。

## 背景

`docs/next-release-backlog.md` は「まだ着手していない作業候補だけを置く恒久バックログ」で、
冒頭の運用ルールに **「完了したらこのファイルから削除する」** と書いてある。v2.13.0 を
出荷するので、今回入った項目を外す。

このファイルは過去に消し忘れ (§1.29) を起こしており、その再発防止が
「v2.10.0 で修正済み・未リリース」ブロックに明記されている。**同じ轍を踏まないこと**が
この作業の目的なので、機械的に消すのではなく、後述の確認を必ず行う。

という引用ブロックがある。そこに挙がっている 10 件と、追加で入った 2 件を削除する。

### 削除するときの注意

- §1.58 の本文末尾に **「残した挙動 (利用者判断 2026-08-10)」** がある。フォルダ末尾で
  キーを押し続けると最後のページがサムネイル画質のまま留まる件で、**直さないと決めた**もの。
  これは `htdocs/mimageviewer/manual/known-issues.html` に転記済みなので、
  バックログからは消してよい。
- 他の項目の本文に、**次版へ持ち越す残件が混ざっていないか**を確認してから消すこと。
  混ざっていたら、その残件だけを新しい項目として残す (何を残したかを報告する)。
  例: §1.55 は 2 件とも完了、§1.61 は「カタログ DB からの寸法先読みは今回行わない」と
  書いてあるが、これは将来の改善案であって残件ではない (= 消してよい)。
