MassiGra からの移行ガイド

MassiGra をお使いの方が mImageViewer に乗り換えるために

MassiGra の公式ヘルプの更新履歴に載っている最新版は、2013 年 4 月 23 日公開の Version 0.45 です。mImageViewer は、無料・広告なしで Windows 11 向けに開発を続けている画像ビューアで、MassiGra でおなじみの Susie プラグイン（.spi）にも対応しています。このページでは、MassiGra から移る方に向けて、プラグインの引き継ぎ・よく使う操作の対応・画像加工の違いをまとめています。

はじめに知っておきたいこと

  • 動作環境は Windows 11（64bit）です。
  • mImageViewer はサムネイル一覧が基本の画面です。フォルダを開くと中の画像がサムネイルで並び、クリックでフルスクリーン表示に切り替わります。フルスクリーン中も ← → やホイールで、同じフォルダの前後の画像へ移れます。
  • エクスプローラーから 1 枚だけ開く使い方もできます。画像ファイルを渡して起動すると、その画像のフォルダを開いたうえで、その画像をフルスクリーンで表示します。環境設定の「起動と連携 → エクスプローラ連携」で「送る」メニューに登録すると、右クリックの 送る → mImageViewer から開けます。
  • 一般的な画像形式はプラグインなしで表示できます。JPEG / PNG / GIF / WebP / BMP は内蔵で表示し、HEIC・AVIF・各社 RAW は Windows の拡張機能（Microsoft Store）を入れると表示できます（対応フォーマット）。アニメーション GIF・APNG・アニメーション WebP も再生します。
  • 書庫は mImageViewer 本体が読みます。ZIP / CBZ と一般的な RAR / CBR は展開せずにそのまま開き、7z / LZH やソリッド圧縮の RAR は、最初に開くときに一度 ZIP へまとめ直してから表示します（元のファイルはそのまま残ります）。書庫用の Susie プラグインを用意する必要はありません。

Susie プラグインを引き継ぐ

PI / MAG / PIC などの特殊・レトロな画像形式を、MassiGra で使っていた Susie の画像プラグインで表示できます。対応するのは 32bit 版の .spi です。

  • 環境設定の「ファイル処理 → Susie プラグイン」を開き、「📁 フォルダを開く」を押します。
  • 開いたフォルダに、使っていた .spi ファイルをコピーします。
  • 同じ画面の「⟳ プラグインを再読み込み」を押します。アプリの再起動は不要です。
JPEG・PNG などは内蔵の読み込みが優先され、Susie プラグインは使われません。プラグインは別のプロセスで動かすため、不正な画像でプラグインが止まっても mImageViewer 本体は巻き込まれません。64bit 版（.sph）には対応していません。詳しくは FAQ（古い PC の画像形式） をご覧ください。

画像加工は「元のファイルを変えない」方式です

明るさ・コントラスト・色合いなどの補正、切り取り、回転は、元のファイルを書き換えずに記録し、表示にだけ反映します。いつでも元に戻したり調整し直したりできます。

  • 補正：フルスクリーン表示中に画面の左端へマウスを寄せると補正パネルが開きます。
  • 加工した画像をファイルにする：Ctrl+E のエクスポートで、補正や切り取りを反映した画像を JPEG / PNG / WebP の別ファイルとして書き出します。出力サイズ（1/2・1/4・長辺の指定）も選べます。
  • まとめて書き出す：サムネイル一覧で複数の画像を選んで Ctrl+E を押すと、縮小したコピーなどを 1 つのフォルダへまとめて書き出せます。

詳しくは 画像補正 と エクスポート をご覧ください。

移行で使える便利な機能

🗂️

サムネイル一覧

フォルダ・ZIP・PDF・画像・動画を一覧で見渡して開けます。作ったサムネイルは保存するので、開き直しても待ちません。

📖

見開き表示

ZIP や PDF の漫画を、右→左の見開きや表紙あり見開きで読めます。

🔍

AI アップスケール

PI / MAG などのレトロ画像や小さな画像を、4 倍に高精細化して表示できます。処理は PC の GPU で行います。

⭐

★・タグで整理

★1〜5 やタグを付けて、フォルダをまたいで呼び出せます。元のファイルは書き換えません。

🧹

AI 消しゴム

スキャンの汚れや傷を塗ると、周囲から自然に補完します（元ファイルは無改変）。

🖥️

高 DPI・GPU 表示

4K などの高解像度ディスプレイでも、きれいで滑らかに表示します。
