Windows フォトからの移行ガイド

標準のフォトから、一覧と整理に強いビューアへ

Windows に最初から入っている「フォト」で画像を見ていて、フォルダの中身をもっと一覧で見渡したい、ZIP や PDF の漫画も同じソフトで読みたい、気に入った画像に印を付けて後から集めたいと感じた方へ。mImageViewer は、そうした使い方のために作った無料・広告なしの画像ビューアです。フォトと入れ替える必要はなく、併用しながら試せます。

mImageViewer で変わること

  • フォルダを開くと、画像・動画・音声・ZIP・PDF がサムネイルで並びます。種類の違うファイルが同じ一覧に並び、クリックでフルスクリーン表示に切り替わります。数万枚のフォルダでも、画面に見えている分から先に表示します（しくみ）。
  • ZIP / CBZ や PDF は展開せずにページをめくれます。漫画は見開き（右→左）や表紙あり見開きで読めます。RAR / 7z / LZH にも対応しています。
  • ★1〜5 とタグで整理できます。付けた★やタグで、フォルダをまたいだ 1 つの一覧を呼び出せます。★とタグは mImageViewer の中に記録し、既定では画像ファイルを書き換えません（★は設定を有効にすると XMP にも書き込めます）。
  • 補正や回転は元のファイルを変えません。明るさ・色合いの補正、回転、切り取りは記録として持ち、表示にだけ反映します。ファイルにしたいときだけ別ファイルとして書き出します。
  • AI の処理はすべて PC の中で行います。AI アップスケール・ノイズ除去・消しゴムの補完は PC の中で実行し、画像を外部へ送りません。広告・アクセス解析・アカウント登録もありません。

はじめに知っておきたいこと

  • 動作環境は Windows 11（64bit）で、DirectX 12 に対応した GPU が必要です。
  • 画面は日本語のみです。
  • HEIC・各社 RAW・AVIF は Windows の拡張機能で表示します。Microsoft Store の「HEIF 画像拡張機能」「Microsoft Raw 画像拡張機能」などを入れると表示できます（対応フォーマット）。
  • エクスプローラーからの開き方：環境設定の「起動と連携 → エクスプローラ連携」で「送る」メニューに登録すると、画像を右クリックして 送る → mImageViewer で開けます。画像のフォルダを開いたうえで、その画像をフルスクリーンで表示します。ダブルクリックで開くようにするには、画像を右クリックして「プログラムから開く」から mImageViewer を選び、その種類のファイルをいつも mImageViewer で開く設定にしてください。一覧に出ないときは、PC 上の mImageViewer の実行ファイルを指定できます。
  • ダウンロードは 3 種類あります。ふつうはインストーラ版、インストールせずに試すならポータブル版がおすすめです（ダウンロード）。Microsoft Store からも入手できます。

フォトと併用するときは

mImageViewer で閲覧するだけなら、画像ファイルを移動したり、フォトのライブラリの設定を変えたりすることはありません。★・タグ・補正などの記録は mImageViewer の中にあります。まずは写真や漫画の入ったフォルダを 1 つ開いて、一覧の見え方を試してみてください。最初の使い方は チュートリアル「はじめての 10 分」 にまとめています。
