Honeyview からの移行ガイド

Honeyview をお使いの方が mImageViewer に乗り換えるために

Honeyview は 2024 年 6 月 21 日公開の 5.53 が最終版で、配布元の 公式ページ には今後アップデートを提供しない旨と、後継製品の案内が載っています。mImageViewer は、無料・広告なしで Windows 11 向けに開発を続けている画像ビューアです。このページでは、Honeyview から移る方に向けて、違いが出やすい点・よく使う操作の対応・おすすめの初期設定をまとめています。

はじめに知っておきたいこと

  • 動作環境は Windows 11（64bit）です。
  • mImageViewer はサムネイル一覧が基本の画面です。フォルダを開くと、中の画像・動画・ZIP・PDF がサムネイルで並び、クリックでフルスクリーン表示に切り替わります。フルスクリーン中も ← → やホイールで、同じフォルダの前後の画像へ移れます。
  • エクスプローラーから 1 枚だけ開く使い方もできます。画像ファイルを渡して起動すると、その画像のフォルダを開いたうえで、その画像をフルスクリーンで表示します。環境設定の「起動と連携 → エクスプローラ連携」で「送る」メニューに登録すると、右クリックの 送る → mImageViewer から開けます。ダブルクリックで開くようにするには、画像を右クリックして「プログラムから開く」から mImageViewer を選び、その種類のファイルをいつも mImageViewer で開く設定にしてください。一覧に出ないときは、PC 上の mImageViewer の実行ファイルを指定できます。
  • 書庫の扱いが一部ちがいます。ZIP / CBZ と、一般的な RAR / CBR（ソリッド圧縮でなく、中に別の書庫を含まず、パスワードなし）は展開せずにそのまま開きます。7z / LZH、ソリッド圧縮やパスワード付きの RAR は、最初に開くときに一度 ZIP へまとめ直してから表示します（元のファイルはそのまま残ります。元の書庫が変わっておらず、変換した ZIP が残っていれば、次回は変換し直さずに開けます）。TAR には対応していません。
  • 各社 RAW の表示・現像を内蔵しています。追加インストールは不要です。HEIC は Windows の表示機能を使います。HEIF 画像表示オプション に加え、HEVC に対応していない PC では HEVC ビデオ拡張機能 も必要です。HEVC ビデオ拡張機能は有料の場合があります（対応フォーマット）。JPEG / PNG / GIF / WebP / BMP は追加なしで表示でき、アニメーション GIF・APNG・アニメーション WebP も再生します。
  • まとめて形式を変えたり縮小したりできます。一覧で複数の画像を選んで Ctrl+E を押すと、PNG / JPEG への変換や、1/2・1/4・長辺の指定での縮小をまとめて行い、1 つのフォルダへ書き出せます（エクスポート）。
  • 画像・漫画のほか、動画・音声も同じ一覧で扱えます。動画はフルスクリーンでそのまま再生できます。

おすすめの初期設定

  • 「送る」メニューに登録する ―― 環境設定の「起動と連携 → エクスプローラ連携」で登録すると、エクスプローラーの右クリックから開けます。
  • ZIP を開いたらすぐページを表示する ―― 「環境設定 → 全体設定」の「ZIP/PDF/対応アーカイブ」で 開いたとき、ページをフルスクリーン表示 を選びます。
  • 7z / LZH などの扱いを決める ―― 「環境設定 → パフォーマンス → キャッシュ」の「RAR / 7z / LZH の処理」で、確認してから変換・確認せずに変換・無視 から選べます。

移行で使える便利な機能

🗂️

サムネイル一覧

フォルダ・ZIP・PDF・画像・動画を一覧で見渡して開けます。時間のかかった画像のサムネイルは保存するので、開き直すときは速く表示できます。

⭐

★・タグで整理

★1〜5 やタグを付けて、フォルダをまたいで呼び出せます。既定では元のファイルを書き換えません。

🔍

AI アップスケール

小さな画像や古いスキャンを 4 倍に高精細化して表示できます。処理は PC の中で行います。

🎨

非破壊の補正

明るさ・コントラスト・色合いなどを、元のファイルを変えずに調整できます。

🎬

動画・音楽の再生

外部プレイヤーなしで再生し、長い動画はタイル表示で全体を見渡せます。

📱

外出先から見る

自宅 PC のライブラリを、スマートフォンのブラウザから開けます（案内）。
