検索機能

mImageViewer には 3 種類の検索モード (Ctrl+S / Ctrl+F / Ctrl+G) があります。 対象範囲と検索できる情報が違うので、使い分けると目的の画像やフォルダに素早く辿り着けます。

1. 3 つの検索モードの使い分け

ショートカット 検索対象 検索できる情報 典型的な用途
Ctrl+S お気に入り配下のフォルダ / ZIP / PDF / 動画名 名前のみ 「あのフォルダ、どこに置いたっけ?」を名前で呼び出す
Ctrl+F 今表示中のフォルダ内の画像・PDF ファイル名 / EXIF / XMP / AI プロンプト / PDF メタ / タグ 開いているフォルダを絞り込む (Lightroom のフィルタに近い)
Ctrl+G お気に入り全体の画像・PDF ファイル名 / EXIF / XMP / AI プロンプト / PDF メタ / タグ お気に入り横断で 1 枚の画像を掘り出す
💡
どれを使えばいい?
  • 名前だけ覚えている → Ctrl+S
  • 開いているフォルダの中で探したい → Ctrl+F
  • お気に入り全体から画像 1 枚を見つけたい → Ctrl+G

2. Ctrl+S: お気に入り名前検索

お気に入りに登録したルート配下のフォルダ / ZIP / PDF / 動画の名前を部分一致で 引き当てます。過去に訪れたフォルダや動画を名前で呼び出すのに向いています。

  1. メニュー「お気に入り」→「名前で検索 (Ctrl+S)」で画面上部に検索バーが出ます。
  2. キーワードを入力すると即座に部分一致で絞り込まれます (大小区別なし)。
  3. 結果は名前昇順で最大 5000 件まで表示されます。
  4. × ボタンまたは Esc で閉じ、元のフォルダに戻ります。
⚠️
事前に名前索引を ON にしてください: Ctrl+S の対象は名前索引に登録されたエントリだけです。 名前索引は既定で OFFなので、お気に入りダイアログで「名前索引」の チェックを ON にする必要があります (ON にするとその場で再帰的に走査し、以後は自動追従)。

絞り込みフィルタ

  • お気に入り: 「すべて」または単一のお気に入り配下に絞り込み。
  • OR 検索: 後述の OR モードに切り替え。

3. Ctrl+F: ローカル検索 (メタデータ検索)

Ctrl+F で今表示しているフォルダの中身を絞り込みます。 ファイル名に加え、EXIF・XMP・PNG の AI プロンプト・PDF メタデータ・タグまで検索対象に含められます。 Lightroom の「フィルタ」バーに近い使い勝手です。

  1. メニュー「ファイル」→「メタデータ検索 (Ctrl+F)」で画面上部に検索バーが出ます。
  2. キーワードを入力して Enter で確定 (入力中も逐次絞り込みされます)。
  3. 「検索対象」ドロップダウンでどのメタデータを見るかを変更できます (後述)。
  4. × ボタンまたは Esc で閉じます。

表示中の ZIP についても検索します

ZIP を開いた状態で Ctrl+F を使うと、ZIP 内の PNG メタデータも同じルールで検索されます。 PDF の場合はタイトル・著者などのドキュメントメタデータが対象です。

Ctrl+F はインデックス不要で動きます

表示中のアイテムを対象に、その場で EXIF / XMP / PNG テキスト等を読んで判定します。 さらにメタ索引を ON にしたお気に入り配下のファイルでは高速パスが 効き、EXIF / XMP をディスクから読み直さず索引から引くので数千件のフォルダでも即時です。

4. Ctrl+G: グローバル全文検索

メニュー「お気に入り」→「メタデータ検索 (Ctrl+G)」でお気に入り全体を 横断検索します。数万件規模でも全文索引による高速検索で、即座にヒット件数と候補が 表示されます。

  1. 任意のタイミングで Ctrl+G を押すと画面上部に検索バーが出ます。
  2. キーワードを入力すると 300ms のデバウンス後に自動実行されます。
  3. 結果はヒット件数が多いフォルダ順に「コンテナ」として表示。クリックで中を覗けます。
  4. × ボタンまたは Esc で閉じて元のフォルダに戻ります。
⚠️
事前にメタ索引を ON にしてください: Ctrl+G はお気に入りダイアログ (お気に入り → 編集) で「メタ索引」を ON にした お気に入り配下だけを対象にします。メタ索引は既定で OFFのため、 ON にしない限り Ctrl+G でヒットは出ません。

最小クエリ長の制限

Ctrl+G は索引の精度を確保するため、検索語に以下の最小長を要求します:

  • CJK (日本語・中国語・韓国語): 2 文字以上
  • ASCII / 数字: 3 文字以上
  • タグトークン (#タグ名) はこの制約の対象外 (完全一致のため)

Ctrl+F と Ctrl+S にはこの制約はありません (直接文字列一致のため短いトークンでも動きます)。

5. 検索クエリ構文 (3 モード共通)

書き方意味例
word1 word2AND: すべて含む夕焼け 海辺
-wordNOT: 含まない (除外は常に AND)夕焼け -曇り
"word1 word2"フレーズ: 連続する文字列"golden hour"
-"word1 word2"フレーズの NOT-"low quality"
#タグ名タグ検索 (# 込みで一致)#原神 #風景
-#タグ名タグの除外#風景 -#夜景
🔤
大文字小文字の扱い: クエリは自動で小文字化されて比較されます (SunSet == sunset)。

OR 検索モード

検索バー右端の □OR チェックを入れると、AND ではなく OR で include トークンを結合します。ただし -word の除外は常に AND で効きます。

クエリAND モード (既定)OR モード (チェック時)
klee paimon 両方の語を含むものだけ いずれかの語を含むもの
klee #klee (キーワード "klee" と タグ "#klee") を両方含む キーワードかタグのいずれかで "klee" を含む
klee #klee -sleep -nsfw "klee" と "#klee" を両方含み、"sleep" も "nsfw" も含まない "klee" か "#klee" のいずれかを含み、"sleep" も "nsfw" も含まない
💡
いつ OR モードを使う? 同じ対象を別表記で呼ぶ場合 (例: キーワード klee と タグ #klee の両方を見たい、 sunset と 夕焼け をまとめて拾いたい、など) に便利です。 OR にしても除外語は AND なので、klee #klee -nsfw で安全に広く拾えます。

6. 絞り込みドロップダウン

検索バー右側のドロップダウンで、検索範囲をさらに狭めることができます。 どのバーがどのドロップダウンを持つかは下表のとおり:

ドロップダウンCtrl+SCtrl+FCtrl+G
お気に入り◯—◯
タイプ (フォルダ/画像/ZIP/PDF)——◯
検索対象 (EXIF/XMP/…)—◯◯
タグピッカー——◯
OR 検索チェック◯◯◯

お気に入り (Ctrl+S / Ctrl+G)

「すべて」または特定の 1 つのお気に入りに絞ります。複数のお気に入りをまたぐ検索で、 対象を狭めたいときに使います。Ctrl+S では名前索引 ON のお気に入り、Ctrl+G ではメタ索引 ON のお気に入りだけが候補に出ます。

タイプ (Ctrl+G 専用)

フォルダ / 画像 / ZIP ファイル / PDF ファイルから 1 つを選んで絞り込みます。 「PDF のタイトルだけで検索したい」「フォルダ名だけ見たい」といった用途に使います。

検索対象 (Ctrl+F / Ctrl+G 共通)

どのメタデータソースを検索するかを選びます。「すべて」だと以下 6 ソースの OR:

  • ファイル名: ファイル名 (拡張子込み)
  • EXIF: カメラ本体の撮影情報 (メーカー・モデル・レンズ・絞り etc.)
  • mXD ツイート情報: mXD が保存した XMP ツイート本文・投稿者・URL
  • AI プロンプト (PNG): Stable Diffusion などが PNG tEXt に埋め込んだプロンプト (Negative Prompt は自動で除外)
  • PDF メタ情報: PDF のタイトル / 著者 / 件名 / キーワード
  • タグ: mImageViewer のタグ機能で付けた #タグ名

単一ソースに絞ると、そのソース以外の情報はノイズとして弾かれます。例えば 「EXIF のレンズ名だけで探したい」「AI プロンプトに EXIF が混ざって困る」といった場面で使います。

タグピッカー (Ctrl+G 専用)

検索バー右の「タグ」ドロップダウンから登録済みタグを選ぶと、クエリ欄に #タグ名 が 自動で追記されます。タグ名の正確な表記を覚えていなくても使えます (タグ機能参照)。

7. 結果の読み方

Ctrl+F の結果表示

  • マッチしたアイテムだけがグリッドに残り、ヒット件数が検索バー右に出ます。
  • 通常のサムネイル操作 (Space / Enter でフルスクリーン等) はそのまま使えます。
  • Esc / × で元のフォルダ全表示に戻ります。

Ctrl+G の結果表示

  • ヒットした画像は「コンテナ」(直上のフォルダまたは ZIP) ごとに集約されます。
  • 各コンテナには代表サムネ (そのコンテナ内の最初のヒット画像) と、 下部の背景色付きボックスにパス階層 + ヒット件数バッジが表示されます。 これでキーワードと関係ない画像までは出さず、代わりに中身を 1 枚のサムネで把握できます。
  • 並び順は件数バッジ右の「ソート:」コンボから切り替えできます (件数順 / 名前順 / 新しい順 / 古い順)。新しい/古い順は初回選択時に更新日時を取得するので、HDD では 一瞬固まることがあります。
  • コンテナをダブルクリックで中を覗くと、当該フォルダ配下のヒットだけを樹形で表示します (ヒットを含まない枝は自動で刈られます)。
  • Ctrl+↑/↓ でコンテナを跨いで前後のヒット画像へ移動できます。
  • 大量ヒット時は 10000 件で打ち切られます (検索バーに「絞り込みキーワードを追加してください」と出ます)。

8. 検索インデックスの作成と保守

mImageViewer は 2 種類のインデックスを持ちます。どちらも既定では OFFで、 お気に入りダイアログで個別に ON にする必要があります。

インデックス格納するもの使われる検索既定
名前索引 フォルダ / ZIP / PDF / 動画の名前 Ctrl+S OFF
メタ索引 画像の全文: ファイル名 + EXIF + XMP + AI プロンプト + PDF メタ + タグ Ctrl+G / Ctrl+F 高速パス / グリッドのタグバッジ OFF

ON にする手順

  1. メニュー「お気に入り」→「編集」でお気に入りダイアログを開く。
  2. お気に入りごとに並んだ「名前索引」「メタ索引」のチェックボックスを ON にする (追加直後の既定は両方 OFF)。
  3. ON にしたお気に入りは、その場で配下を再帰的に走査してインデックスを作成します。 以降は自動監視でファイル追加/削除/変更を反映します。

進捗の確認

初期スキャン中は次の場所で進捗を確認できます:

  • ウィンドウタイトルバー: (インデックス更新中) がサフィックスに出ます (名前索引・メタ索引のどちらかがスキャン実行中なら表示)。
  • お気に入りダイアログ: 各お気に入り行にインライン状態 (⏳ 起動中 / ⏳ スキャン中 / ✅ 等) が出ます。

大容量お気に入り (数万枚) で初回は数分〜数十分かかる場合があります。スキャン中に mImageViewer を終了しても、次回起動時に続きから再開されます。

インデックスの再構築

正常運用では自動監視で同期されるため、手動再構築は通常不要です。 それでもインデックスが壊れた / 怪しいと感じる場合:

  • チェックボックス OFF → ON: お気に入りダイアログでチェックを一度 OFF にして ON に戻すと、配下を再度フル走査します (該当お気に入りだけ)。
  • インデックスファイル削除 → 再起動: 以下のファイル / フォルダを削除して mImageViewer を再起動すると、ON にしている全お気に入りが初期スキャンからやり直します。
    • 名前索引: %APPDATA%\mimageviewer\search_index.db
    • メタ索引: %APPDATA%\mimageviewer\fts_meta.db および %APPDATA%\mimageviewer\fts_index\ フォルダ
