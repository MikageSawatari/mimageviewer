検索機能

mImageViewer には 4 種類の検索モード (Ctrl+S / Ctrl+F / Ctrl+G / Ctrl+T) があります。 「S はフォルダ・ZIP・PDF を探す / G は画像・PDF・動画・音声 1 件ずつを探す / F は今見ている場所を絞る / T はタグで探す」と覚えると使い分けが簡単です。

1. 4 つの検索モードの使い分け

ショートカット 名称 検索対象 検索できる情報 典型的な用途
Ctrl+S コンテナ検索 お気に入り配下のフォルダ / ZIP / PDF 名前のみ 「あのフォルダ、どこに置いたっけ?」をフォルダ名・ファイル名で呼び出す
Ctrl+F 現在地フィルタ 今表示中のグリッドのすべてのアイテム フォルダ・ZIP・PDF はファイル名。画像・動画はファイル名 + EXIF / XMP / AI プロンプト / PDF メタ / 動画メタ / サイドカー 開いているフォルダを絞り込む (Lightroom のフィルタに近い)
Ctrl+G アイテム検索 お気に入り全体の画像 / PDF / 動画 / 音声 画像・PDF・動画はファイル名と各種メタ情報、音声はファイル名 お気に入り横断で画像やメディアを掘り出す
Ctrl+T タグビュー mIV タグ付き項目 アプリ内カタログに保存された mIV タグ タグから画像・動画・音声・フォルダ・ZIP/PDF を探す
💡
どれを使えばいい?
  • フォルダ・ZIP・PDF を名前で探したい → Ctrl+S (コンテナ検索)
  • 今開いている場所の中で絞り込みたい → Ctrl+F (現在地フィルタ)
  • お気に入り全体から画像・動画・音声 1 件を見つけたい → Ctrl+G (アイテム検索)
  • タグで横断的に探したい → Ctrl+T (タグビュー)

2. Ctrl+S: コンテナ検索

お気に入りに登録したルート配下のフォルダ / ZIP / PDF の名前を横断検索します。 動画はコンテナ (フォルダ・アーカイブ) ではないため対象外です。過去に訪れたフォルダや よく使うアーカイブを名前で素早く呼び出すのに向いています。

  1. メニュー「お気に入り」→「コンテナ検索 (Ctrl+S)」で画面上部に検索バーが出ます。
  2. キーワードを入力すると即座に部分一致で絞り込まれます (大小区別なし)。
  3. 結果は名前昇順で最大 5000 件まで表示されます。
  4. × ボタンまたは Esc で閉じ、元のフォルダに戻ります。
⚠️
事前にコンテナ索引を ON にしてください: Ctrl+S の対象はコンテナ索引に登録されたエントリだけです。 コンテナ索引は既定で OFFなので、お気に入りダイアログで「コンテナ索引」の チェックを ON にする必要があります (ON にするとその場で再帰的に走査し、以後は自動追従)。

絞り込みフィルタ

  • お気に入り: 「すべて」または単一のお気に入り配下に絞り込み。コンテナ索引 ON のお気に入りだけが候補に出ます。
  • 種別: すべて / フォルダ / ZIP / PDF から 1 つ選んで絞り込み。
  • OR 検索: 後述の OR モードに切り替え。

3. Ctrl+F: 現在地フィルタ

Ctrl+F で今表示しているグリッドの中身を絞り込みます。 索引なしでその場で動作するため、コンテナ索引・アイテム索引のどちらも ON にしていないフォルダでも使えます。

  1. メニュー「ファイル」→「現在地フィルタ (Ctrl+F)」で画面上部に検索バーが出ます。
  2. キーワードを入力して Enter で絞り込みます (入力中は実行されません)。
  3. 「検索対象」ドロップダウンでどのメタデータを見るかを変更できます (後述)。
  4. × ボタンまたは Esc で閉じます。

アイテム種別ごとの絞り込みルール

現在地フィルタはグリッドに表示されているすべての種類のアイテムを対象にします:

  • フォルダ / ZIP / PDF ファイル: ファイル名 (basename) でマッチ判定します。
  • 画像 / 動画: 「検索対象」の設定に応じて、ファイル名・EXIF・XMP・AI プロンプト・PDF メタ・動画メタ・サイドカーを検索します。
  • PDF ファイル: ファイル名に加え、検索対象が「PDF メタ情報」または「すべて」のときはタイトル・著者・件名・キーワードも対象になります。

「検索対象」を EXIF など画像専用の次元に設定すると、その情報を持たないフォルダ・ZIP・PDF は すべて非表示になります。これは意図どおりの動作です (「EXIF で絞った場合は画像だけ残る」)。

マッチ件数は検索バーに「X/Y 件」と表示されます。すべての可視マッチをカウントします。

ZIP 内を表示中の場合

ZIP を開いた状態では、検索対象がファイル名のみに固定されます。 ZIP 内の画像は AI プロンプト・EXIF などのメタ情報を逐次読み取る仕組みを持たないため、ファイル名で素早く絞り込む用途に特化しています。 I/O なしで即座に動作するため、大きなアーカイブでも快適に使えます。

PDF ページを表示中の場合

PDF を開いてページ一覧を表示しているときは、Ctrl+F は無効になります (ショートカット無反応・検索バーは開きません)。 PDF のページは連番の名前しか持たないため、絞り込んでも得られる情報がほとんどないためです。

4. Ctrl+G: アイテム検索

メニュー「お気に入り」→「アイテム検索 (Ctrl+G)」でお気に入り全体を 横断検索します。数万件規模でも全文索引による高速検索で、即座にヒット件数と候補が表示されます。 画像・PDF・動画・音声が対象で、ZIP は対象外です (ZIP を探すには Ctrl+S を使います)。 音声はファイル名で検索でき、曲名やアーティストなどの埋め込み情報は検索対象になりません。

  1. 任意のタイミングで Ctrl+G を押すと画面上部に検索バーが出ます。
  2. キーワードを入力すると 300ms のデバウンス後に自動実行されます。結果が確定するまでは、 検索バーのヒット件数に「検索中」と表示されます。
  3. 結果は「一覧」または「集約」で表示されます (後述)。
  4. × ボタンまたは Esc で閉じて元のフォルダに戻ります。
⚠️
事前にアイテム索引を ON にしてください: Ctrl+G はお気に入りダイアログ (お気に入り → 編集) で「アイテム索引」を ON にした お気に入り配下だけを対象にします。アイテム索引は既定で OFFのため、 ON にしない限り Ctrl+G でヒットは出ません。

最小クエリ長の制限

Ctrl+G は索引の精度を確保するため、検索語に以下の最小長を要求します:

  • CJK (日本語・中国語・韓国語): 2 文字以上
  • ASCII / 数字: 3 文字以上

Ctrl+F と Ctrl+S にはこの制約はありません (直接文字列一致のため短いトークンでも動きます)。

タグ候補への橋渡し

mIV タグは Ctrl+G / Ctrl+F の検索結果には混ぜませんが、入力した語が mIV タグ名と 一致または前方一致すると、検索バーの下に「タグ候補」が表示されます (Ctrl+G と Ctrl+F の両方)。 候補ボタンを押すと、そのタグの Ctrl+T タグビューを開けます。

5. Ctrl+T: タグビュー

Ctrl+T で、mImageViewer 内部のカタログに保存されたタグから項目を探します。 タグはファイル本体や XMP には書き込まれず、Ctrl+F / Ctrl+G の全文検索には含まれません。 タグを探すときはこのタグビュー、またはグリッドのスマートフィルタのタグ欄を使います。

  • 入力欄の右にある「一覧▼」から、ピン留めしたタグ・最近使ったタグ・件数の多いタグを選べます。
  • タグを入力または一覧から選ぶと、そのタグが付いた画像・動画・音声・フォルダ・ZIP/PDF などをグリッドに表示します。#cat #dog のように複数タグを入力すると AND 検索になります。「すべての種類」プルダウンで画像・動画・音声・フォルダ・ZIP/PDF・アーカイブに絞れます。
  • タグメニュー・ツールバー・メタデータパネルのタグを右クリックして「このタグで探す」からも開けます。
  • 結果からフォルダ・ZIP/PDF・アーカイブを開いた後は、BS またはフォルダバーの ⬆ でタグビューの結果一覧へ戻れます。
  • 削除済み・移動済みのパスは結果から除外されます。

詳しい使い方はタグ機能を参照してください。

6. 検索クエリ構文 (Ctrl+S / Ctrl+F / Ctrl+G 共通)

書き方意味例
word1 word2AND: すべて含む夕焼け 海辺
-wordNOT: 含まない (除外は常に AND)夕焼け -曇り
"word1 word2"フレーズ: 連続する文字列"golden hour"
-"word1 word2"フレーズの NOT-"low quality"
🔤
大文字小文字の扱い: クエリは自動で小文字化されて比較されます (SunSet == sunset)。

OR 検索モード

検索バー右端の □OR チェックを入れると、AND ではなく OR で include トークンを結合します。ただし -word の除外は常に AND で効きます。

クエリAND モード (既定)OR モード (チェック時)
klee paimon 両方の語を含むものだけ いずれかの語を含むもの
klee paimon -sleep -nsfw "klee" と "paimon" を両方含み、"sleep" も "nsfw" も含まない "klee" か "paimon" のいずれかを含み、"sleep" も "nsfw" も含まない
💡
いつ OR モードを使う? 同じ対象を別表記で呼ぶ場合 (例: sunset と 夕焼け をまとめて拾いたい、 klee と クレー のどちらでも見つけたい、など) に便利です。 OR にしても除外語は AND なので、klee クレー -nsfw で安全に広く拾えます。

7. 絞り込みドロップダウン

検索バー右側のドロップダウンで、検索範囲をさらに狭めることができます。 どのバーがどのドロップダウンを持つかは下表のとおり:

Ctrl+G の検索バーは横幅が足りないと折り返して表示されます。Ctrl+G のドロップダウンを 開いてホイール操作している間は、背後のグリッドはスクロールしません。

ドロップダウンCtrl+SCtrl+FCtrl+G
お気に入り◯—◯
種別 (フォルダ/ZIP/PDF)◯——
種別 (画像/PDF/動画/音声)——◯
検索対象 (ファイル名/EXIF/XMP/…)—◯◯
集約トグル——◯
OR 検索チェック◯◯◯

お気に入り (Ctrl+S / Ctrl+G)

「すべて」または特定の 1 つのお気に入りに絞ります。複数のお気に入りをまたぐ検索で、 対象を狭めたいときに使います。Ctrl+S ではコンテナ索引 ON のお気に入り、Ctrl+G ではアイテム索引 ON のお気に入りだけが候補に出ます。

種別 (Ctrl+S 専用)

すべて / フォルダ / ZIP ファイル / PDF ファイルから 1 つを選んで絞り込みます。 「PDF だけ探したい」「フォルダだけ一覧したい」といった場面で使います。

種別 (Ctrl+G 専用)

画像 / PDF ファイル / 動画ファイル / 音声ファイルから 1 つを選んで絞り込みます。 「PDF のタイトルだけで検索したい」「音声ファイルだけに絞りたい」といった用途に使います。

検索対象 (Ctrl+F / Ctrl+G 共通)

どのメタデータソースを検索するかを選びます。「すべて」だと以下 7 ソースの OR:

  • ファイル名: ファイル名 (拡張子込み)
  • EXIF: カメラ本体の撮影情報 (メーカー・モデル・レンズ・絞り etc.)
  • XMP ツイート情報: ローカルファイルに埋め込まれたツイート本文・投稿者・URL
  • AI プロンプト (PNG): Stable Diffusion などが PNG tEXt に埋め込んだプロンプト (Negative Prompt は自動で除外)
  • PDF メタ情報: PDF のタイトル / 著者 / 件名 / キーワード
  • 動画メタ情報: FFmpeg が読める動画のタイトル / 作者 / 説明 / URL / チャプター名
  • サイドカー: 画像と同じ場所に置かれた同名の JSON / テキストファイル (画像名.json / 画像名.txt) の中身。作者名・作品名・元 URL・各種ラベルなどを そのまま全文検索できます。mIV タグとは別系統で、中身の語をそのままキーワードとして検索します (例: ラベルや作者名)。読み取り専用で、 サイドカーファイルを書き換えることはありません。

単一ソースに絞ると、そのソース以外の情報はノイズとして弾かれます。例えば 「EXIF のレンズ名だけで探したい」「AI プロンプトに EXIF が混ざって困る」といった場面で使います。

mIV タグは全文検索の検索対象には含まれません。タグで探す場合は Ctrl+T のタグビュー、 またはグリッドのスマートフィルタのタグ欄を使います。

8. 結果の読み方

Ctrl+F の結果表示

  • マッチしたアイテムだけがグリッドに残り、ヒット件数が検索バー右に「X/Y 件」で出ます。
  • 通常のサムネイル操作 (Space / Enter でフルスクリーン等) はそのまま使えます。
  • Esc / × で元のフォルダ全表示に戻ります。

Ctrl+G の結果表示 (一覧 / 集約)

Ctrl+G の結果は 一覧 と 集約 の 2 種類の表示で見られます。 検索バーの「集約」トグルボタンで切り替えます。

  • 一覧: ヒットしたアイテムをサムネイル単位でフラットに並べます。 少数ヒットなど「直接 1 枚を見たい」用途に向いています。 並び順は通常グリッドのソート設定に従います。
  • 集約: ヒットを親フォルダ単位でまとめ、フォルダごとにヒット件数バッジ付きのタイルで表示します。 大量ヒット時に全体像を把握するのに向いています。 タイルをダブルクリックするとフォルダ内のヒットだけを掘り下げて表示します (ドリルイン)。

ヒット件数が多い場合は自動的に集約表示に切り替わります。ユーザーが結果を操作したあとは自動切替は行われません。

  • ストリーミング中は途中まで見つかった件数に「検索中」が付きます。0 件表示は検索完了後だけです。
  • 集約モードの並び順は件数バッジ右の「ソート:」コンボから切り替えできます (件数順 / 名前順 / 新しい順 / 古い順)。
  • ドリルイン中は「← 戻る」で一覧または集約に戻ります。
  • Ctrl+↑/↓ でコンテナを跨いで前後のヒット項目へ移動できます。
  • 大量ヒット時は 10000 件で打ち切られます (検索バーに「絞り込みキーワードを追加してください」と出ます)。

9. 検索索引の作成と保守

mImageViewer は 2 種類の索引を持ちます。どちらも既定では OFFで、 お気に入りダイアログで個別に ON にする必要があります。

索引格納するもの使われる機能既定
コンテナ索引 フォルダ / ZIP / PDF の名前 Ctrl+S (コンテナ検索) OFF
アイテム索引 画像 / PDF / 動画のファイル名と各種メタ情報、および音声のファイル名 Ctrl+G (アイテム検索) OFF

ON にする手順

  1. メニュー「お気に入り」→「編集」でお気に入りダイアログを開く。
  2. お気に入りごとに並んだ「コンテナ索引」「アイテム索引」のチェックボックスを ON にする (追加直後の既定は両方 OFF)。
  3. ON にしたお気に入りは、その場で配下を再帰的に走査して索引を作成します。 以降は自動監視でファイル追加/削除/変更を反映します。

進捗の確認

初期スキャン中は次の場所で進捗を確認できます:

  • ウィンドウタイトルバー: (インデックス更新中) がサフィックスに出ます (コンテナ索引・アイテム索引のどちらかがスキャン実行中なら表示)。
  • お気に入りダイアログ: 各お気に入り行にインライン状態 (⏳ 起動中 / ⏳ スキャン中 / ✅ 等) が出ます。

大容量お気に入り (数万枚) で初回は数分〜数十分かかる場合があります。スキャン中に mImageViewer を終了しても、次回起動時に続きから再開されます。

索引の再構築

正常運用では自動監視で同期されるため、手動再構築は通常不要です。 それでも索引が壊れた / 怪しいと感じる場合:

  • チェックボックス OFF → ON: お気に入りダイアログでチェックを一度 OFF にして ON に戻すと、配下を再度フル走査します (該当お気に入りだけ)。
  • 索引ファイル削除 → 再起動: 以下のファイル / フォルダを削除して mImageViewer を再起動すると、ON にしている全お気に入りが初期スキャンからやり直します。
    • コンテナ索引: %APPDATA%\mimageviewer\search_index.db
    • アイテム索引: %APPDATA%\mimageviewer\fts_meta.db および %APPDATA%\mimageviewer\fts_index\ フォルダ

ℹ️

検索中はフォルダバーの戻る / 進む / A/B クイックフォルダ / 履歴メニューは無効化されます (検索中の移動はフォルダ履歴に残らないためです)。 親フォルダボタン (⬆) は検索結果の階層を 1 階層戻るボタンに切り替わり、最上位では無効になります。 ツリー順の前 / 次ボタン (▲ / ▼) は Ctrl+↑/↓ と同じく前後のヒットフォルダへ移動します。

検索結果から右クリックメニューの「フォルダに移動」を選んだときは検索を終了して実フォルダへ着地し、その移動は通常どおりフォルダ履歴に残ります (移動先で ← を押すと検索前のフォルダに戻れます)。

ℹ️
IME 変換中の Enter (変換確定) や Esc (変換キャンセル) は検索バーが奪わないようになっています。 日本語をそのまま入力して変換確定するだけで検索できます。
