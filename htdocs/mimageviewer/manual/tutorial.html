チュートリアル

スクリーンショットを見ながら、具体的なシナリオに沿って主要機能の使い方を紹介します。 「ボタンを押せばすぐ分かる」操作は省き、少し設定が必要なもの・ 最初は見つけにくい / 戸惑いやすいものを中心にまとめています。 各項目をクリックすると、画面を広く使った解説ページが開きます。

💡
ラベルの見方 — 要設定 事前にちょっと準備が要る / 見つけづらい 導線が分かりにくい / 戸惑いやすい 動きに最初とまどう
⌨️
本チュートリアルに出てくるキーは既定の割り当てです。操作をカスタマイズしている場合、 いま実際に効くキーは各画面で ?（ショートカット一覧）を押すと確認できます。

1. 基本機能 — まずここから

どの使い方でも土台になる、最初の流れ・フォルダの行き来・フルスクリーン閲覧・アーカイブ・初期設定。

🚀
はじめての 10 分
起動してフォルダを開き、カーソル位置・チェック・表示・移動・戻るまでをひと通り体験する導入シナリオ。
🧭
フォルダを開く・移動する戸惑いやすい
ドライブから開く、フォルダバー、そして Ctrl+↑/↓ のツリー移動・BS で親フォルダ。「今どこにいるか」を見失わないコツ。
🔍
フルスクリーン閲覧の基本
フィット切替（0）・部分拡大（Z）・Ctrl+ホイール・パン・回転・? の一覧。拡大表示の土台。
🗜️
アーカイブを開く（必要に応じて ZIP へ変換）要設定
ZIP / CBZ はそのまま、条件を満たす RAR / CBR は直接、それ以外は ZIP へ変換して読む。変換キャッシュの管理も解説。
⭐
お気に入りで素早くアクセス
よく見るフォルダをお気に入り登録し、横断検索（Ctrl+G）の対象にする。音声はファイル名だけで検索。追加・並べ替え・編集の基本。
🗃️
ファイルを整理する（コピー・移動・削除）
右クリックメニュー、ドラッグ＆ドロップ、名前を指定したフォルダ作成、A / B クイックフォルダで整理する。
🖥️
表示モードを選ぶ（1 画面 / 別ウィンドウ）要設定
フル機能ウィンドウと複数ウィンドウの違い、動画・音声だけを別ウィンドウで開く設定、F12 の使い方。
⚙️
環境設定と操作カスタマイズ要設定
最初に見ておきたい設定項目と、キー割り当ての変え方、変えた設定を元に戻す方法。テーマや表示倍率もここで。

2. 画像・漫画・コミックを見る

大量の画像やアーカイブ、漫画をストレスなく閲覧するための機能。

📖
見開きで漫画を読む戸惑いやすい
右綴じ / 左綴じの切り替えと、表紙がズレるときの先頭ページ調整。本読みのページ順について。
📚
漫画を快適に読み続ける
縦 / 横連結、フィット、表示トリム、読書位置の復元、読書履歴。長い作品を読み進めるための設定。
🪄
AI アップスケールで拡大して見る要設定
低解像度の画像や古い CG を、AI で高精細化して鑑賞する。モデル選びと適用範囲。
🗂️
ファイル名スタックで一覧をすっきり戸惑いやすい
同じ接頭辞・連番を 1 セルに畳む仕組み。集約⇔フラット切り替えと Shift+↓/↑ ジャンプ。
🔀
2 枚を並べて比較する見つけづらい
X でピン留め →C 切り替え・Shift+C ワイプ・Alt+C 差分。加工前後の見比べに。
🔎
検索で目的のファイルを探す戸惑いやすい
Ctrl+F（現在地の絞り込み）/Ctrl+S（フォルダ・ZIP・PDF を名前で）/Ctrl+G（画像・動画はメタ情報も、音声はファイル名のみ）の使い分け。

3. 印を付けて整理する

増えていくコレクションに印を付けて、あとから探し出す・続きへ戻るためのワークフロー。

🏷️
タグを付けて分類する
ファイル本体を書き換えずに「#タグ」で分類。付与のしかたとタグビュー（Ctrl+T）。
🎨
色で絞り込む（カラー検索）見つけづらい
表示中の一覧を色でフィルタ。使う瞬間にスキャンして、許容範囲を調整しながら絞り込む。
⭐
レーティングで星付け・横断一覧
☆1〜5 を付けて、場所をまたいだフラット一覧で見返す。設定日時での並べ替え。
📕
本棚に集めて 1 冊にまとめる
バラの画像・ZIP/PDF ページ・動画フレームを本へ集約。追加先の切り替えと読書。
🔖
ブックマークで続きから戻る
本のページや動画・音声の再生位置に目印を付け、種類をまたいだ一覧で見返す。★やタグとの使い分け。

4. 写真・イラストを加工する（非破壊）

元ファイルは触らず、表示だけに効果を重ねる編集ツール群。まず「加工の全体像」で流れをつかみ、あとは使いたい加工だけ読めば OK。

🗺️
加工の全体像（非破壊編集の流れ）
編集の起点（左パネル）、非破壊で記録される仕組み（移動で消える設定・バックアップ）、結果をファイルにする 2 つの方法。最初にここを。
🎨
明るさ・色を補正する（＋表示トリム）
明るさ・コントラスト・色・レベルの全体補正、プリセット保存、表示トリム。まず押さえたい表示の基本。
🩹
消しゴムで不要物を自然に消す
汚れやノイズをマスクして AI で補完。筆・囲みツールとマスクスロット・Undo。
◐
補正レイヤーで部分的に補正戸惑いやすい
マスク付きレイヤーで「背景だけぼかす」「人物だけ明るく」。マスクの作り方と重ね方。
▦
モザイク・白塗りで隠蔽加工
モザイク・白 / 黒塗り・ぼかしを非破壊で重ねる。タイルサイズやオブジェクト編集。
✂️
切り取りで出力範囲を決める
出力に反映される切り取り。範囲外が暗くなり、書き出し・本棚に切り取った画像が入る。自動クロップも。
💬
吹き出し・テキスト・注釈を入れる
吹き出し・装飾テキスト・オノマトペ・赤枠 / 矢印 / 蛍光マーカーなどの図形を重ねる。

5. 動画・音楽を楽しむ

ビューアのままメディアを再生。隠れた便利機能もここで紹介します。

🎬
動画をインライン再生する
フルスクリーンでそのまま再生。シーク・倍速・ループと、映像を止めて音声だけ聴く（Z）モード。
🎞️
動画をもっと使いこなす
タイルモード（S）、ブックマーク、チャプター移動、現在フレームの保存。基本再生の先の機能。
🎵
音楽を波形・スペクトラムで再生
上部の ♪ から音楽ビューへ。波形・スペクトラム・鍵盤表示で聴く。

6. さらに使いこなす・最適化

大量のコレクションを快適に扱うための、一歩進んだ設定と運用。

🧰
一覧を掘り下げる（並べ替え・絞り込み）
並べ替え・詳細表示・スマートフィルタ・サブフォルダ展開・代表サムネイル固定で、グリッドを使い倒す。
🔬
画像分析モードで色・ピクセルを調べる見つけづらい
ホバーバーの 🔬（Shift+Z）で起動。カラーピッカー・ヒストグラム・等倍拡大。Z（ズーム）との違いも整理。
⚡
サムネイルキャッシュで高速表示要設定
Off / Auto / Always の違いと、大きなフォルダを一括でキャッシュ作成しておく運用。
ℹ️
各機能のすべての項目・設定は、左メニューの機能別リファレンス（グリッド表示・検索機能など）に網羅しています。 このチュートリアルは「よく使う流れ」を抜き出したガイドです。
