ブラウザ連携

ブラウザで見ている画像を PC に保存し、mImageViewer の窓で開くための設定です。

Chrome / Edge 用の拡張機能は公開準備中です。本体側の設定を先に用意しています。ブラウザから開くには、拡張機能の公開をお待ちください。

拡張機能の入れ方・公開後の使い方

公開準備中です。現在はストアからインストールできません。公開後、この節に Chrome / Edge のインストール先と手順を掲載します。

以下は拡張機能の公開後に使える操作と注意点です。

  1. 下記の mIV 側の登録を行います。
  2. ブラウザで画像を右クリックし、「mIV で見る」を選びます。サイト独自のメニューが出る場合は、Shift を押しながら右クリックするとブラウザのメニューを出せることがあります。
  3. 初めて使うサイトでは、画像のあるサイトとページのサイトへのアクセス許可をブラウザが確認します。画像ファイルへのリンクがある場合は、リンク先のサイトへの許可もまとめて確認します。取得対象となる画像のサイトに一つでも許可がないと取得できません。画像を取得するサイトがすべて許可済みで、ページのサイトを許可していない場合は、窓の位置を推定して開きます。
  4. 画像を「ブラウザ閲覧」フォルダに保存し、ブラウザのページ部分に重ねて mIV の窓を開きます。mIV が起動していない場合は起動します。

対象は選んだ画像 1 枚です。動画や SVG、HTTP / HTTPS 以外の画像は対象外です。ただし、ページの画像を直接取得できない形式でも、HTTP / HTTPS の画像ファイルへのリンクがあればリンク先を開けます。ログインが必要な画像や大きな画像など、取得できない画像もあります。

拡張のアイコンのバッジは、処理中が ...、成功が OK、エラーが ! です。詳しい説明は、アイコンにマウスを重ねると表示されます。

拡張のアイコンに出る知らせ対処
...（処理中）完了を待ってから次の画像を開きます。
OK（成功）mIV への受け渡しが完了しました。リンク先が画像でなく、ページの画像を取得できる場合は、ページに表示されている画像を開き、その旨を知らせます。
!（リンク先は画像ではない）リンク先は画像ではなく、ページの画像もこの拡張では取得できない形式です。HTTP / HTTPS の画像を選び直します。
未登録・連携できないmIV の環境設定でブラウザ連携を登録します。
更新・再起動が必要mIV や拡張機能を更新し、起動中の mIV を終了して起動し直します。
mIV が見つからないmIV を入れ直すか連携を解除します。mimageviewer.exe を移動した場合は、新しい場所から起動して連携を登録し直します。
サイトの許可がない・取得できないブラウザの拡張機能の設定でサイトへの許可を確認します。許可済みでも、サイトの制限や転送先によって取得できない場合があります。

拡張からの受け渡しが成功しても、mIV の状態によっては開けないことがあります。★固定で保存先が対象のお気に入りの範囲外になる場合は、★固定を解除してから操作してください。リモート操作中や本の構成を編集中など、受け付けられない理由は mIV 側で知らせます。

mIV 側の登録と解除

  1. mimageviewer.exe から通常版の mIV を起動します。
  2. 「設定」→「環境設定…」→「起動と連携」→「ブラウザ連携」を開きます。
  3. 「ブラウザ連携を使う」にチェックを入れます。「Chrome / Edge に登録されています。」と表示されれば登録済みです。

登録・解除と保存先の変更は、この画面で操作するたびに反映します。「キャンセル」で画面を閉じても、反映済みの登録・解除は取り消されません。処理中に画面を閉じても処理は続きます。

登録を変更できるのは、既定のデータフォルダ %APPDATA%\mimageviewer を使う mIV だけです。ポータブル版、--data-dir を指定した起動、起動元の mimageviewer.exe を確認できない起動では、理由を表示して設定を変更できなくします。直接起動した本体ではなく、mimageviewer.exe から起動してください。連携用のファイルがないと表示された場合は、mIV を入れ直してください。

解除するには同じ画面の「連携を解除」を押します。「ブラウザ連携を使う」のチェックを外した場合も、使用中の連携を解除します。解除しても保存済みの画像は残り、ブラウザの拡張機能も削除されません。拡張機能の削除はブラウザ側で行います。

mIV をアンインストールする前に、この画面で連携を解除してください。別の管理者アカウントの資格情報を使ってアンインストールすると、mIV を使っていたアカウントの登録は残ります。

保存先と「ブラウザ閲覧」

保存先のフォルダは、ページ構成の設定にかかわらず、いつも単ページで開きます。見開きを選ぶと開いている間は見開きになりますが、開き直すと単ページに戻ります。

既定の保存先は、Windows の「ピクチャ」内の mimageviewer\browser です。その中の 2026-11 のような月別フォルダへ、元の画像形式のまま保存します。保存先と月別フォルダは、最初の保存時に作成します。

環境設定の「ブラウザ閲覧の保存先」で「変更…」から選ぶか、フォルダの絶対パスを入力して「保存先を適用」を押します。入力したパスは環境設定の「OK」でも反映できます。「既定に戻す」でピクチャ内の保存先へ戻り、「フォルダを開く」で保存先を開けます。保存先を変更しても、以前保存した画像は移動しません。

連携が有効な間は、メインウィンドウの「場所▼」→「ブラウザ閲覧」から保存先へ移動できます。ファイル名は保存日時・ページのドメイン・連番から付き、既存のファイルは上書きしません。クリップボード取り込みの保存先とは別です。

保存前に失敗した画像は残りません。保存後に、出どころの記録や mIV への受け渡し、表示に失敗した場合は、保存済みの画像が残ります。窓が開かなかったときも保存先を確認してください。

重ねて開く窓の動き

ブラウザのタブやアドレスバーの下にある、ページの表示領域へ窓を重ねます。位置合わせはおおよそのもので、ページの拡大率、サイドパネル、モニターの表示倍率などによってずれることがあります。位置を合わせるのは開くときだけで、後からブラウザを動かしても追従しません。

環境設定のビューワモード開き方
フル機能ウィンドウ（編集機能あり）一覧と連動する別ウィンドウで開きます。通常は別ウィンドウを使わない設定でも同じです。既に F12 の別ウィンドウが開いている場合は、閉じて作り直します。
複数ウィンドウ（編集機能なし）開くたびに新しい窓を作り、前の窓は残します。全体の色調補正・ポストフィルタ・AI の表示設定は使えますが、消しゴムや補正レイヤーなどの編集の道具は使えません。

どちらのモードでもメインウィンドウの一覧は保存先の月別フォルダへ移り、開いた画像が選ばれます。未起動から mIV を起動したときはメインウィンドウも表示され、ブラウザの一部を隠すことがあります。

ブラウザから開いた窓を対象とする「別ウィンドウ表示の切り替え」（既定 F12）は使えません。メインウィンドウやリングから同じ操作をした場合も同じです。F11 の枠なし全画面表示は使えます。新しくブラウザから開く窓は、枠付きで開きます。

Esc や「×」で窓を閉じたとき、mIV はメインウィンドウを前に出しません。次にどの窓が前に出るかは Windows が決めるため、ブラウザへ戻ることは保証できません。この窓の位置は、通常の F12 の別ウィンドウの保存位置を上書きしません。

補正を画像ごとに残す

mIV の補正は保存した元画像を書き換えません。その画像だけに補正を残したい場合は、補正パネルの書き込む先で「このページ」を選んでから調整します。後で「ブラウザ閲覧」を開くと、画像の一覧に「補」の印が付きます。

「標準」を選んだままの調整は、その場所の標準設定を変えます。アップスケールの U などのショートカットも、画像に個別設定があればそこへ、なければお気に入りの標準、または共通の標準へ書き込みます。新しく保存した画像では通常は標準を変えるため、ほかの画像にも効き、「補」の印は付きません。

サムネイルに反映されるのは色の補正で、アップスケールやポストフィルタは反映されません。補正や編集を画像ファイルとして残すには、Ctrl+E のエクスポートを使います。詳しくは画像補正をご覧ください。

通信と出どころの記録

拡張機能の公開後、「mIV で見る」を選んだときだけ、選んだ画像を拡張機能が取得します。画像ファイルへのリンクがある場合はリンク先を先に取得し、画像ではなかったときだけページに表示されている画像を取得します。サイトの Cookie はブラウザの規則に従って付きます。それぞれの最初の URL への要求には、ページや画像の参照元の指定にかかわらず、ページのアドレスのホスト名まで（例: https://example.com/）を参照元として送ります。参照元にページのパスや検索語は含めません。転送先への要求とその参照元はブラウザの規則に従い、転送先の許可がない場合などは取得できないことがあります。

許可したサイトでは、窓の位置合わせのために直前の右クリックの座標と窓の位置・大きさを記録します。ページ本文は読みません。「mIV で見る」を選んだときだけ、画像データとページ・画像・転送後の URL、窓と右クリックの座標を、この PC 内の mIV へ渡します。これらを開発者へ送信することはありません。

保存した画像には Windows の Mark of the Web として、ページの URL と取得後の画像の URL を記録します。ファイルの内容とは別の記録で、Windows がインターネット由来のファイルとして扱うためのものです。通信と保存データの詳細はプライバシーポリシーをご覧ください。
