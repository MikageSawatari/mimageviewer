クリップボード取り込み

コピーした画像を保存したり、コピーしたページに含まれる画像を選んで保存したりできます。

コピーしたときに取り込む

「設定」→「環境設定…」→「起動と連携」→「クリップボード取り込み」で、使いたい取り込み方法にチェックを入れ、「OK」で確定します。クリップボードの取り込み監視は、チェックを ON にしたときだけ動きます。

チェック項目動作
画像がコピーされたら自動で保存するコピーした画像を取り込みフォルダへ PNG で保存し、画面右下の小窓で知らせます。「開く」を押すと保存した画像へ移動します。
ページ (HTML) がコピーされたら、含まれる画像を選んで保存できるようにする画像を含むページの内容がコピーされると、右下に「このページの画像 N 件」という小窓が出ます。「画像を選んで保存」を押すと選択ダイアログが開きます。

監視は mImageViewer の起動中だけ動きます。タスクトレイ常駐と組み合わせて使えます。小窓が出ても、作業中のアプリからフォーカスを奪いません。「×」で通知を閉じられます。

ページの画像を選ぶには、mImageViewer の一覧画面でほかのダイアログを閉じておきます。受付できないときは、小窓に「一覧画面で Ctrl+V を押すと開けます」と表示します。その場合の保存先は、下記の Ctrl+V と同じく今のフォルダです。

ページの画像を選ぶ

  1. ブラウザで、画像を含むページの内容を選んでコピーします。ページのアドレスだけをコピーした場合は対象になりません。
  2. 小窓の「画像を選んで保存」を押します。この時点でページに含まれる画像の取得が始まります。
  3. 表示された縮小画像のチェックを選び、「選んだ N 枚を保存」を押します。

「最小サイズ (短辺 px)」で、小さな画像を一覧から除外できます。最初は 100 px で、変更した値を覚え、次にダイアログを開くときにも使います。「全選択」「全解除」も使えます。同じ内容の画像はひとつにまとめます。

取得できた画像はチェック済みで表示します。取得に失敗した画像には理由が表示され、選択できません。取得が終わると保存できるようになります。保存中は「閉じる」、Esc、タイトルバーの「×」で閉じられません。完了後はメイン画面で保存件数を知らせます。途中で保存に失敗した場合も、保存済みのファイルは残ります。

取り込みフォルダとファイル名

自動取り込みの保存先は、Windows の「ピクチャ」内の mimageviewer\clipboard です。その中の 2026-10 のような月別フォルダへ保存します。別の場所に保存したいときは、環境設定の「保存先フォルダ」で「変更…」を押します。「実際の保存先」で場所を確認し、「フォルダを開く」からも開けます。

一覧画面の「場所▼」→「クリップボード取り込み」から、取り込みフォルダへ移動できます。この項目は、取り込みのチェックがどちらかひとつでも ON のときだけ表示します。

ファイル名は取り込んだ日時・出どころのドメイン（わかる場合）・連番で付きます。たとえば、同じコピーで保存した画像は 20261006-123456-789-example.com_01.jpg、20261006-123456-789-example.com_02.png のようになります。ページから取り込んだ場合のドメインは、ページのものを使います。

同じコピーの画像は共通の名前に連番が付くので、ファイル名スタック表示で 1 コピーを 1 スタックとしてまとめられます。既存ファイルは上書きせず、名前が重なる場合は別の名前で保存します。ページから取得した画像は元の画像形式のまま保存します。

Ctrl+V で今のフォルダへ保存する

一覧画面で Ctrl+V を押すと、画像なら PNG を今のフォルダへ保存し、ページの HTML なら画像の選択ダイアログを開きます。選んだ画像も今のフォルダへ保存します。自動取り込みのチェックが OFF でも使えます。

ファイル・フォルダをコピーしている場合は、従来どおり Windows 標準の貼り付けになります。ファイル・フォルダ、画像、ページの HTML の順に優先します。ZIP・PDF の中や検索結果など、ファイルを貼り付けられない一覧では使えません。

ページの HTML を取り込む場合、コピー内容にページの出どころが記録されていないときや、画像候補がないときは「取り込める画像がありません」と表示して終了します。

取り込まないもの・取得できない画像

自動監視では、Office からのコピー、文章だけのコピー、直前と同じ画像の連続コピーを取り込みません。mImageViewer 自身がコピーした画像も自動では取り込みません。手動の Ctrl+V には、自動監視のこれらの除外を適用しません。

ページの画像をすべて取得できるとは限りません。ブラウザの Cookie やログイン情報を使わないため、ログインが必要な画像や、参照元を確かめるサイトの一部などは取得できないことがあります。コピー範囲に含まれない画像や SVG も対象外です。

社内ネットワークのページからコピーした画像も取り込めます。通信先はブラウザにならった規則で制限し、コピー元のページのアドレスの区分（公開・社内・この PC）より内側の宛先へは取りに行きません。ただし、この区分はアドレスで判断するため、社内のすべてのサービスへの通信を防げるわけではありません（社内でもグローバルな IPv6 アドレスを使うサービスは公開と同じ扱いになります）。ログインが必要な場合は、社内の画像でも取得できません。

出どころの記録

出どころの URL がわかる画像には、Windows の Mark of the Web としてページや画像の URL を記録します。ファイルの内容とは別の記録で、Windows がインターネット由来のファイルとして扱うためのものです。コピー元が URL を渡さない画像では、出どころを記録できません。

通信とデータの扱いについては、プライバシーポリシーをご覧ください。
