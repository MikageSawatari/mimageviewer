製本・本棚

画像、ZIP/PDF 内のページ、動画フレーム、クリップボード画像を 1 冊の本へ集め、 番号順の画像フォルダとして整理する機能です。元ファイルを参照し続けるプレイリストではなく、 追加時点のページをコピーして本棚に保存します。

基本の考え方

本棚ルート直下の各フォルダが 1 冊の本です。ページは 0001_元名.ext のような番号付き画像ファイルとして保存されます。 Explorer でフォルダごとコピーしたり ZIP 化しても、番号順に並べればページ順が保たれます。

本棚ルートと本フォルダは、通常のお気に入りや Ctrl+S / Ctrl+G の自動検索対象にはしません。 本の中ではソート操作も番号順に固定され、手動で混入した ZIP・PDF・フォルダ・動画などの画像以外はページとして表示されません。

読書履歴

メニュー「ファイル」→「読書履歴を開く」、またはフォルダバーの「場所▼」→「読書履歴」（ドライブ一覧の下、本棚フォルダの上）から、 最近フルスクリーンで読んだ画像フォルダ、ZIP、PDF、対応アーカイブを一覧できます。 同じ「場所▼」では「読書履歴」の下から本棚フォルダも開けます。動画は読書履歴には入りません。

  • 画像だけで構成されたフォルダを読んだ場合は、そのフォルダが記録されます。
  • ZIP / PDF / 対応アーカイブを読んだ場合は、その本体が記録されます。
  • コンテナ検索から開いた本は記録されます。アイテム検索やタグビューから開いた一時的な結果は対象外です。
  • サムネイルや一覧の項目にマウスを重ねると、場所（フルパス）、最終閲覧日時、既読位置をツールチップで確認できます。複数のフォルダやドライブにある同名の本も場所で見分けられます。
  • 詳細表示では「更新日時」列が「最終閲覧」に、「状態」列が「既読位置」に変わり、最終閲覧日時と既読位置をそれぞれの列で一覧できます。
  • 履歴から開くときの「続きから / 先頭から」は、環境設定の「ライブラリ → 履歴と復元」に従います。
  • 読書履歴から開いた本を閉じると、実フォルダではなく読書履歴に戻ります。続けて前に読んでいた別の本を探せます。
  • 削除済みの本を開こうとした場合は移動せず、通知して履歴から外します。外付けドライブ未接続などアクセス不能の場合は、勝手に履歴から削除しません。
  • 項目を右クリックして「この本のフォルダに移動」を選ぶと、その本が入っている実フォルダへ移動し、前後の本を探せます。

履歴の項目は右クリックから 1 件ずつ削除できます。記録の ON/OFF、保持件数、全件クリア、起動時に読書履歴を開く設定は 環境設定 → ライブラリ → 履歴と復元 と 起動と連携 → 起動時に開く場所 で変更できます。

ページをブックマークする

本をフルスクリーンで読んでいるときに B を押すと、現在の基準ページを ブックマークできます。同じページは重複登録しません。対象は製本した本、ZIP / CBZ / PDF、 対応アーカイブ、および「画像のみのフォルダを本として扱う」が有効な画像フォルダです。

  • 左パネルの「ブックマーク」タブでは、上部のブックマーク追加ボタンから現在ページを登録できます。登録済みページはサムネイル付きで確認でき、行を選ぶとそのページへ移動し、右側の削除ボタンはブックマークだけを削除します。
  • 画像フォルダではページ番号ではなく相対ファイル名を記録するため、後から画像が追加・削除されてページ番号が変わっても同じファイルを探します。
  • 見開き・連結表示では、ページ表示やシークバーが示す基準ページを 1 件登録します。
  • 透過画像の背景色切り替えは Shift+B です。操作カスタマイズで割り当てを変更できます。

動画・音声・本のブックマークをまとめて見る

フォルダバーの「場所▼」→「ブックマーク」では、動画・音声・本のブックマークを 通常のメイン一覧に 1 ブックマーク 1 項目で表示します。サムネイル表示と詳細表示を切り替えられ、 種類・拡張子・場所・タグ・評価・状態など通常一覧の絞り込みをそのまま利用できます。 ブックマーク専用の「すべて / 動画 / 音声 / 本」でも絞り込め、本についてはさらに 「画像フォルダ / ZIP・CBZ / PDF / その他アーカイブ」へ絞り込めます。既定は登録日時の新しい順です。

ダブルクリックまたは Enter で、動画・音声は登録時刻、本は登録ページへ直接移動します。 Delete または右クリックの削除はブックマークだけを削除し、元ファイルは削除しません。 元ファイルやページが一時的に見つからない項目は「見つかりません」と表示して残します。

追加先の本

「追加先の本」は、次にページを追加する本です。メニュー「製本」またはツールバーの 本棚: セクションで切り替えられます。

  • 追加先の本に追加：選択中またはチェック済みの画像・ページを追加先の本へ追加します。
  • クリップボードの画像を本に追加：クリップボード上の画像を、新しいページとして追加します。
  • 追加先の本を開く：現在の追加先の本を mImageViewer 内で開きます。
  • 本棚フォルダを開く：本棚ルートを Explorer ではなく mImageViewer 内で開きます。
  • 製本の管理：本の作成、名前変更、削除、追加先の本の切り替えを行います。

追加対象に画像・ページ以外が混在している場合は、一部だけ追加せず全体を中止します。 本ページを別の本へ追加する場合は、画像ファイルと一緒にタグ・★・補正・消しゴム・隠蔽加工・注釈などの mImageViewer 内部編集情報もコピーされます。同じ本へ同じページを追加する操作は中止されます。

ツールバーに本を固定する（クイック追加）

よく使う本をツールバーに固定しておくと、ワンクリックでその本へページを追加できます。 「追加先の本」を切り替えなくても、固定した本それぞれへ直接振り分けられるので、複数の本に並行して仕分けるときに便利です。

  • 固定する：メニュー「製本」→「製本の管理…」を開き、各本の 「固定」 ボタンを押すと、その本がツールバーの「本棚:」セクションにボタンとして並びます。もう一度押すと外れます。
  • 左クリック：その本を開きます。
  • 右クリック：選択中・チェック済み・フルスクリーン表示中のページを、その本へ追加します（既に入っているページはスキップしてトーストで知らせます）。
  • 固定した本のボタンは「追加先の本」（Ctrl+B の対象）とは独立して動きます。本の名前変更・削除にも自動で追従します。

ツールバーの「本棚:」セクションは、セクション名を右クリックして表示形式（展開 / 折りたたみ）を切り替えられます。詳しくは 設定リファレンス → ツールバーの操作とカスタマイズ を参照してください。

保存される内容

通常画像や ZIP 内画像は、焼き込む編集が無い場合は再エンコードせず、 元ファイルまたは ZIP 内の画像をそのまま保存します。補正、回転、隠蔽加工、消しゴム、 補正レイヤー、テキスト注釈、切り取りのいずれかがあるページは、編集結果を原寸で 1 枚の画像に焼き込んで保存します。PDF ページ、動画フレーム、クリップボード画像も画像として保存されます。

!
表示用の効果について: 表示用のフィルタ（セピア・CRT・縮小など）やシャープ化、AI アップスケール、ノイズ除去は本の画像には焼き込まれません。 ページごとの編集だけを元の大きさで保存するため、表示設定を変えても本へ追加した画像の大きさは変わりません。 消しゴムの補完を簡易処理で再作成した場合は、追加完了時にお知らせします。

追加後の本ページにも、mImageViewer 内部のタグ・★・画像補正・消しゴム・補正レイヤー・隠蔽加工・テキスト注釈を重ねられます。 本ページは外部サイドカーを作らず、グローバル補正やお気に入り別補正を継承しません。 投稿前に一部を隠す、セリフを差し替える、といった後段加工に使えます。

本ページの回転はページ順や見開きの意味が変わりやすいため、初期版では本棚内での後からの回転操作は無効です。 必要な回転は追加時に焼き込まれます。

本の並べ替え

本を開いているときに「この本を並べ替え」を選ぶと、専用ウィンドウでページ順を編集できます。 小サムネイルをドラッグして挿入位置へ移動し、ホバーで拡大プレビューを確認できます。 Ctrlクリックで複数選択、Shiftクリックで範囲選択ができます。

  • ドラッグ移動：選択ページをまとめて挿入位置へ移動します。ドラッグ中は端へ近づくと自動スクロールします。
  • 左右ボタン：選択ページを 1 ブロックとして前後へ移動します。
  • 別の本へコピー / 移動：上部の本一覧から移動先を選び、選択ページを別の本へコピーまたは移動します。
  • サムネサイズ：上部スライダーで並べ替え画面のサムネイルサイズを調整できます。
  • キーボード：PageUp / PageDown / Home / End で一覧をスクロールできます。

並べ替えウィンドウは閉じる時に順序を保存します。別の本へ移動・コピーする場合は、現在の並び順を先に確定してから処理します。 ページを移動・コピーした場合も、対象ページの mImageViewer 内部編集情報は移動先へ引き継がれます。

検索とお気に入り

本棚はページを整理するための出力先なので、お気に入りとして登録できません。 本棚の上位フォルダをお気に入りに登録している場合でも、本棚ルート以下は Ctrl+S / Ctrl+G の自動索引から除外されます。 本の中で探したい場合は、通常のツールバー検索や Ctrl+F の現在フォルダ検索を使います。
