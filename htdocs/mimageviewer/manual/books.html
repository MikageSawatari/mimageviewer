製本・本棚

画像、ZIP/PDF 内のページ、動画フレーム、クリップボード画像を 1 冊の本へ集め、 番号順の画像フォルダとして整理する機能です。元ファイルを参照し続けるプレイリストではなく、 追加時点のページをコピーして本棚に保存します。

元ファイルをその場所に残したまま名前付きの一覧へまとめる場合は、コレクションを使います。

基本の考え方

本棚ルート直下の各フォルダが 1 冊の本です。ページは 0001_元名.ext のような番号付き画像ファイルとして保存されます。 Explorer でフォルダごとコピーしたり ZIP 化しても、番号順に並べればページ順が保たれます。

本棚ルートと本フォルダは、通常のお気に入りや Ctrl+S / Ctrl+G の自動検索対象にはしません。 本の中ではソート操作も番号順に固定され、手動で混入した ZIP・PDF・フォルダ・動画などの画像以外はページとして表示されません。

本の構成を編集する

書庫・PDF・EPUB の本では、閲覧中の HUD の「…」または本一覧の右クリックから「本の構成を編集」を開き、元ファイルを変えずにページの順序、非表示、ページごとの表示方法を指定できます。見開きの組は、残りのページから自動で作ります。画像だけのフォルダは「ZIP に変換」してから、作成した ZIP の構成を編集してください。

  1. 画面の上で「読む方向」と「表紙あり・なし」を選びます。表紙ありでは、並べ替え・非表示を適用した後の先頭ページを表紙として扱います。
  2. 左の元ページ一覧で、ページをドラッグするか「前へ」「後へ」で順序を入れ替えます。「非表示」「表示に戻す」も左で操作します。隠したページは左に印を付けて残し、右の結果と閲覧中には表示しません。
  3. 右に自動で組んだ結果が表示されます。ページを選び、「単独で表示」で一枚の組にするか、「隣を白紙にする」で片側に置き、反対側を白紙にできます。白紙を付ける場合は実ページを置く側も選べます。指定したページには内容の分かる印が付き、「自動」で指定を解除できます。

右側では順序を入れ替えません。隣り合うページを組にするので、組にしたいページは左で隣へ並べてください。片側を非表示にした場合や単独表示を指定した場合は、後のページも組み直します。指定のない横長ページは通常どおり単独になり、表紙・先頭・末尾の配置や自動の単独表示は環境設定と本ごとの設定に従います。構成を使う本も「末尾の単ページへ表紙を添える」の環境設定と本ごとの設定に従います。組ごとに表紙を添える指定は行いません。

表紙ありの見開きで、構成を適用した後の最後が単ページなら、設定に従って空き側へ表紙を添えます。最後のページを非表示にした場合は、残りを組み直した結果で判定します。末尾の「単独で表示」にも表紙を添えます。ただし「隣を白紙にする」を明示した末尾ページは、実ページを置く側と白紙を保ち、表紙を添えません。自動の単独表示で付く白紙は、末尾表紙設定が有効なら表紙に置き換わります。本全体で添えたくない場合は、本ごとの末尾表紙設定を OFF にしてください。最後が二枚の組、表紙だけの本、表紙なし、単ページ・横長分割、絞り込んだ一覧では添えません。

「単独で表示」は、そのページから組を作り直す起点として、表紙と同じ配置規則を使います。本来の側は左→右読みでは画面右、右→左読みでは画面左です。PC のページ単位の見開きでは、ページめくりアニメーションが ON の間は本来の側へ置きます。OFF のときは「先頭の単ページを本来の側に置く」の全体設定と本ごとの設定に従います。末尾の単独指定も先頭設定に従い、横長ページの単独は中央です。末尾に表紙を添える場合は二枚の表示になり、これまでどおり末尾ページと表紙を並べます。「隣を白紙にする」の白い側も、通常の見開きと同じように前後へめくります。末尾の明示白紙も対象で、表紙を添えない指定は保ちます。

「単独で表示」または「隣を白紙にする」を指定したページの直前で、組にできず一枚だけ余った縦長ページは、末尾単ページの配置規則を使います。左→右読みでは画面左、右→左読みでは画面右です。PC のページ単位の見開きでアニメーションが ON の間はこの側へ置き、OFF のときは末尾単ページの全体設定と本ごとの設定に従います。連結読みと Remote は保存済みの末尾設定に従い、横長の余りは中央です。指定ページそのものの配置は上記の規則を使い、この余りに末尾の表紙は添えません。

変更は右の結果へそのまま反映されます。「元に戻す」「やり直す」で編集中の変更を戻せます。白紙は指定した実ページの空き側だけに表示され、独立して選択・移動することはできません。単ページ・横長分割では白紙を表示せず、ページの書き出しにも含めません。

保存前に、元の窓が保存後に表示するページを確認できます。現在のページを非表示にすると、その窓の以前の順序で次のページ、前のページ、新しい先頭の順に移り、可視ページがなければ一覧へ戻ります。同じ本を開いた別窓もそれぞれの位置から移ります。「キャンセル」は編集中の変更を破棄します。「構成を解除」は編集画面に重なる確認ダイアログを開きます。「解除する」で確定すると、順序・非表示・ページ指定と構成の読む方向・表紙指定を解除し、通常の本ごとの設定へ戻します。原本のページを削除する操作ではありません。確認中は背面を操作できず、「キャンセル」または Esc で編集へ戻れます。Enter は確認を確定します（日本語変換中のキーは確認には使いません）。

編集中は別の本を開く操作や背景の閲覧を止めます。Remote が操作権を取得すると Remote を優先し、未保存の編集を破棄して通知します。すでに送信した保存は一度だけ完了します。外部でページが変わった場合は保存を止め、編集内容を残して読み直しを案内します。「ページを読み直す」を押すと、同じ形式の確認ダイアログで未保存の変更を破棄することを説明します。「読み直す」で再読込、「キャンセル」または Esc で編集を続けます。保存前の移動先は編集画面の下部に常時表示し、別の確認操作は必要ありません。保存失敗では以前の構成と編集中の内容を保持し、保存後の読み直しに失敗しても保存データは残ります。再読み込みまたは再起動してください。読めない構成を自動で消去することはありません。「今回は構成を使わず開く」は、選んだ窓の今回の閲覧だけに適用されます。

構成がある本の読む方向・表紙・ページごとの指定は、この画面で変更します。閲覧中の単ページ・見開き・横長分割・連結読みの切り替えや、先頭・末尾の配置、表紙の次・最終ページの自動単独表示、末尾への表紙の添付設定は引き続き使えます。見開きの一ページずらしは使わず、組の調整はページごとの指定で行います。Remote では表示方法と自動配置の設定を変更でき、構成全体の編集は PC で行います。

単ページから見開きへ戻すには、上部バーの「見開き」、または構成の読む方向と表紙に一致するキーを使います。標準では左→右・表紙なしが 2、左→右・表紙ありが 3、右→左・表紙なしが 4、右→左・表紙ありが 5 です。テンキーも同じです。不一致のキーを押すと、戻せるキーと構成編集を案内します。PC では操作カスタマイズの割り当てを使い、未割り当てなら上部バーを案内します。横長分割は上部バーまたは専用のカスタム割り当てで切り替え、標準の 8/9 は構成がある本では使いません。ゲームパッドの Select は単ページと構成に一致する見開きを切り替えます。Remote の 2〜5 も一致するキーで見開きへ戻せます。これらの表示切り替えで、構成の読む方向・表紙や保存済みの見開き調整は変わりません。

製本への追加と一括書き出しは、構成で並べ替えた可視ページの順を使います。白紙や末尾に添えた表紙は追加の画像にしません。検索結果などから選択した場合も、出力時点で本の構成の非表示を確認し、該当ページを除外して通知します。

Remote では、並べ替え・非表示を適用した後のページ列にも、通常の本と同じ件数・応答容量の制限が掛かります。大きい本の一覧が途中で区切られると、PC と見開きの組が異なる場合があります。その場合は表紙の次・最終ページの自動単独表示や先頭・末尾の配置、末尾への表紙の添付が適用されません。ページごとの単独・白紙指定は、取得した範囲で適用します。

EPUB の構成は元 EPUB とページ番号で保存されるため、再変換によって同じ番号の内容が変わることがあります。必要なら構成を解除して作り直してください。

画像フォルダを ZIP に変換する

一覧の実フォルダを右クリックして「ZIP に変換…」を選ぶか、画像フォルダで「本の構成を編集」を開いたときの案内から「ZIP に変換」を押します。画像数・容量・引き継ぐ登録や編集・作成先を確認してから変換します。

  • 親フォルダ/写真集/ は 親フォルダ/写真集.zip になります。画像を再圧縮しない ZIP（Stored）で保存し、元のフォルダと画像は残します。同名の ZIP がある場合は上書きしません。
  • 直下に画像があり、サブフォルダ・動画・音声・別の本を含まない実フォルダが対象です。表示設定や絞り込みで隠している画像も含め、直下の全画像を保存します。メタ情報やテキストなど画像以外のファイルは ZIP に入れず、元の場所に残します。
  • 元フォルダ自身と全画像のタグをまとめ、ZIP 本体のタグにします。ZIP 内の各ページには個別のタグを複製しません。★・画像の編集内容・しおり・読書位置などは ZIP 側にも引き継ぎ、元側の登録を残します。
  • コレクションの登録・並び順は変えず、元のフォルダや画像を参照し続けます。後で元フォルダを削除すると、その登録は「見つかりません」になります。ZIP をコレクションに入れたい場合は、作成後に別途登録します。

変換中は別の本を開く操作や背景の閲覧操作を止めます。「取消」で中止できますが、保存を確定する段階からは取り消せません。完了画面で保存先を確認できます。別ウィンドウから始めた場合は、その窓の元の閲覧を保ちます。一覧で ZIP が見えるかどうかは、環境設定 → ファイル処理 → 同名ファイルの「本を表示 / フォルダを表示 / 両方表示」と、通常の絞り込みに従います。

本ごとの見開き調整

製本した本や画像だけの本フォルダ、ZIP / CBZ / PDF / EPUB、対応アーカイブでは、Ctrl+← / → で合わせ直した見開きを既定で記憶します。ZIP内の作品は別々に記憶し、履歴や読書位置を消しても調整は残ります。上部バーの … → 見開きの調整 から状態・基点を確認し、この本の調整を解除できます。記憶のON/OFFとPDF / EPUBの制限も参照してください。

記憶がONなら、mIV Remoteでも保存した基点に従って見開きを組み合わせます。構成を保存していない本では、リモートでページ構成や読み方向を変えると、この本の調整も解除します。構成を保存している本の読む方向・表紙とページごとの指定は、PCの「本の構成を編集」で変更します。1ページずらしと記憶設定の変更はPCで行います。

本の名前を変更すると、保存済みの見開き調整は新しい名前の本へ引き継がれます。開いている別窓は変更前の場所を参照し続けるため、新しい場所から開き直してください。一覧から「★固定」に切り替えた場合も、固定した一覧に基点のページが含まれていれば、そのページを基点に調整を保ちます。メタ情報の再インポートで調整が変更されなかった本は、各窓の現在の見開きを保ちます。

閲覧履歴

メニュー「ファイル」→「閲覧履歴を開く」、またはフォルダバーの「場所▼」→「閲覧履歴」（ドライブ一覧の下、本棚フォルダの上）から、 ユーザーがフルスクリーンで開いた画像フォルダ、ZIP、PDF、対応アーカイブ、動画、音声を最終閲覧順に一覧できます。 同じ「場所▼」では「閲覧履歴」の下から本棚フォルダも開けます。

  • 画像だけで構成されたフォルダを読んだ場合は、そのフォルダが記録されます。
  • ZIP / PDF / 対応アーカイブを読んだ場合はその本体、動画・音声を開いた場合はそのファイルが記録されます。
  • 絞り込みバーで「すべて / 動画 / 音声 / 本」を切り替え、「本」では画像フォルダ / ZIP・CBZ / PDF / その他アーカイブへさらに絞り込めます。
  • スライドショー、次フォルダへの自動送り、動画・音声の連続再生による自動遷移は記録されません。↑↓ / ホイール / Ctrl+↑↓ などの手動移動は記録されます。
  • コンテナ検索から開いた本は記録されます。アイテム検索やタグビューの画像ページは対象外ですが、そこで手動で開いた動画・音声はファイル単位で記録されます。
  • サムネイルや一覧の項目にマウスを重ねると、場所（フルパス）、最終閲覧日時、閲覧位置をツールチップで確認できます。複数のフォルダやドライブにある同名の本も場所で見分けられます。
  • 詳細表示では「更新日時」列が「最終閲覧」に、「状態」列が「閲覧位置」に変わり、最終閲覧日時と閲覧位置をそれぞれの列で一覧できます。
  • 履歴から開くときの「続きから / 先頭から」は、環境設定の「ライブラリ → 履歴と復元」に従います。完走した動画は履歴に残りますが、resume は従来どおり削除されるため次回は先頭から再生します。
  • 閲覧履歴から開いた本を閉じると、実フォルダではなく閲覧履歴に戻ります。続けて前に読んでいた別の本を探せます。
  • 閲覧履歴の一覧で「親へ戻る」（親ボタン・Backspace・Alt+↑）を使うと、閲覧履歴を開く前の場所へ戻ります。起動直後など戻る場所がない場合はドライブ一覧へ移ります。マウスやリングに割り当てた親操作も同じです。
  • ★固定中にファイルメニューから閲覧履歴を開いた場合、Backspaceなどの「親へ戻る」で固定を解除し、固定を始める前の場所へ戻ります。固定中は親ボタンを使えません。
  • 削除済みの本を開こうとした場合は移動せず、通知して履歴から外します。外付けドライブ未接続などアクセス不能の場合は、勝手に履歴から削除しません。
  • 項目を右クリックして「この本のフォルダに移動」を選ぶと、その本が入っている実フォルダへ移動し、前後の本を探せます。

履歴の項目は右クリックから 1 件ずつ削除できます。記録の ON/OFF、保持件数、全件クリア、起動時に閲覧履歴を開く設定は 環境設定 → ライブラリ → 履歴と復元 と 起動と連携 → 起動時の動作 で変更できます。

ページをブックマークする

本をフルスクリーンで読んでいるときに B を押すと、現在の基準ページを ブックマークできます。同じページは重複登録しません。対象は製本した本、ZIP / CBZ / PDF、 対応アーカイブ、および「画像のみのフォルダを本として扱う」が有効な画像フォルダです。

  • 左パネルの「ブックマーク」タブでは、上部のブックマーク追加ボタンから現在ページを登録できます。登録済みページはサムネイル付きで確認でき、行を選ぶとそのページへ移動し、右側の削除ボタンはブックマークだけを削除します。
  • 画像フォルダではページ番号ではなく相対ファイル名を記録するため、後から画像が追加・削除されてページ番号が変わっても同じファイルを探します。
  • 見開き・連結表示では、ページ表示やシークバーが示す基準ページを 1 件登録します。
  • 透過画像の背景色切り替えは Shift+B です。操作カスタマイズで割り当てを変更できます。

動画・音声・本のブックマークをまとめて見る

フォルダバーの「場所▼」→「ブックマーク」では、動画・音声・本のブックマークを 通常のメイン一覧に 1 ブックマーク 1 項目で表示します。サムネイル表示と詳細表示を切り替えられ、 種類・拡張子・場所・タグ・評価・状態など通常一覧の絞り込みをそのまま利用できます。 ブックマーク専用の「すべて / 動画 / 音声 / 本」でも絞り込め、本についてはさらに 「画像フォルダ / ZIP・CBZ / PDF / その他アーカイブ」へ絞り込めます。既定は登録日時の新しい順です。

ダブルクリックまたは Enter で、動画・音声は登録時刻、本は登録ページへ直接移動します。 Delete または右クリックの削除はブックマークだけを削除し、元ファイルは削除しません。 元ファイルやページが一時的に見つからない項目は「見つかりません」と表示して残します。

追加先の本

「追加先の本」は、次にページを追加する本です。メニュー「製本」またはツールバーの 本棚: セクションで切り替えられます。

  • 追加先の本に追加：選択中またはチェック済みの画像・ページを追加先の本へ追加します。
  • クリップボードの画像を本に追加：クリップボード上の画像を、新しいページとして追加します。
  • 追加先の本を開く：現在の追加先の本を mImageViewer 内で開きます。
  • 本棚フォルダを開く：本棚ルートを Explorer ではなく mImageViewer 内で開きます。
  • 製本の管理：本の作成、名前変更、削除、追加先の本の切り替えを行います。

「製本の管理」の番号列は、操作カスタマイズの「本1〜20を開く」で使う番号です。 本一覧の名前順で 1〜20 が付き、ツールバーに固定した本だけを数えるものではありません。 本の追加・名前変更・削除で名前順が変わると番号も変わり、21冊目以降には番号が付きません。 キー、メニュー、ツールバーの「追加先の本を開く」は同じ待機画面を使い、 「中止」または Esc で取り消せます。

追加対象に画像・ページ以外が混在している場合は、一部だけ追加せず全体を中止します。 本ページを別の本へ追加する場合は、画像ファイルと一緒にタグ・★・補正・消しゴム・隠蔽加工・注釈などの mImageViewer 内部編集情報もコピーされます。同じ本へ同じページを追加する操作は中止されます。

ツールバーに本を固定する（クイック追加）

よく使う本をツールバーに固定しておくと、ワンクリックでその本へページを追加できます。 「追加先の本」を切り替えなくても、固定した本それぞれへ直接振り分けられるので、複数の本に並行して仕分けるときに便利です。

  • 固定する：メニュー「製本」→「製本の管理…」を開き、各本の 「固定」 ボタンを押すと、その本がツールバーの「本棚:」セクションにボタンとして並びます。もう一度押すと外れます。
  • 左クリック：その本を開きます。
  • 右クリック：選択中・チェック済み・フルスクリーン表示中のページを、その本へ追加します（既に入っているページはスキップしてトーストで知らせます）。
  • 固定した本のボタンは「追加先の本」（Ctrl+B の対象）とは独立して動きます。本の名前変更・削除にも自動で追従します。

ツールバーの「本棚:」セクションは、セクション名を右クリックして表示形式（展開 / 折りたたみ）を切り替えられます。詳しくは 設定リファレンス → ツールバーの操作とカスタマイズ を参照してください。

保存される内容

通常画像や ZIP 内画像は、焼き込む編集が無い場合は再エンコードせず、 元ファイルまたは ZIP 内の画像をそのまま保存します。補正、回転、隠蔽加工、消しゴム、 補正レイヤー、テキスト注釈、切り取りのいずれかがあるページは、編集結果を原寸で 1 枚の画像に焼き込んで保存します。PDF ページ、動画フレーム、クリップボード画像も画像として保存されます。

!
表示用の効果について: 既定では、表示用のフィルタ（セピア・CRT・縮小など）やシャープ化、AI アップスケール、ノイズ除去は本の画像に焼き込まれません。 これらも焼き込みたいときは、環境設定 →「表示」→「書き出しの焼き込み」で製本の段を変えます （どこまで反映するかを選ぶ）。 ページごとの編集だけを元の大きさで保存するため、表示設定を変えても本へ追加した画像の大きさは変わりません。 消しゴムの補完を簡易処理で再作成した場合は、追加完了時にお知らせします。

追加後の本ページにも、mImageViewer 内部のタグ・★・画像補正・消しゴム・補正レイヤー・隠蔽加工・テキスト注釈を重ねられます。 本ページは外部サイドカーを作らず、グローバル補正やお気に入り別補正を継承しません。 投稿前に一部を隠す、セリフを差し替える、といった後段加工に使えます。

本ページの回転はページ順や見開きの意味が変わりやすいため、初期版では本棚内での後からの回転操作は無効です。 必要な回転は追加時に焼き込まれます。

本の並べ替え

本を開いているときに「この本を並べ替え」を選ぶと、専用ウィンドウでページ順を編集できます。 小サムネイルをドラッグして挿入位置へ移動し、ホバーで拡大プレビューを確認できます。 Ctrlクリックで複数選択、Shiftクリックで範囲選択ができます。

  • ドラッグ移動：選択ページをまとめて挿入位置へ移動します。ドラッグ中は端へ近づくと自動スクロールします。
  • 左右ボタン：選択ページを 1 ブロックとして前後へ移動します。
  • 別の本へコピー / 移動：上部の本一覧から移動先を選び、選択ページを別の本へコピーまたは移動します。
  • サムネサイズ：上部スライダーで並べ替え画面のサムネイルサイズを調整できます。
  • キーボード：PageUp / PageDown / Home / End で一覧をスクロールできます。

並べ替えウィンドウは閉じる時に順序を保存します。別の本へ移動・コピーする場合は、現在の並び順を先に確定してから処理します。 ページを移動・コピーした場合も、対象ページの mImageViewer 内部編集情報は移動先へ引き継がれます。 別の本へ移動したページについては、元の本の「本の構成」・見開き調整・本のサムネイル指定からそのページへの設定が外れます。

本を削除すると、その本のページに付けた編集情報・★・タグなども削除されます（しおりは「見つかりません」として残ります）。 本やフォルダを開いている途中は、並べ替えの保存・ページの移動・本の名前変更・削除を受け付けません。開き終わってからもう一度実行してください。

検索とお気に入り

本棚はページを整理するための出力先なので、お気に入りとして登録できません。 本棚の上位フォルダをお気に入りに登録している場合でも、本棚ルート以下は Ctrl+S / Ctrl+G の自動索引から除外されます。 本の中で探したい場合は、通常のツールバー検索や Ctrl+F の現在フォルダ検索を使います。
