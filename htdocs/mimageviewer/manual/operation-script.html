操作のスクリプト

画面の状態に応じて、ページ送り・表示切り替えなどの操作を組み合わせられます。

できること・できないこと

Rhai 言語で書いたスクリプトが現在の画面の状態を読み、許可された mIV の操作を返します。 「★3 を付けて次へ」「最後のページなら次の本へ」のような組み合わせを、キーやリングから呼び出せます。 本を開いたときやページが変わったときに、表示の切り替えを自動で行うこともできます。 ファイル名から画像をまとめるスタック用のスクリプトとは別の機能です。

スクリプトはレーティングやピン留めタグを変更でき、手動で呼び出したときにはキャプチャ保存やクリップボードへのコピーもできます。 レーティングの XMP 書き込みを有効にしている場合は、通常の操作と同じくファイルにも書き込みます。 人から受け取ったスクリプトは、何をするか確かめてから使ってください。 ファイルの削除・移動、ほかのプログラムの起動、インターネットへの接続はできません。

ファイルの自由な読み書き、クリップボードの読み取り、任意の設定値の読み書きはできません。 書き出し・名前の変更・編集の適用・管理画面を開く操作・元に戻す操作も呼べません。 キャプチャは mIV で設定した保存先と名前を使います。1 回の起動で保存・コピーを合わせて 1 つまでで、押しっぱなしやイベントでは保存しません。

使えるのはメインウィンドウの一覧、画像の全画面表示、動画・音声の全画面表示（音楽表示を含む）です。 別ウィンドウの表示、編集モード、ページ一覧、ダイアログ、文字入力中、mIV Remote が表示を取得している間は実行しません。 メインの画像を別ウィンドウへ表示していても、メインウィンドウの一覧では使えます。

有効にする・ファイルを編集する

  1. 環境設定 → 拡張と診断 → 操作のスクリプトを開きます。
  2. 「操作のスクリプトを使う」を ON にします。初回の説明を読み、「使う」を選びます。
  3. 環境設定の「OK」で確定します。有効化と初回確認の記録はここで保存されます。「キャンセル」なら両方とも保存されません。
  4. 同じページの「スクリプトを開く」で編集し、保存後に「再読み込み」を押します。
  5. 操作カスタマイズで「スクリプト操作 1」〜「スクリプト操作 20」にキーなどを割り当てます。既定の割り当てはありません。

確認を保存した後は、有効にし直しても初回の説明は出ません。確定した設定が OFF の間は「再読み込み」を押せません。 チェックの変更は「OK」で反映しますが、「スクリプトを開く」「再読み込み」「既定に戻す」は押した時点で働きます。

保存場所はデータフォルダ内の operation_scripts.rhai です。 通常は %APPDATA%\mimageviewer\operation_scripts.rhai、ポータブル版はプログラムと同じ場所の data\operation_scripts.rhai、--data-dir を指定している場合はそのフォルダです。

  • 有効化・起動時の読み込み・再読み込み・「スクリプトを開く」でファイルが無ければ、雛形を作ります。既存の本文や空のファイルは置き換えません。
  • 編集内容は自動で反映されません。「再読み込み」、有効にし直す、または再起動で反映します。
  • 「既定に戻す」は確認後にファイルを雛形で置き換えます。元に戻せないので必要なら先にコピーしてください。置き換え後も「再読み込み」が必要です。
  • 止めるには設定を OFF にして「OK」を押してください。ファイルを削除しても、次の読み込みで雛形が作られ、雛形の自動実行も動きます。
  • この実行許可と初回確認の記録は、設定のエクスポート・インポートや AI による設定変更の対象外です。

設定ページには確定済みの状態（OFF・読み込み中・使える・失敗とその理由）、使える場合はスロットの番号・名前・関数名と 本を開いたときなどに自動で動く処理（on_event）の有無が表示されます。編集中のチェック状態とは区別してください。失敗時は理由を直して再読み込みします。

スロットと呼び出し方

slots() は、番号 slot（1〜20、重複不可）、表示する名前 label、 状態を 1 つ受け取る関数名 run の組を配列で返します。使う番号だけ登録できます。

fn slots() {
    [#{ slot: 1, label: "★3 を付けて次へ", run: "rate3_next" }]
}
fn rate3_next(s) {
    if s.context != "fs_image" { return []; }
    ["RatingItem3", "FsPageNext"]
}

操作カスタマイズの表示名は常に「スクリプト操作 N」です。label は環境設定のスロット一覧と右クリックの 「スクリプト」メニューに表示されます。右クリックには名前の付いたスロットだけが並び、該当するスロットが無ければメニューも出ません。 動画の全画面表示では右クリックからの実行に対応していません。キー・リングなどの割り当てを使ってください。

キーのほか、一覧・画像・動画のリング、マウスジェスチャー、戻る／進む／ホイールクリック、ゲームパッドの X リングへ割り当てられます。 ツールバーには追加しません。キーを押し続けた自動繰り返しでは起動しません。マウスのダブルクリックは 2 回の起動になる場合があります。 キー入力を書き換える外部ツールの組み合わせでも、1 回の押下が複数回の起動になる場合があります。

戻り値は操作名の配列です。#{ run: ["FsPageNext"], notice: "次へ進みました" } のように通知も付けられます。 () または [] は何もしません。操作名は次の表の綴りをそのまま使います。

返せる操作と組み合わせの制約

種類制約イベントから
A：その場で表示・再生を変える並びのどこでも下表で許される操作だけ
B：本の中で移動するB と C を合わせて 1 つまで、並びの最後だけ不可
C：場所を移る・全画面を開閉するB と C を合わせて 1 つまで、並びの最後だけ不可
D：レーティング・ピン留めタグを変える並びのどこでも不可

1..20 などは番号の範囲を表します。たとえば GridColumnCount3 は 3 列にします。 表に無い操作は使えません。全体を実行前に確かめ、操作名・画面・並びの制約が合わなければ、その回は何も実行せず通知します。 実行の途中で対象が変わったり操作を受け付けられなくなった場合は、残りを実行せず通知します。先に行った変更は戻しません。

操作名の Prev / Next は前／次、First / Last は先頭／末尾です。 画像の FsSiblingPrev/Next は兄弟フォルダ、FsCtrlNavPrev/Next はフォルダまたは検索結果の移動、 GridOpenFavoriteN / GridOpenBookN / GridOpenCollectionN は登録済みの番号の場所を開きます。 RatingItem は項目、RatingContainer は現在のフォルダ・書庫など、RatingBookPreferred は本を優先するレーティングです。 Clear は解除、StepUp/Down は星を 1 つ増減します。 操作は通常のキーと同じ条件で働きます。各機能の説明はキーボードショートカットも参照してください。

音楽表示（音声ファイルと動画の音声モード）では VideoCapture と VideoSeekStripToggle は使えません。 パス・名前・画像のコピーは一覧と画像表示だけです。動画表示からのコピーはできません。

本を開いたときなどの自動実行（on_event）

fn on_event(s) を書くと、状態の変化をまとめた s.events を受け取れます。 複数の理由が同時に入ることがあるので、"open" in s.events のように含まれているかを調べます。

名前発生する変化
view一覧・画像・動画／音声の表示の切り替え
open全画面表示で、項目の入れ物（フォルダ・ZIP・PDF・EPUB）が変わったとき。一覧では発生しない
page全画面表示で、表示する項目・見開きの形や本のページ構成・分割の左右などが変わったとき
select一覧で選択中の項目が変わったとき。全画面から戻ったときの選択の変化も含む

検索結果やコレクションでも、open は表示中の項目の入れ物で判断します。 違うフォルダの画像を続けて見ると、その都度発生します。ZIP の中のサブフォルダ移動では発生せず、書庫の中の別の書庫へ移ると発生します。 変換して読む書庫では、変換後の ZIP が入れ物になります。EPUB は元の EPUB を使います。 一覧を挟んで同じ本へ入り直したときも、view・open・page が発生します。

変化は画面の更新に合わせて検出するため、短い間の複数の変化や往復は 1 回にまとまることがあります。 初回の検出も対象です。同じ項目が選ばれたままの再読み込みでは select は発生しません。 全画面の項目・表示の設定・本のページ構成が同じまま、一覧の並べ替えや絞り込みだけで見開きの組が変わった場合は page を出しません。

イベントから実行できる操作

A のうち次の 32 操作だけを使えます。ほかの入力が無ければ、その操作をきっかけに新たなイベントを繰り返し起こしません。

  • 画像の 7 操作：FsBgCycle、FsPixelGrid、FsPageTurnAnimationToggle、FsZoomIn、FsZoomOut、FsToggleMetadata、FsNavigatorToggle
  • 動画の 4 操作：VideoMute、VideoVolumeUp、VideoVolumeDown、VideoSeekStripToggle（音楽表示を除く）
  • 一覧の 21 操作：GridColumnCount1..20、GridToggleDetailsView

さらに FsReadingDirectionToggle と FsFitModeCycle の 2 操作は、 s.events に open が含まれる回だけ使えます。 横長分割と自由回転を組み合わせた表示でこの 2 操作を使うと、後で page が 1 回余分に発生することがあります。 大きさが未取得の場合や検出できない期間があれば、その後の検出にまとまります。 page だけの回に同じ 2 操作を返すと、並び全体を実行せず通知します。

見開きの形の 6 操作、3D 写真（FsDepthParallax）、スライドショー（FsSlideshow）と、動画の再生／一時停止・ループ・先頭へ・前後すべてのシークは、イベントから使えません。 3D 写真は準備の確認が開く場合があり、スライドショーは後からページを送るためです。 動画のこれらの操作は再生や次のファイルへの移動につながり、自動操作が繰り返されるおそれがあるためです。 移動・レーティング・タグ・保存・コピーもイベントからは使えません。必要な場合はスロットへ登録し、手動で呼び出してください。

イベントの呼び出しは 1 秒に 10 回までです。超えた回は実行せず、後から実行し直しません。 イベントで行う表示設定の保存も、通常のキー操作と同じです。保存が重い環境では短く引っかかることがあります。

言語と上限

四則演算・比較・論理演算、条件分岐、変数、関数の直接呼び出し、配列・マップ、配列と整数の範囲の繰り返しが使えます。 文字列の contains / starts_with / ends_with / to_lower / len、 配列の contains / len、マップの contains、in が使えます。

待機・出力・正規表現・外部ファイルの取り込み・文字列をプログラムとして実行する機能は使えません。 関数を値として扱うこと、無名関数、try / catch、値付きの break、 添字やプロパティへの代入（a[i] = x、m.key = x など）も使えません。 変数そのものへの代入と ops += "FsPageNext" のような追加は使えます。

ファイルの大きさ256 KiB
1 回の評価での計算量2,000（返す mIV の操作数とは別）
関数の呼び出し・式の深さ32
文字列8 KiB
配列・マップ200 要素（入れ子も合算）。配列を直接書く場合は 199 要素まで
マップに直接書くキー256 バイト

構文エラー・実行エラー・上限超過は通知とログに記録され、その回は何も実行しません。 読み込み時の失敗も通知とログに記録され、環境設定の「操作のスクリプト」の読み込み結果でも理由を確かめられます。 操作の途中で受付不能になった場合は、それまでの変更を保ったまま残りを中止します。

雛形の例

ファイルが無いときと「既定に戻す」で、次の内容が用意されます。

// 番号・表示名・状態を受け取る関数を指定します。
// 表示名は右クリックメニューと環境設定の「操作のスクリプト」に表示されます。
fn slots() {
    [
        #{ slot: 1, label: "最後のページなら次の本へ", run: "next_or_next_book" },
        #{ slot: 2, label: "★3 を付けて次へ", run: "rate3_next" },
    ]
}

fn next_or_next_book(s) {
    if s.context != "fs_image" { return []; }
    if s.page.is_last { ["FsSiblingNext"] } else { ["FsPageNext"] }
}

fn rate3_next(s) {
    if s.context != "fs_image" { return []; }
    ["RatingItem3", "FsPageNext"]
}

// 本を開いたとき、パスに \manga\ を含むなら読む向きを右→左にします。
fn on_event(s) {
    if s.context != "fs_image" { return []; }
    if "open" in s.events && s.book.path.contains("\\manga\\") {
        if s.view.direction != "rtl" { return ["FsReadingDirectionToggle"]; }
    }
    []
}

\manga\ を含む本を開いたとき、右から左へ読む向きに揃えます。 自分のフォルダ名に合わせて変えてください。スロットの例は画像表示で使います。

スクリプトの利用例

各例は独立した本文です。使いたい例を選び、スロットの番号や名前を自分の割り当てに合わせてください。複数の例を合わせる場合は、slots() と on_event(s) をそれぞれ 1 つにまとめます。

1. 最後のページなら次の本へ

最後のページでは次の兄弟フォルダへ、それ以外は次のページへ進みます。

割り当て：スロット 1（画像表示）

fn slots() { [#{slot:1, label:"最後のページなら次の本へ", run:"next_book"}] }
fn next_book(s) {
    if s.context != "fs_image" || s.page.is_last == () { return []; }
    if s.page.is_last { ["FsSiblingNext"] } else { ["FsPageNext"] }
}

2. ★3 を付けて次へ

表示中の画像に ★3 を付けてから、次のページへ進みます。

割り当て：スロット 1（画像表示）

fn slots() { [#{slot:1, label:"★3 を付けて次へ", run:"rate_next"}] }
fn rate_next(s) {
    if s.context != "fs_image" { return []; }
    ["RatingItem3", "FsPageNext"]
}

3. 名前で見開きの形を選び分ける

本のパスに LTR・RTL があれば表紙を単独にする左綴じ・右綴じの見開き、それ以外は単ページを選びます。

割り当て：スロット 1（画像表示、手動で呼び出す）

fn slots() { [#{slot:1, label:"名前で見開きの形を選び分ける", run:"named_spread"}] }
fn named_spread(s) {
    if s.context != "fs_image" || s.book.path == () { return []; }
    if s.book.path.contains("LTR") { return ["FsSpreadLtrCover"]; }
    if s.book.path.contains("RTL") { return ["FsSpreadRtlCover"]; }
    ["FsSpreadSingle"]
}

4. 本を開いたら読む向きを合わせる

AI に書いてもらうときのテンプレート

AI アプリとの連携で「読み取りのみ」以上と「設定の確認と変更を AI に任せる」を許可すると、 AI は MCP の operation_script で現在の本文を読み、変更した本文を書き込めます。本文も AI アプリの提供元へ送られます。 書く前に現在の本文を読ませ、戻せるように保持させてください。文法やスロットの定義に誤りがある場合や、読んだ後に本文が変わった場合は書き込みを断ります。

操作スクリプトが有効なら、AI が書き込んだ内容は自動で反映されます。無効なら保存だけを行い、有効化と初回説明の確認は利用者が環境設定で行います。 AI は有効化できません。キーなどへの割り当ては set_operations で固定名「スクリプト操作 N」を指定して頼めます。 有効にしている場合は、AI の書き換えでイベントから自動で行う表示操作や、1 回の入力で行う操作の組み合わせも変わるため、変更内容を確認してください。

次の文章に「やりたいこと」を書き足して AI に渡してください。連携を使わない場合は、このページの状態・操作の表と現在の本文も貼り付けます。 生成された本文を「スクリプトを開く」で貼り付け、保存してから「再読み込み」を押してください。

mImageViewer の操作スクリプト（Rhai 言語）を書いてください。
マニュアル: https://mikage.to/mimageviewer/manual/operation-script.html

【契約】
- fn slots() は #{ slot: 1〜20, label: "名前", run: "関数名" } の配列。
  スロット番号は重複不可。run は fn 関数名(s) に対応します。
- 関数は読み取り用の状態 s を受け取り、許可された操作名の配列を返します。
  #{ run: [...], notice: "通知" } も可。() と [] は何もしません。
- s.context は grid / fs_image / fs_video。分からない値は ()。
  対象の画面と値の有無を確かめてから使ってください。
- 最大16操作。移動・画面切り替えは合計1つで末尾だけ。
  キャプチャ保存・コピーは手動起動だけで合計1つ。
- fn on_event(s) は任意。s.events は view / open / page / select の配列。
  イベント可の32操作だけを使用。読む向きと合わせ方の2操作は open を含む回だけ。
  3D 写真・スライドショー、動画の再生／一時停止・ループ・全シーク、
  見開きの形、移動、レーティング、タグ、保存、コピーはイベント不可。
- view.depth / view.slideshow は画像・動画／音声の表示でだけ使えます。
  video.muted / video.volume_db は動画・音声だけ。音量は dB（-80.0〜+18.0）。
  grid.columns / grid.details は一覧だけ。ほかの画面では () です。
- 操作名・状態はマニュアルの表だけを使い、存在しないものを作らないでください。
- 使える補助関数: 文字列 contains / starts_with / ends_with / to_lower / len、
  配列 contains / len、マップ contains、in。配列・整数範囲の for は可。
  変数への代入・+= は可。添字・プロパティへの代入、try/catch、無名関数、
  正規表現、print、sleep、eval、import、ファイル・通信操作は不可。
- 上限: 計算量2000、深さ32、文字列8 KiB、配列・マップ200要素（入れ子合算、
  配列を直接書く場合は199）、マップのキー256バイト、ファイル256 KiB。
- 操作カスタマイズでは固定名「スクリプト操作 N」を選びます。
  label が表示されるのは環境設定と右クリックメニューです。
- mImageViewer の MCP ツールが使える場合は、operation_script で現在の本文を
  最後まで読み、戻せるように保持してから、読んだ本文を照合して書き込んでください。
  有効なら自動で反映されます。無効なら利用者に環境設定での有効化を案内してください。
  キーなどへの割り当ては set_operations で「スクリプト操作 N」を指定してください。
- 本文全体と、何を変更するか・どの画面で呼ぶかを説明してください。
