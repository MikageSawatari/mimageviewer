音響調整

音響調整には mIV Sound を使用します。イコライザーやエフェクトで音を整え、 Visualizer で音の様子や再生中の曲情報・歌詞を見ることができます。

mIV Sound について

mIV Sound は、Frieve 氏の EffeTune / EffeTune Mixwright（MIT License）を元にした、mImageViewer 専用の派生版です。 mIV Sound についてのお問い合わせは mImageViewer 側へお寄せください。

  • mIV Sound のソース
  • EffeTune の作者による使い方の動画

チェーン作成、プリセット、A/B 比較などは、基本操作をご覧ください。 新しく追加する Volume の音量は 0 dB です。

エフェクトごとの説明は、mIV Sound の説明書をご覧ください。 以下では、mImageViewer から使うときの操作と注意点を説明します。

初めて開いたときの表示

初めて開いたときは、Visualizer の mIV Original を表示します。 エフェクトを編集するときは Effect Pipeline へ切り替えます。 mIV Sound の 設定 → 環境設定... → 起動 にある 起動時の表示 は、 前回の表示 (デフォルト) が初期設定です。次回は前回の表示を引き継ぎます。

曲名と代表画像を表示する

音響調整を使用中は、再生中の曲名・アルバム名・アーティスト名と代表画像を mIV Sound へ自動で渡します。 mIV Sound の Visualizer で Artwork、Title、Album、Artist を配置すると表示できます。 曲名が無いときは拡張子を除いたファイル名を使い、アルバム名とアーティスト名は情報が無ければ空欄です。 絶対パスや URL は渡しません。このためだけに音響調整を起動することはありません。

画像は長辺1024ピクセルまでにし、縦横比を保って中央に置き、透明な余白で正方形にします。正方形の画像には余白を足しません。 動く画像は最初の一枚を使います。先に文字を送り、画像ができたら表示します。 音楽は同名画像・MP3表紙、動画は一覧と同じ代表画像を使います。 一時停止・シーク・読み込み待ち・同曲の繰り返しでは情報を残します。PCでの停止・閉じる・再生終了では消します。 リモートは最後の曲が終わっても情報を残し、次曲への切替やセッション終了で消します。切替中や開始失敗時は空表示になることがあります。

画像を読み込めないときは画像無しで送ります。送信失敗やプラグインの拒否では、前の表示が残る場合があります。 通常の受け渡し失敗では音響調整を続け、次の情報変更や初期化時に送り直します。 プラグインが5秒以上応答しないときは mIV Sound の専用ホストを終了して知らせ、音は音響調整を通さず再生します。 ほかの VST プラグインは停止しません。自動で再起動はしません。

再生に合わせて歌詞を表示する

Visualizer の Lyrics で、同じフォルダーにある曲と同名の .lrc ファイルや、 曲ファイルに埋め込まれた歌詞を表示できます。時刻付きの LRC、時刻付きの埋め込み歌詞、時刻なしの LRC、 時刻なしの埋め込み歌詞の順で選びます。一時停止・シーク・速度変更に表示が追従します。 歌詞の行をクリックして再生位置を変える操作はできません。リモート配信中は歌詞を表示しません。 表示が音とずれる場合は Lyrics のオフセットで調整します。正の値で歌詞が遅れて表示されます。

再生位置を Counter で表示する

Visualizer の Counter は、mImageViewer の再生位置を歌詞と同じ時刻で表示します。 歌詞のない曲でも使え、一時停止中は止まります。シーク・速度変更・曲の切り替え・繰り返し再生に追従します。 停止中やリモート配信中など、再生位置を受け取れないときは0を表示します。クリックしても表示時刻や再生位置は変わりません。 Counter Gallery プリセットでは、異なる見た目のカウンターを並べて使えます。 詳しくはCounter の設定をご覧ください。

利用に必要な環境

音響調整には、AVX2 と FMA の両方に対応した CPUが必要です。 mIV Sound の画面表示には Microsoft Edge WebView2 Runtime が必要です。Windows 11 には標準で含まれています。

mImageViewer で開く

メイン画面のツールバーにある音響調整ボタンから開きます。 押すと mIV Sound の窓を表示して前面に出します。表示中にもう一度押しても窓は隠れません。 窓を閉じるときは、タイトルバーの × やタスクバーのメニューを使います。 窓を閉じても音響調整は続きます。初期設定では、メイン画面を最小化すると mIV Sound の窓も一緒に隠れ、メイン画面を戻すと再び表示されます。

音響調整の窓は、初期設定では Windows のタスクバーに表示されます。 mImageViewer のアイコンの右下に音符が付いた項目を選び、最小化・復元できます。窓のタイトルは「mIV Sound」です。 音響調整ボタンからも、最小化した窓を復元できます。窓のタイトルバーやタスクバーのメニューから閉じても、音響調整の処理は続きます。

環境設定 → 動画・音声 → 動画の「音響調整 (mIV Sound)」にある 「音響調整の窓をタスクバーに表示する」を OFF にすると、タスクバーには表示されません（初期値は ON）。 OK を押すと、開いている窓にも反映します。閉じている窓は開きません。タイトルバーの大きさは ON/OFF で変わりません。 OFF のときに最小化すると窓が隠れ、音響調整ボタンで再び表示できます。最小化中に OFF へ変更したときも窓は隠れます。音響調整の処理は続きます。 メイン画面の最小化中の表示は、次の設定に従います。リモート閲覧で操作している間は、タスクバー表示の設定にかかわらず隠れます。 タスクバー上のグループ分けやメニューの表示名は Windows が決めます。

ビジュアライザーなどを最小化中も見たいときは、環境設定 → 動画・音声 → 動画の「音響調整 (mIV Sound)」で 「メインウィンドウを最小化しても音響調整の窓を表示したままにする」を ON にします（初期値は OFF）。 OK を押すと反映し、最小化中に変更しても表示が切り替わります。自分で閉じた窓は開きません。 まだ一度も表示していない窓も、この設定だけでは開きません。 リモート閲覧で操作している間は、この設定にかかわらず隠れます。 タスクトレイへの格納だけでは、どちらの設定でも音響調整の窓は隠れません。最小化した状態で格納した場合は、この設定に従います。

一度設定すると、次からは mImageViewer の起動時に音響調整が自動で有効になります。窓を開かなくても、設定した調整が効いた音で再生されます。

音の加工を止めるときは、mIV Sound 画面内の全体バイパスを使います。 音響調整ボタンの点灯は、音響調整が有効なことを示します。窓を閉じても音響調整が有効なら点灯したままです。 ボタンにポインターを重ねると、窓の開き方と音響調整が効いているかどうかが表示されます。 保存済みの設定がない場合は、初めて開いた窓を閉じるまで設定は未確認となり、ボタンは点灯しません。 この表示は mIV Sound の窓を閉じたときの設定で判定するため、窓を開いたまま変えた内容は、窓を閉じるまで表示に反映されません。

音響調整ボタンが使えない場合は、ボタンにポインターを重ねると理由が表示されます。 ポータブル版でも音響調整と、利用者が追加した VST3 プラグインを利用できます。

動画の再生時に自動で開く

環境設定 → 動画・音声 → 動画の「音響調整 (mIV Sound)」で 「起動後の最初の動画再生で音響調整の窓を自動で開く」を ON にします（初期値は OFF）。 OK を押すと反映し、この起動中で最初に条件を満たした動画の再生開始時に、一度だけ窓を開きます。 キー操作中の画面を切り替えずに表示します。通常の別窓での動画再生も対象です。音声ファイルや動画を音声として再生するモードは対象外です。

いずれかの閲覧窓が全画面のとき、メイン画面が最小化・トレイ格納で隠れているとき、 リモート閲覧で操作している間は開きません。元に戻しただけでは開かず、次の動画を開くか、一時停止後に再生を始めたときに判定します。 「最小化しても表示したままにする」を ON にしていても、自動で新しく開くときは最小化中を除きます。

再生中にこの設定を ON にしても、その再生では開きません。シークや音量ノーマライズの測定後の再開でも開きません。 この起動中に手動で窓を開いてから閉じた場合も、自動では開き直しません。 表示の準備中に設定を OFF にしたり、全画面・最小化・トレイ格納・リモート閲覧へ切り替えたりした場合は、 その自動表示を取り消し、復帰しても再試行しません。必要ならツールバーから手動で開けます。

まだ起動していない音響調整は、この自動表示で開始します。読み込み中も動画は再生を続けます。 窓を閉じても、mImageViewer を終了するまで音響調整の処理は続きます。

調整が適用される音

mImageViewer で再生する動画・音声に適用します。音響調整はステレオ（左右2チャンネル）で処理します。 ほかのアプリの再生音を調整するものではありません。

大きな音と OVERLOAD 表示

音響調整へ渡す前に、0dB を超える音のピークを抑えます。音量を全体的に下げるものではありません。 動画や音楽では、音を加工していなくても元の音が 0dB を超えることがあります。 この保護により、音の可視化だけで Level Meter に OVERLOAD が表示されるのを防ぎます。 mIV Sound 内の調整で音量を上げた場合は、OVERLOAD が表示されることがあります。

環境設定 → 動画・音声 → 動画の「mIV Sound に渡す前に 0dB を超える音を抑える」で切り替えます（初期値は ON）。 mIV Sound 内で音量を管理したい場合は OFF にすると、元の音をそのまま渡します。 ユーザーの VST3 プラグインを使っている場合は、その調整後の音に適用します。 出力側の過大な音を抑える保護は、どちらの場合も有効です。音響調整を使わないときも常に働きます。

OK を押すと、再生中の動画・音楽にも反映します。画面を開き直す必要はありません。 リモート配信にも適用しますが、すでに先読みした音声の後から反映するため、聴こえる変化には遅れがあります。

設定の保存先とプリセット

調整状態、プリセット、設定、取り込んだ IR・測定データ、Visualizer のレイアウトや背景画像は、 mImageViewer のデータフォルダー内の effetune に保存します。 通常版のデータフォルダーは %APPDATA%\mimageviewer です。 ポータブル版は実行ファイルの隣の data\effetune に保存し、従来の共通保存先からは引き継ぎません。 --data-dir で別のデータフォルダーを指定した場合も、その中に保存します。 SFZ 音源は元のファイルを参照するため、データフォルダーとは別に保管してください。

通常版では初回起動時に、従来の共通保存先にあるプリセット・設定と画面用データを一度だけコピーします。元のデータは削除しません。 --data-dir で別のフォルダーを使う場合は、そのフォルダーに音響調整の保存済み状態があるときに引き継ぎます。 ほかのアプリがコピー元を使用中の場合は、関連するアプリを終了して mImageViewer を起動し直してください。

コピー元は %APPDATA%\Frieve\EffeTunePlugin\、%APPDATA%\effetune\、 %APPDATA%\mimageviewer-vst3-host.exe\ です。mIV Sound はこれらを引き継ぎのために読み取り、日常の保存には使いません。 追加したユーザー VST や、ほかの EffeTune 製品がこれらを使うことはあります。 ユーザー VST は独自に APPDATA などへ保存する場合があり、ポータブル版でも mImageViewer からは止められません。

DAW の EffeTune Mixwright やデスクトップ版 EffeTune とは、プリセット・設定を自動で共有しません。 保存済みのプリセットを行き来させるには、設定 → バックアップ / 復元で書き出し・読み込みを行います。 .effetune_preset ファイルの読み込みにも対応します。現在のチェーンをファイルに残したい場合は、 名前付きのパイプラインプリセットとして保存してからバックアップしてください。

リモート配信で使う

リモート閲覧で配信する動画・音声にも、設定した音響調整が効いた音が届きます。

リモート閲覧で操作している間は、PC 側の mIV Sound の窓を閉じ、リモート閲覧を終えると元に戻します。 調整を変えたいときは、リモート閲覧を始める前か、終えた後に行ってください。

mIV Sound から外部サイトを開く操作

mIV Sound のヘルプはこのマニュアルを、原作のクレジットは EffeTune Mixwright の GitHub を既定のブラウザで開きます。 「AI に質問」は、入力した質問とエフェクト名を含むリンクを ChatGPT または Perplexity のページとしてブラウザで開きます。 どちらもリンクを開くだけで、mImageViewer が質問を送るわけではありません。

保存先については、プライバシーポリシーもご覧ください。
