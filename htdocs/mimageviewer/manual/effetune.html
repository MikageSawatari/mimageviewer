音響調整 (EffeTune)

EffeTune は、Frieve-A 氏が開発する音響調整ツールです。MIT License で公開されています。 イコライザーやエフェクトで音を整え、ビジュアライザーで音の様子を見ることができます。

EffeTune について

  • EffeTune 公式サイト
  • EffeTune の GitHub
  • EffeTune Mixwright の GitHub（mImageViewer が使用する EffeTune）
  • 作者による使い方の動画があります

エフェクトごとの説明は、同梱 EffeTune の説明書をご覧ください。 以下では、mImageViewer から使うときの操作と注意点を説明します。

mImageViewer で開く

メイン画面のツールバーにある音響調整ボタンから開きます。 もう一度押すか、EffeTune の窓の × を押すと窓を閉じます。窓を閉じても音響調整は続きます。

音の加工を止めるときは、EffeTune 画面内の全体バイパスを使います。 音響調整ボタンにポインターを重ねると、音響調整が効いているかどうかが表示されます。 この表示は EffeTune の窓を閉じたときの設定で判定するため、窓を開いたまま変えた内容は、窓を閉じるまで表示に反映されません。

音響調整ボタンが使えない場合は、ボタンにポインターを重ねると理由が表示されます。 ポータブル版では音響調整を利用できません。

調整が適用される音

mImageViewer で再生する動画・音声に適用します。音響調整はステレオ（左右2チャンネル）で処理します。 ほかのアプリの再生音を調整するものではありません。

複数の窓で同時に再生している場合は、最後に再生を始めた音だけに音響調整が適用されます。 一時停止から再開した場合も、その再生が対象になります。ほかの再生音は音響調整を通さずに鳴ります。

設定の保存先とプリセット

次に起動したときに同じ調整で始めるための状態は、mImageViewer のデータフォルダーに保存します。

EffeTune 自身が保存するプリセットや設定は、mImageViewer のデータフォルダーとは別に、 %APPDATA%\effetune\ または %APPDATA%\Frieve\EffeTunePlugin\ に保存されます。 取り込んだ IR ファイル・測定データ、ビジュアライザーのレイアウト・背景画像などは %APPDATA%\mimageviewer-vst3-host.exe\ に置かれます。 mImageViewer のデータフォルダーを変更しても、これらの保存先は変わりません。

エフェクトの組み合わせを保存するプリセットは、デスクトップ版 EffeTune と共有されます。 mImageViewer のデータフォルダーだけを持ち運んでも、EffeTune 自身の保存データは含まれません。

リモート配信で使う

リモート閲覧で配信する動画・音声にも音響調整を適用します。 配信前に音響調整を起動してください。配信を始めてから初めて起動した場合は、次の配信から適用されます。

PC 側の EffeTune の窓で変えた設定は、配信中の音にも反映されます。 ビジュアライザーにも配信中の音が表示されますが、先読みして処理するため、端末で聞こえる音より先に進みます。

EffeTune から外部サイトを開く操作

EffeTune のヘルプや GitHub は外部サイトを開きます。「AI に質問」を使うと、入力した質問とエフェクト名を含む URL で ChatGPT または Perplexity を開きます。質問の扱いは、そのサービスの規約・プライバシーポリシーに従います。

保存先と通信については、プライバシーポリシーもご覧ください。
