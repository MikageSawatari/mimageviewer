音楽再生

mImageViewer は音声ファイルをフルスクリーンの「音楽ビュー」で再生できます。 波形タイムラインとスペクトラム表示で曲の構造を見ながら聴けるほか、動画を再生中に映像を消して 音声だけを聴く「音声モード」にも切り替えられます。本ページでは音楽ビューの開き方・画面構成・ 再生操作・ブックマーク・VST3 プラグイン処理をまとめて説明します。

音楽ビューを開く

音声ファイルを開く

MP3 / FLAC / WAV / M4A / AAC / OGG / Opus / WMA の音声ファイルは、グリッド一覧に画像や動画と 一緒に並びます。音声ファイルをダブルクリック（または Enter）で開くと、フルスクリーンの 音楽ビューが開いて自動再生します。前後のファイルへの移動やフォルダ内の連続再生も、動画と同じ操作で 行えます。

一覧のジャケット画像

音声の一覧サムネイルと詳細一覧のプレビューには、同名の画像、MP3 に埋め込まれた画像、 音楽アイコンの順で表示します。例えば song.mp3 と同じフォルダに song.jpg を置くと、その画像が優先されます。FLAC などの音声にも同名画像を使えます。 folder.jpg など、音声と名前が違う画像は自動では選びません。

MP3 の埋め込み画像は、ファイル先頭の ID3v2 タグにある JPEG / PNG が対象です。 前面表紙を優先し、なければ最初の表示可能な画像を使います。後続のタグや末尾だけのタグは読まないため、 古い表紙や音楽アイコンになる場合があります。その場合は同名画像を置いてください。 壊れた画像や安全な読み取り上限を超える画像は採用しません。

同名画像を使うには、環境設定 → 表示 → サムネイルの 「同名の画像をサムネイルに使う（動画・音声）」と、環境設定 → ファイル処理 → 同名ファイルの 「同名の動画・音声がある画像を省略」を ON にします（どちらも既定は ON）。 採用設定を OFF にしても画像省略が ON なら画像行は隠れたままで、MP3 の埋め込み画像または音楽アイコンを表示します。 画像行を表示したい場合は画像省略を OFF にします。これは動画も音声も同じ規則です。 動画用に OFF にしていた採用設定も引き継ぎます。 詳しくは サムネイルの設定をご覧ください。

画像上の音声の目印は、環境設定で「音楽アイコン」（既定）、左下の「音声」表示、「なし」から選べます。 画像がない場合はどの設定でも音楽アイコンです。サムネイル比率の Auto は画像の比率を使います。 ジャケットは一覧とプレビューに表示し、再生画面では波形・スペクトラムを表示します。

動画→音声モード

動画を再生しているとき、映像を消して音声だけを音楽ビューで聴けます。作業用 BGM として動画を 流したいときや、波形・スペクトラムで音を確認したいときに便利です。

  • 動画再生中に上部バーの ♪ ボタン、または Z キーで音声モードへ切り替わります
  • 映像が消えて波形・スペクトラムの音楽ビューになります。音は途切れず、再生位置・音量・ 音量自動調整・VST3 の状態はそのまま引き継がれます
  • 上部バーの ▶ ボタン、または再度 Z キーで動画表示へ戻ります
  • 音声モードのまま前後のファイルへ移動でき、連続再生の途中でも音声モードを保ちます。移動先が 映像付きの動画でも、音声モードのままなら映像は表示しません

複数の音声トラックがある動画では、音声モードの下部 HUD にも「音声 N」ボタンが表示されます （ウィンドウが狭くても残ります）。ボタンから一覧を開き、聴きたいトラックを選べます。測定中は取り消してから選んでください。切り替えたトラックは動画表示と共通で、次に同じ動画を開いたときにも使われます。 トラックの表示内容と切り替えの動きは動画再生の音声トラックの切り替えを参照してください。

画面構成

波形タイムライン（中央）

画面中央には曲全体を「行」に分けた DJ スタイルの波形が表示されます。ステレオの左右チャンネルを 上下に分け、盛り上がりや打点（トランジェント）が一目で分かります。

  • 1 行あたりの長さ（10 / 15 / 30 / 60 / 120 秒）を上部バーのセレクタで切り替えられます
  • 再生位置には縦線（プレイヘッド）、ブックマーク位置には縦マーカーが表示されます
  • 波形の下には行ごとの簡易な分析レーンを併記します（音量とベース音の目安 / 推定キー）。 解析は自動で行われ、あくまで目安として色分け表示します

スペクトラム（下部）

画面下部には再生位置周辺の周波数スペクトラムを、E0〜C#10 の MIDI 半音ごとのバーとしてリアルタイム表示します。 88 鍵のピアノ鍵盤が音の内容にあわせて発光し、どの音程・音域が鳴っているかを視覚的に確認できます。 表示にマウスを重ねると、その位置の周波数・最も近い音名・音程のずれ（セント）が表示されます。

情報パネル（右）

「通常ホバー」では画面右端にカーソルを近づけると情報パネルが表示されます。 「クリック表示」では右端に現れる呼び出しバーをクリックすると表示されます。

  • ★ レーティング：画像・動画と共通の★1〜★5。絞り込みにも使えます
  • タグ：画像・動画と共通のタグ機能。曲にタグを付けて検索できます
  • 音声情報：形式・コーデック・長さ・サンプルレート・チャンネル数・ビットレート。 ファイルに埋め込まれたタイトル・アーティスト・アルバムなどの情報があれば併せて表示します

上部バーの ℹ ボタン、I または Tab で、左右パネルの呼び出し方を「通常ホバー」と「クリック表示」の間で切り替えられます。 クリック表示で開いた左右パネルは現在のファイルを表示している間だけ維持され、別のファイルへ移動するかフルスクリーンを閉じると閉じます。

タッチ画面では、音楽ビューを一度タッチすると上下の操作バーの間に左右パネル用のハンドルが表示されます。左はブックマーク、右は情報・レーティング・タグのパネルを開きます。波形のタップ操作を遮らないよう、ハンドルはグラフ外側の空き領域だけに表示され、極端に狭いウィンドウでは表示されません。

ブックマークパネル（左）

「通常ホバー」では画面左端にカーソルを近づけ、「クリック表示」では左端に現れる呼び出しバーをクリックすると、ブックマーク一覧が表示されます。各行をクリックするとその位置へ 移動でき、名称の編集（✏）や個別削除（×）もできます。パネル上部のボタンから現在位置への ブックマーク追加と、一覧の一括登録・書き出しができます（ブックマーク参照）。 再生中のファイルにチャプター情報があれば、ブックマークとチャプターを分けて表示し、 チャプター行からその位置へ移動できます。

上部バー・下部 HUD

上部バーにはファイル名・再生位置・総時間・音量・行長セレクタ・左右パネルの呼び出し方を切り替えるボタン・VST3 ボタン（有効時のみ）が並びます。 下部 HUD には シークバー（クリック / ドラッグで頭出し）と再生コントロール （頭出し / 再生・一時停止 / ループ / 連続再生 / 前後ファイル / 前後ブックマーク / ミュート / 音量スライダー / 再生速度）が並びます。複数の音声トラックがある動画の音声モードでは「音声 N」も表示されます。音楽ビューでは上部バーと下部 HUD を常に画面の幅いっぱいに表示します。右の情報パネルを固定すると、中央の波形・スペクトラムだけが狭くなり、上下の操作バーの幅は変わりません。

窓を狭めると、下部 HUD は再生・一時停止、前後ファイル、時間、ミュートに続き「音声 N」を優先し、 dB 表示や再生速度、Norm、ループ・連続再生、音量スライダーなどを順に省略します。 さらに狭い場合は時間を現在位置だけに短縮します。窓を広げると操作部は戻り、 省略中もキーボード操作と設定は変わりません。同じ窓幅では、測定中も通常再生と同じ項目・位置で表示します。

シークバーの下には曲の長さに応じた目盛りが表示され、全体の中でどのあたりを再生しているかが分かります。

再生操作

音楽ビューのキーボード操作は動画再生と共通です。主な操作は次のとおりです。

操作動作
Space / Enter再生 / 一時停止をトグル
W先頭へ移動して再生
← / →中シーク（既定 5 秒、環境設定で変更可能）
Shift+← / →小シーク（既定 1 秒、環境設定で変更可能）
Ctrl+← / →大シーク（既定 30 秒、環境設定で変更可能）
Shift+↑ / ↓音量を上げる / 下げる
↑ / ↓前 / 次のファイルへ移動
Mミュートのトグル
Lループモードの切り替え
J / K前 / 次のブックマークへ移動
B現在位置にブックマークを追加
Z音声モードの切り替え（動画再生中は映像を消す / 音声モード中は動画表示へ戻す）

これらのキー割り当ては、設定メニュー →「操作カスタマイズ…」で変更できます。 再生速度は下部 HUD の速度ボタンから変更でき、ピッチ（音の高さ）は保ったまま速く / 遅く再生します。

ループ・連続再生

ループモード

L キーまたは下部 HUD のループボタンで、ループなし → 全体ループ → ブックマーク区間ループ の順に切り替えられます。ブックマーク区間ループには隣り合うブックマークが必要です。

連続再生

下部 HUD の連続再生ボタンで、フォルダ内のファイルを順番に再生できます。曲の末尾まで再生すると、 一覧内の次のファイルを自動的に再生します。音声モードで聴いているときは、次のファイルも音声モードのまま 続けて再生します（映像付きの動画でも映像は表示しません）。曲の末尾は最後まで鳴らし切ってから次へ 進むので、末尾が途切れません。

ブックマーク

B キー、または左パネル上部のボタンで現在位置にブックマークを追加できます。 J / K で前 / 次のブックマークへ移動します。既存のブックマークと ±1 秒以内の 位置には重複して追加されません。ブックマークは動画と共通の仕組みで保存され、同じファイルを 音声・動画のどちらで開いても同じブックマークが見えます。

左パネルの一括登録ボタンから、mm:ss タイトル または hh:mm:ss タイトル 形式の リストをまとめて貼り付けてブックマーク化できます。同じダイアログから現在のブックマーク一覧を クリップボードへ書き出すこともできます。詳しい書式は動画再生のブックマークと 共通です。

VST3 プラグイン処理

音楽ビューの音声も、動画と同じように VST3 プラグインのチェーンに通してから再生できます。 LUFS 測定・EQ・コンプなどを、波形やスペクトラムを見ながらリアルタイムに適用・確認できます。 有効化・プラグインのスキャン・チェーンの管理は動画と共通で、 環境設定 → 動画・音声 → VST3 プラグイン で行います。

音声モード中も上部バーの「VST」ボタンからプラグインの GUI を表示でき、動画→音声モードに 切り替えても VST の設定はそのまま引き継がれます。詳細は 動画再生 → VST3 プラグイン処理を参照してください。

プラグインを用意しなくても、同梱の 音響調整 (EffeTune) で音を整えられます。

レーティング・タグ

音声ファイルにも F1〜F5 で★1〜★5、F6 で解除を設定でき、 操作カスタマイズで標準キーのない評価1段階上げる / 下げる操作も割り当てられます。 画像・動画と同じ★フィルタで絞り込めます。タグも共通の仕組みで、曲にタグを付けて タグ機能や検索機能から探せます。

関連する環境設定

音声の音量自動調整（ラウドネス ノーマライズ）は動画と共通の設定です。有効にすると、 ファイルを開くたびに音量を測定して曲ごとの音量差をそろえます。設定項目は 設定リファレンス → 動画・音声 にまとめてあります。

進捗パネルが表示されている測定中の前後移動は、常時表示される下部 HUD の ↑ / ↓、またはキーの ↑ / ↓ で行います。 狭い F12 音楽ウィンドウでも、測定中は通常再生と同じ配置の HUD 矢印をクリックとタッチで操作できます。 幅が足りない場合の省略順も通常再生と同じです。さらに狭い場合は時間表示を短縮または省略します。 進捗パネル内には前後ボタンはなく、取消は × または Esc です。他の再生・シーク・音量操作は測定中は使えません。 F11 で右情報パネルの固定を一時抑制していても HUD の矢印は使えます。

音声専用 VST ウィンドウでは、従来どおり測定中を含め前後移動はできません。 Esc はこのウィンドウから音楽ビューへ戻り、測定は続きます。測定の取消には進捗パネルの × を使ってください。

音声を「一覧から開く」ときと前後移動で開くときに、続きから再生するか最初から再生するかは、 環境設定 → ライブラリ → 履歴と復元 で選べます。
