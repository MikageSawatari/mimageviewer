追加の検出器

自分で入手した検出器を置いて、検出した領域を消しゴム・隠蔽加工・補正レイヤーのマスクに追加できます。

mIV は追加の検出器を配布していません。入手した検出器は配布元のライセンスに従って使ってください。

検出には見落としや誤検出があり得ます。追加されたマスクと仕上がりを確かめ、必要な修正をしてから使ってください。 検出は PC 内で行い、そのために画像を外部へ送信しません。

置き場所

各ツールの［自動検出…］で［フォルダを開く］を押すと、<データフォルダ>\detectors\ を開きます。 フォルダがなければ作成します。ポータブル版や --data-dir を使う場合も、そのデータフォルダの中です。

次のどちらかの置き方を使います。表示名は、直接置く場合は拡張子を除いたファイル名、フォルダに入れる場合はそのフォルダ名です。 さらに下のフォルダは探しません。同じ表示名を重ねずに置いてください。

detectors\
  sample.onnx
  sample.json          （任意）
  another\
    model.onnx
    model.json         （任意）
    labels.json        （任意）
    threshold.json     （任意）
    model_artifacts.json （任意）

置いたり入れ替えたりしたら［一覧を読み直す］を押します。読み込み中は「読み込み中」と表示します。 フォルダに検出器がなければ「検出器はありません」と置き場所を表示します。

選択・形・余白・閾値

  1. 消しゴム、隠蔽加工、 補正レイヤーでマスクを編集できる状態にし、［自動検出…］を押します。
  2. 検出器にチェックを付け、その下で使う分類を選びます。複数の検出器を選べます。初めは「顔 (内蔵)」だけが選ばれています。 追加の検出器の分類は、初回はすべて選ばれています。
  3. 形と余白を選び、必要なら［詳細］で閾値を変えます。［検出］を押すと、選んだ検出器を順に実行します。 読める検出器が選ばれていない場合や、追加の検出器の分類が一つも選ばれていない場合は、検出できません。
  4. 結果を確かめ、筆や図形で調整します。1 回の検出は Undo 1 回で取り消せます。0 件やキャンセルの場合はマスクを変えません。
項目内容
箱の形楕円 / 矩形。顔の既定は楕円、追加の検出器は設定ファイルの指定、なければ矩形です。追加した図形は選択ツールで動かせます。
輪郭の形輪郭に沿う / 楕円 / 矩形。既定は設定ファイルの指定、なければ輪郭に沿います。輪郭に沿って加えた範囲は筆・消去で直せます。
箱の余白顔と追加の検出器で共通。既定 15%。検出した幅・高さの指定割合を各辺の外側に足します。
輪郭の余白元画像の長辺に対する割合を半径として円形に太らせます。既定 0.6%。画素数に切り上げ、最小 2px です。
閾値確からしさの下限。顔の既定は 0.6。追加の検出器は設定ファイルの分類ごとの値、全分類の値、0.25 の順で使います。 ［詳細］で上書きを選ぶと、全分類に同じ値を使います。

輪郭の余白は、選んでいて読める輪郭の検出器があるときに表示します。箱の余白は顔・箱の検出器を選んだときや、輪郭の検出器の形を楕円・矩形にしたときに表示します。表示されていない間も余白の設定は残ります。

選択・分類・形・余白・閾値は 3 ツールで共有します。検出器を一時的にフォルダから外しても、その設定は残ります。 一覧には種類（箱 / 輪郭）、分類の数、ONNX 内のライセンス表記があればその文字列を表示します。

マスクは、筆や輪郭で加えた範囲を下地にし、図形を作った順に重ねます。 輪郭で足した部分に、以前作った消去の図形が重なると、そこは抜けたままになります。 箱から作る楕円・矩形は末尾に加わるため、前の消去の図形より後に効きます。

設定ファイル

直接置く場合は ONNX と同じ名前の .json、フォルダに入れる場合は model.json で上書きできます。 すべての項目は省略できます。不明な項目は無視しますが、書式が壊れたファイルは読めない検出器として表示します。

{
  "names": ["分類 A", "分類 B"],
  "thresholds": {"分類 A": 0.15},
  "threshold": 0.25,
  "shape": "rect"
}

names はモデルの分類番号順の名前です。上の分類名は書式を説明するための仮の名前です。 thresholds は分類名ごとの閾値、threshold は指定のない分類で使う閾値です。 shape は rect（矩形）、ellipse（楕円）、contour（輪郭に沿う）のいずれかです。 輪郭に沿う形は輪郭の検出器で使えます。

分類名はこの json の names、ONNX 内の名前、labels.json の順で使います。 どこにも名前がなければ「分類 0」「分類 1」…と表示します。

フォルダ形式では labels.json を ["分類 A", "分類 B"] のような名前の配列にできます。 threshold.json は {"threshold": 0.278} のように全分類共通の値を指定します。 model.json の同じ項目を優先します。 model_artifacts.json の args.imgsz は入力サイズに使います（例: {"args": {"imgsz": 640}}）。 入力サイズは ONNX 内の指定を優先し、それらがなければ固定の入力サイズ、どれもなければ 640 を使います。

読めないとき

対応する形式は Ultralytics の箱の検出（detect）と輪郭の検出（segment）の ONNX です。 重なり除去済みの形式には対応していません。形式が違う、分類名の数が出力と合わない、json を読めない、ONNX を開けない場合は、 灰色の行に理由を出し、選べないようにします。元のファイルと設定ファイルを確かめてから一覧を読み直してください。

一覧を読んだ後で ONNX が変わった場合も検出を中止し、「検出器のファイルが変わりました。一覧を読み直してください」と表示します。
