動画（インライン再生）

動画ファイルはフルスクリーンでインライン再生できます (FFmpeg LGPL DLL バックエンド)。 下部 HUD から 0.5x〜3.0x の倍速再生を選択でき、音声はピッチを維持して再生します。 グリッドサムネは Windows Shell API + 同名ファイル名画像 (sidecar) + ピン留めフレームの 優先順位で表示します。フルスクリーン操作の詳細は 動画再生 ページを参照してください。

拡張子フォーマット
.mp4MPEG-4 (H.264 / HEVC / AV1 等)
.mkvMatroska (ほぼ全コーデック)
.movQuickTime
.aviAVI
.wmvWindows Media Video / VC-1
.mpg / .mpegMPEG-1 / MPEG-2
💡
音声は WASAPI 共有モード経由 (cpal)。ハードウェア デコード (D3D11VA) は環境設定の 「動画」ページで有効化できます。D3D11VA 非対応の古いコーデックは SW デコードで再生し、 D3D11VA 対応コーデックの HW 経路失敗は再生エラーとして表示します。

アーカイブ

拡張子フォーマット備考
.zip / .cbzZIP / CBZアーカイブ内の画像をそのまま閲覧可能（変換不要）。中にサブフォルダや別の ZIP がある場合は、それぞれを「開いて中に入れるフォルダ」として表示し、ツリー状に行き来できます。CBZ は中身が ZIP のコミック形式で、ZIP と同じく扱います
.rar / .cbrRAR / CBRクリックで ZIP に変換して閲覧（パスワード付き対応。パスワード自体は保存せず、変換後 ZIP キャッシュはパスワードなし。分割 RAR は先頭パートから開く）
.7z / .cb77z / CB7クリックで ZIP に変換して閲覧（変換は初回のみ、2 回目以降はキャッシュから高速表示）。CB7 は中身が 7z のコミック形式
.lzh / .lhaLZHクリックで ZIP に変換して閲覧（7z と同様）
ℹ️
変換済み ZIP のキャッシュは「設定 → 変換済みアーカイブキャッシュ管理…」から一覧・削除できます。 容量上限は「環境設定 → キャッシュ」で設定できます（既定は無制限）。 確認画面を省略して自動変換する設定も同じページにあります。変換中の進捗は表示されます。 RAR 展開には RARLAB UnRAR を使用します。詳しくは FAQ を参照してください。

Susie 画像プラグイン（オプション）

Susie 画像プラグイン（.spi ファイル、32bit 版のみ）を使うことで、上記以外の 画像形式にも対応できます。主に PC-98 / X68000 時代のレトロ画像形式（PI / MAG / PIC 等）を 閲覧したい場合に利用します。

プラグインは環境設定の「Susie プラグイン → 📁 フォルダを開く」で開かれる %APPDATA%\mimageviewer\susie_plugins\ に配置します。プラグインは 32bit の ワーカープロセス（mimageviewer-susie32.exe、最大 3 並列）に隔離されるため、 プラグインがクラッシュしても本体には影響しません。

詳しくは FAQ: 古い PC の画像形式に対応していますか？ を参照してください。

エクスポート対応形式

Ctrl+E のエクスポートでは、現在の表示結果を JPEG / PNG / WebP のいずれかで書き出せます。

  • JPEG / PNG / WebP は同じ形式で書き出す場合にメタデータ保持を選べます
  • HEIC / AVIF / JPEG XL / RAW / TIFF は JPEG または PNG に変換して保存します
  • PDF ページは画像として保存できますが、元画像メタデータはありません
  • アニメーション WebP はエクスポート対象外です
