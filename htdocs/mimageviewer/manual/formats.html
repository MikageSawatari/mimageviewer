動画（インライン再生）

動画ファイルはフルスクリーンでインライン再生できます (FFmpeg LGPL DLL バックエンド)。 下部 HUD から 0.5x〜3.0x の倍速再生を選択でき、音声はピッチを維持して再生します。 グリッドサムネは Windows Shell API + 同名ファイル名画像 (sidecar) + ピン留めフレームの 優先順位で表示します。フルスクリーン操作の詳細は 動画再生 ページを参照してください。

拡張子フォーマット
.mp4MPEG-4 (H.264 / HEVC / AV1 等)
.mkvMatroska (ほぼ全コーデック)
.movQuickTime
.aviAVI
.wmvWindows Media Video / VC-1
.mpg / .mpegMPEG-1 / MPEG-2
💡
音声は WASAPI 共有モード経由 (cpal)。ハードウェア デコード (D3D11VA) は環境設定の 「動画」ページで有効化できます。D3D11VA 非対応の古いコーデックは SW デコードで再生し、 D3D11VA 対応コーデックの HW 経路失敗は再生エラーとして表示します。

アーカイブ

拡張子フォーマット備考
.zip / .cbzZIP / CBZアーカイブ内の画像をそのまま閲覧可能（変換不要）。中にサブフォルダや別の ZIP がある場合は、それぞれを「開いて中に入れるフォルダ」として表示し、ツリー状に行き来できます。CBZ は中身が ZIP のコミック形式で、ZIP と同じく扱います
.rar / .cbrRAR / CBR非ソリッド圧縮で入れ子アーカイブを含まない場合は変換せず直接閲覧します。ソリッド圧縮、入れ子あり、パスワード付きは設定に応じて ZIP キャッシュへ変換します。分割 RAR は先頭パートから開きます
.7z / .cb77z / CB7設定に応じて確認後または自動で ZIP に変換して閲覧（変換は初回のみ、2 回目以降はキャッシュから高速表示）。CB7 は中身が 7z のコミック形式。設定で無視することもできます
.lzh / .lhaLZH設定に応じて確認後または自動で ZIP に変換して閲覧（7z と同様）。設定で無視することもできます

RAR / CBR / 7z / CB7 / LZH / LHA を選択して（スペースキーで複数選択できます） 変換 → ZIP ファイルに変換を実行すると、元ファイルと同じフォルダに 同名の .zip を作成できます。これは閲覧用キャッシュではなく、通常のファイルとして残ります。 同名の ZIP が既にある場合は上書きせず、そのファイルの変換をスキップします。 入れ子アーカイブを含む全画像の展開と、生成した ZIP の全画像を最後まで読み取る検証に 成功した場合だけ ZIP を保存します。読めないエントリや破損が見つかった場合は変換を失敗にし、 不完全な ZIP は残しません。元アーカイブは変更しません。 同名 ZIP を優先する設定が有効な場合、変換後の一覧には ZIP だけが表示されます。 元アーカイブから再変換したい場合は、環境設定の「同名の ZIP/CBZ と RAR/7z/LZH がある場合、 ZIP/CBZ だけ表示」を一時的に OFF にして元アーカイブを選択してください。

ℹ️
変換済み ZIP のキャッシュは「設定 → 変換済みアーカイブキャッシュ管理…」から一覧・削除できます。 容量上限は「環境設定 → パフォーマンス → キャッシュ」で設定できます（既定は無制限）。 変換前に確認する、自動変換する、RAR / 7z / LZH を無視する設定も同じページにあります。変換中の進捗は表示されます。 RAR 展開には RARLAB UnRAR を使用します。詳しくは FAQ を参照してください。

アーカイブの入れ子（ZIP の中の RAR など）

アーカイブの中に別のアーカイブが入っている場合も、中の画像まで閲覧できます。

  • ZIP の中に ZIP / CBZ：変換なしでそのままツリー表示します（上記のとおり）。
  • RAR / 7z / LZH の中のアーカイブ：変換時に入れ子のアーカイブも中まで展開し、それぞれが独立した「作品」としてツリーに並びます。
  • ZIP の中に RAR / 7z / LZH：設定が確認または自動変換の場合は、開いたときに「ZIP 内のアーカイブを展開」の確認または変換が行われます。変換すると入れ子の中身も見えるようになります。キャンセルしても、その ZIP 自体（入れ子以外の部分）は今までどおり閲覧できます。無視する設定ではこの提案は表示されません。

展開されたキャッシュは通常の変換キャッシュと同じく「変換済みアーカイブキャッシュ管理…」に並びます。 入れ子が極端に深い場合（8 段超）やパスワード付き・破損した入れ子は飛ばして、読める部分だけを展開します。

Susie 画像プラグイン（オプション）

Susie 画像プラグイン（.spi ファイル、32bit 版のみ）を使うことで、上記以外の 画像形式にも対応できます。主に PC-98 / X68000 時代のレトロ画像形式（PI / MAG / PIC 等）を 閲覧したい場合に利用します。

プラグインは環境設定の「ファイル処理 → Susie プラグイン → 📁 フォルダを開く」で開かれる %APPDATA%\mimageviewer\susie_plugins\ に配置します。プラグインは 32bit の ワーカープロセス（mimageviewer-susie32.exe、最大 3 並列）に隔離されるため、 プラグインがクラッシュしても本体には影響しません。

詳しくは FAQ: 古い PC の画像形式に対応していますか？ を参照してください。

エクスポート対応形式

Ctrl+E のエクスポートでは、現在の表示結果を JPEG / PNG / WebP のいずれかで書き出せます。

  • JPEG / PNG / WebP は同じ形式で書き出す場合にメタデータ保持を選べます
  • HEIC / AVIF / JPEG XL / RAW / TIFF は JPEG または PNG に変換して保存します
  • PDF ページは画像として保存できますが、元画像メタデータはありません
  • アニメーション WebP はエクスポート対象外です
