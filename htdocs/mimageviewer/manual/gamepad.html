ゲームパッド操作

画像・動画を閲覧するためのゲームパッド割り当てです。固定ボタンは既定動作で使い、操作カスタマイズから X+方向リングを差し替えられます。

ℹ️
Xbox 系の A/B/X/Y、方向パッド、左右スティック、LB/RB、LT/RT、Select/Start を想定しています。削除や外部エクスポートなどの破壊的な操作はゲームパッドには割り当てていません。

共通ルール

ボタン基本動作
A決定 / 開く / 次へ / 再生
B戻る / 閉じる
LB / RB前 / 次のフォルダへ移動。キーボードの Ctrl+↑ / Ctrl+↓ と同じツリー順ナビゲーションです
X方向と組み合わせるとリングショートカット、方向なしで離すとピッカーパネルを開きます
Yモードにより、単体操作または修飾ボタンとして使用します。Y を押しながら方向操作した場合、離したときの Y 単体操作は発火しません
Startお気に入り一覧を開きます。上下で選び、A でそのお気に入りへ移動します
Selectグリッドでは場所リストを開きます。画像・動画フルスクリーンでは下記の画面別動作になります

リングショートカットとピッカー

X を押しながら方向パッドまたは左スティックで 8 方向を選び、X を離すと現在の画面に対応した一発アクションを実行します。左スティックは軽く触れた程度では方向確定せず無方向扱いです。グリッド、画像フルスクリーン、動画フルスクリーンで別々の割り当てを持ち、設定メニューの「操作カスタマイズ…」で変更できます。

操作カスタマイズの「ゲームパッド」タブでは、A/B/X/Y、Select/Start、LB/RB、LT/RT の単体動作を、画面ごとに「既定」「なし」「一発アクション」から選べます。X 単体と X+方向リングは別設定です。

入力操作
X+方向選んだ方向のリングスロットを実行。画像フルスクリーンでは、既定で右上スロットがメタデータパネル切り替えです
X 単体列数、ソート、レーティング、見開き、フィット、ポストフィルタ、動画音量などの多状態項目を選ぶピッカーパネルを開きます
ピッカー中の方向 / A / B / X上下で項目選択、左右で値変更。A は一覧表示または一覧項目の選択、X / B は確定して閉じます

グリッド表示

入力操作
方向パッド / 左スティックサムネイル表示では選択を上下左右に移動。詳細表示では上下で 1 行移動し、左右で表示行数ぶん前後にスキップ
A選択中のアイテムを開く。画像・動画はフルスクリーン、フォルダ・ZIP・PDF はその場所へ移動
B親フォルダへ戻る。検索結果表示中は検索結果の階層を 1 段戻る
Select場所リストを開く。ドライブ一覧、読書履歴、レーティング一覧、本棚フォルダ、主要フォルダ、ドライブを上下で選び、A で移動します
LB / RBツリー順で前 / 次のフォルダへ移動
LT / RT押している間、一覧を上 / 下へスクロール
Yフォルダツリーペインの表示 / 非表示を切り替え。表示時は現在フォルダへツリーカーソルを移動。ツリー表示中は方向パッド / 左スティックで移動し、A で決定するとそのフォルダへ移動してツリーを閉じます。もう一度 Y を押したときも、ツリーカーソルを別のフォルダへ動かしていればそのフォルダへ移動してから閉じます（動かしていなければそのまま閉じます）

画像フルスクリーン

入力操作
方向パッドページ送り。左右は現在の見開き方向に従い、キーボードの左右キーと同じ意味になります。縦読み中は上下で縦スクロールします
A次のページへ移動
Bフルスクリーンを閉じる
Xリングショートカット / ピッカーパネル。メタデータパネル切り替えは、既定で画像リングの右上スロットに入っています
Select見開きモードを順に切り替え。単ページ → 見開き 左→右 → 見開き 左→右（表紙あり） → 見開き 右→左 → 見開き 右→左（表紙あり）
Y+方向パッド左右見開きを 1 ページずらす。キーボードの Ctrl+← / → と同じで、左右の意味は見開き方向に従います
Y+方向パッド上下フォルダ内の最初 / 最後の画像へ移動。キーボードの Home / End と同じです
左スティック拡大中の画像をパン
右スティック上下ズームイン / ズームアウト。細かい調整よりも素早い拡大縮小に向いた速度です
LT / RT押している間、ズームアウト / ズームイン
LB / RB前 / 次のフォルダへ移動し、移動先の先頭画像を開く

動画フルスクリーン

入力操作
方向パッド左右通常再生中は 5 秒シーク。タイルモード中はタイルカーソルを前 / 次へ移動
方向パッド上下前 / 次の動画・画像へ移動。タイル一覧を表示していても、キーボードの上下キーと同じく前後ファイル移動として動作します
A通常再生中は再生 / 一時停止。タイルモード中は選択中のタイル位置から再生
Bタイルモード中はタイルを閉じる。通常再生中はフルスクリーンを閉じる
Yタイルモードの表示 / 非表示を切り替え。キーボードの S と同じです
Y+方向パッド左右前 / 次のチャプター・ブックマーク・ピンへ移動。キーボードの J / K と同じです
Selectブックマーク / チャプター / ピンの一覧を開きます。上下で選び、A でその位置へ移動します
LT / RT押している間、戻る / 進む方向へ連続シーク。タイルモード中は左右キーと同じくタイルカーソル移動になります
LB / RB前 / 次のフォルダへ移動し、移動先の先頭メディアを開く
⚠️
ダイアログ表示中、テキスト入力中、消しゴム・隠蔽加工・補正レイヤー・テキスト注釈などの編集モード中は、通常のゲームパッド閲覧操作は無効になります。
