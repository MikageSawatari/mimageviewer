Changes made by Mikage Sawatari for mImageViewer:

- The original safetensors weights were converted to GGUF with llama.cpp
  b12032 (convert_hf_to_gguf.py).
- The language model was quantized to Q4_K_M with llama-quantize, using an
  importance matrix computed from the text of the mImageViewer manual.
- The vision projector (mmproj) is stored in F16.
- No fine-tuning or retraining was performed.
- The language model file is split into parts for distribution.
  Concatenating the parts in order restores the original file.
